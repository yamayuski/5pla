# 最後の一針（sewing-factory）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最後の一針

## 一行ピッチ

夜の縫製工場で納期前の残業。誰も座っていないミシンが、一台ずつ動き出す。裁断台の布の下に。

## 舞台

夜の縫製工場（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 仕上がった服を検品する。 |
| 1:00〜3:00 | 異変①ボタンが散らばる（1:10）②照明が瞬き足音が止まる（2:00）③ミシンの陰に糸まみれの人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。針の音は布の下から聞こえる。めくるしかない。 |
| 4:00〜5:00 | 布をめくると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- ミシンの音、鋏の音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（布をめくる）、F: ライト

## エンディング

翌朝、工場の出来上がり品に、一着だけ寸法の合わない服が混じっていた。 タグには、あなたの名前が縫い付けられていた。
