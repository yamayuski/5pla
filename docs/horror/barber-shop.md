# カットは終わりません（barber-shop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

カットは終わりません

## 一行ピッチ

閉店後の理容室。誰もいないのに、三脚目の椅子だけが鏡に背を向けて座られている。その椅子を回した瞬間。

## 舞台

閉店後の理容室（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 誰もいない理容室で財布を探す。床には切りたての髪。 |
| 1:00〜3:00 | 異変①蛇口の水が勝手に出る（1:10）②照明が瞬き足音が止まる（2:00）③鏡の奥に白いケープの人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。奥の椅子に誰かが座っている。回して確かめるしかない。 |
| 4:00〜5:00 | 一番奥の椅子を回すと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 鏡、ハサミの音、水音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（一番奥の椅子を回す）、F: ライト

## エンディング

翌朝、店主は言った。「三番の椅子は、先月から誰も座っていないよ」 財布は、切りそろえられたあなたの髪の上に置かれていた。
