# 巡回中（koban-night）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

巡回中

## 一行ピッチ

雨の夜、「ただいま巡回中」の札が掛かった無人の交番で警官を待つだけ。鳴る電話、変わる手配書、そして机の向こうにはいつの間にか制服の男が座っている。

## 舞台

住宅街の小さな交番（約6m × 6m）。机と赤い電話、掲示板、無線機、奥に仮眠室。入口はガラス戸で、外は大雨の路地。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯と雨音だけの静かな交番。25秒で机の電話が鳴り、受話器を取る（E）と「机の向こうに誰か座っていませんか」。 |
| 1:00〜3:00 | 異変①掲示板の手配書が「氏名 あなた」に変わる（1:35）②仮眠室の戸が勝手に開き足音（2:20）③無線「本官は、すでに……」（3:05）。 |
| 3:00〜4:00 | 入口の戸が閉まってロック、照明が落ち（3:35）、懐中電灯だけに。背後に足音、霧が濃くなる。 |
| 4:00〜5:00 | 机の向こうに制服の男が現れる。**見た瞬間**にジャンプスケア。見なくても約25秒で襲ってくる。330秒で強制発火。 |

## 主な演出

- 蛍光灯の交番から、照明を順に落として暗闇へ
- 手配書のテクスチャ差し替え、電話の受話器の揺れ、仮眠室の戸が開く
- 無線のノイズとささやき、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（電話）、F: ライト（消灯後に自動で点く）

## エンディング

「翌朝、無人の交番で、机に伏せた制服の男性が見つかった。死後数年。日誌の最後の行には、昨夜の日付で『来訪者一名、待機中』とあった。」

## 実装メモ

- config.ts に演出をデータで記述（time / interact / look / after、requires / unless で保険）
- level.ts は MeshBuilder のプリミティブのみ。共通キット @5pla/horror-kit を使用
