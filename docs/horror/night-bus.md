# 終点まで（night-bus）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

終点まで

## 一行ピッチ

寝静まった夜行バスで目が覚めると、眠っているはずの乗客が全員、後ろ向きの白い顔でこちらを見ていた。

## 舞台

東京行きの夜行バスの車内（幅3m × 長さ15m）。左右5列ずつの座席で乗客は全員眠っている。前方に運転席、フロントガラスに行先表示と時計、側面は黒い窓。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 低いエンジンの振動と寝息。運転席の近くまで行って到着時刻を確かめるつもりで通路を進む。車内放送「まもなく終点です」（まだ出発して二時間のはず）。 |
| 1:00〜3:00 | 異変①左側の乗客の頭に、後ろ向きの白い顔が現れ、全員がこちらを向いている（1:15）②右側も同様に（2:10）③バスが急停止し、窓の外に名前の読めないバス停。誰も降りない（2:50）。 |
| 3:00〜4:00 | 乗降口の扉が閉まり、後ろの灯りが消える（3:25）。さらに中ほどの灯りも消え、ライトが弱まる。運転手の声が「終点です」を繰り返す（3:40）。 |
| 4:00〜5:00 | 運転席に近づくと、運転手がゆっくり振り向き、目の前に現れる（ジャンプスケア）。近づかなくても約55秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 乗客の頭を円柱、顔を白いパーツで構成し、TransformNode ごと visible を切り替える（左右2段階）
- 灯りは3グループを後ろから順に消し、閉塞感を作る
- 窓の外の街灯は点光源の点滅で表現（外の景色は作らず、車内に絞る）
- 手続き音：エンジンのドローン、放送チャイム、きしみ、ささやき、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、東京行きの夜行バスは終点に着いたが、降りてきた乗客は一人もいなかった。運転手は『ずっと満席だった』と繰り返すばかりだったという。座席には、人の形に湿ったシートだけが残っていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（zone / time / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
