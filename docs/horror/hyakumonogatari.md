# 百物語（hyakumonogatari）

## タイトル
百物語

## 一行ピッチ
百物語の最後の一話のあと、仏間のおりんを鳴らしに一人で長い廊下を歩く。障子の影が、増えていく。

## 舞台
親戚の古い日本家屋の長い廊下。行灯の灯る障子、突き当たりに仏壇とおりん。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 行灯の廊下を歩き、突き当たりのおりんを目指す（interact）。 |
| 1〜3分 | 障子に人影（1:05）、影が増え笑い声（1:50）、行灯が消える（2:30）。 |
| 3〜4分 | 背後の襖が閉まり戻れない（3:20）。ライトが弱まり、背後から足音。 |
| 4〜5分 | おりんを鳴らすと蝋燭が消え暗闇、背後から白い影が現れる（大ジャンプスケア）→ エンディング。 |

## 主な演出
- 障子の影、行灯の消灯、襖の閉塞、背後の足音

## 操作方法
- クリックで開始、WASD移動、マウス視点、E/クリックで調べる、Fライト

## エンディング
「百本目の蝋燭が消えると、本物が来る。…廊下には、百人目の足跡だけが残っていた。」
