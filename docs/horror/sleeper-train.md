# 終点の名前（sleeper-train）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

終点の名前

## 一行ピッチ

夜行寝台特急の個室から、水を飲みに通路へ出ただけ。空き個室の扉がひとりでに開き、時速百キロの窓の外に女の顔が並走し、車内放送は終点の駅名だけが聞き取れない。

## 舞台

夜行寝台列車の一両（幅1.2mの通路、長さ16m）。西側は窓（外を町の灯りが流れていく）、東側に個室の扉が6つ並ぶ。自分は1号室。北端に洗面台と連結扉、南端に案内表示のLED。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | レールの継ぎ目の音と流れる灯り。個室を出て、通路の突き当たりの洗面台で水を飲む（E）。少し鉄の味。何もしなくても50秒で水がひとりでに流れ出す。 |
| 1:00〜3:00 | 異変①4号室の扉がすうっと開くが、中は真っ暗で誰も出てこない（1:15）②窓を叩く音。走る列車の窓の外に女の顔が並び、自分の歩く速さについてくる（2:00〜）③車内放送「次は、終点……」。駅名のところだけ雑音で聞き取れない。LEDも同じ（2:45）。 |
| 3:00〜4:00 | 急ブレーキのような衝撃で、自分の個室の扉も連結扉も閉まってロック（3:25）。車内灯が消え、青い非常灯だけ。列車は止まらない。 |
| 4:00〜5:00 | 個室の扉を叩く（E）と扉が開き、同時に通路の奥の連結扉から車掌が歩いてくる。「……切符を、拝見します」。**それを見た瞬間**、目の前に迫る（ジャンプスケア）。叩かなくても消灯から約35秒で現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 幅1.2mの細い通路で、前後の扉と窓に挟まれる閉塞感
- 窓の外を流れる灯り（フックで常時スクロール）と、並走して追ってくる顔（フック `faceFollow`）
- 案内表示（DynamicTexture）と車内放送の雑音
- 個室扉と連結扉の slam → lock、非常灯（青）への切り替え、走行音のドローン
- 手続き音：走行音、扉、窓を叩く音、チャイム、ノイズ、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（洗面台・個室の扉）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「翌朝、寝台特急は定刻に終着駅へ着いた。1号室の乗客だけが、どこにもいなかった。個室の枕元には、見たことのない駅名の入った切符が一枚、鋏を入れて置かれていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。他の個室の中は見えない壁で塞いである
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
