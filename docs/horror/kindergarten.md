# ひなぐみの教室（kindergarten）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

ひなぐみの教室

## 一行ピッチ

閉院間際の幼稚園医院。壁を叩く音、変わるお絵かき、閉まる扉。教室の向こうには、最初から先生が立っていた。

## 舞台

幼稚園の診察室（6m × 7m）。南壁に扉、東西にソファ、中央にテーブルとおもちゃ箱とリモコン、北壁に大型お絵かき、天井に電気。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 遠くのオルガン音が漏れる静かな個室。リモコンで曲を入れる（E）と電気が回る。40秒で自動再生。 |
| 1:00〜3:00 | 異変①遠くのオルガン音が止み壁を内側から叩く（1:15）②お絵かきの歌詞が「たすけて／うしろにいる」に（2:05）③おもちゃ箱からささやき（2:45）。 |
| 3:00〜4:00 | 扉が勝手に閉まりロック（3:25）。照明が赤に変わりライトが弱まる、背後で息づかい（3:35）。おもちゃ箱を置き直すしかない。 |
| 4:00〜5:00 | 向かいの教室の向こうに園児服の人影がおもちゃ箱を握って座っている。**見た瞬間**目の前に現れる。見なくても約35秒で強制発生。 |

時間切れ救済: プレイ開始320秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 電気の紫から非常灯の赤への照明切り替え
- お絵かき表示の差し替え、扉の slam → lock、フォグ上昇
- 手続き音：ノック、ささやき、ノイズ、息づかい、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（リモコン・おもちゃ箱）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、衛生士は倒れたままの教室を見つけた。カルテには十年前に閉院した医院の患者として、あなたの名前があった。」と表示して終了。
