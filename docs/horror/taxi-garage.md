# 回送（taxi-garage）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

回送

## 一行ピッチ

深夜のタクシー車庫。誰もいない車の後部座席から「出してください」と声がして、メーターだけが上がり続ける。

## 舞台

タクシー会社の車庫（約8m × 14m）。入口にシャッター、奥に黄色いタクシー、手前に運賃メーター台と事務所の電話。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の車庫。運賃メーターを点検する（料金が勝手に上がっている）。 |
| 1:00〜3:00 | 異変①事務所の電話「もう車の中です」（1:10）②車内から窓を叩く音（2:00）③「出してください」の声（2:45）。 |
| 3:00〜4:00 | シャッターが落ちて消灯（3:25）。後部座席に人影、背後に足音。 |
| 4:00〜5:00 | メーターを止めようとすると人影が目の前に現れる（ジャンプスケア）。触らなくても330秒で発生。 |

## 主な演出

- 蛍光灯→消灯、シャッターの slam / lock
- 赤く光る運賃メーター、後部座席の人影
- 手続き音：ブザー、ノック、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝、無人のタクシーと、夜通し上がり続けた料金だけが残る。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。
