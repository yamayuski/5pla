# 椿の間（ryokan-loop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

椿の間

## 一行ピッチ

大浴場の帰り、自室へ向かう古い旅館の廊下。歩いても歩いても突き当たりに着かず、同じ廊下の手前へ戻される。

## 舞台

山あいの古い温泉旅館の長い一本廊下（幅2.4m、長さ32m）。左右に客室の襖と部屋札（梅・竹・松・桜・菊）が並び、突き当たりが自室「椿の間」。畳敷きの床、橙の電灯、浴衣姿。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 浴衣で廊下を歩いて椿の間へ戻る。古い床板の軋みと橙の灯り。突き当たり付近まで来ると、廊下の手前へ戻される（ループ①）。 |
| 1:00〜3:00 | 異変①全部屋の前に揃えたスリッパが現れる（1:15）②部屋札がすべて「四」に変わる（2:00）。ループ②。③襖の隙間に白い目が並び、手前の灯りが落ちる（2:40）。 |
| 3:00〜4:00 | 廊下の灯りが奥から消え、フォグが濃くなる（3:25）。ループ③で背後から畳を擦る足音がついてくる。 |
| 4:00〜5:00 | ようやく椿の間の前に着くと襖が内側から開き、正座した女の背中。**見た瞬間**（または約9秒後）に振り向いて目の前に現れる（ジャンプスケア）。 |

時間切れ救済: 3:25の消灯から75秒で襖が自動で開く／プレイ開始330秒で強制ジャンプスケア → エンディング。

## 主な演出

- 廊下を一様に作り、プレイヤー座標を 18m 手前へ戻すだけの無限回廊（custom: loop）。継ぎ目は見えない
- 戻されるたびに少しずつ変化（スリッパ → 部屋札 → 襖の隙間の目 → 消灯 → 椿の間が開く）
- 手続き音：床の軋み、囁き、襖のがたつき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- ライトなし（廊下の電灯だけ）
- ヘッドホン推奨

## エンディング

「翌朝、女将は宿帳を見て首をかしげた。『椿の間』は、四十年前の火事のあと、一度も客を通していないという。廊下の突き当たりには、誰の部屋もなかった。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（zone の連鎖 requires + 時間マーカーで進行を制御）
- `level.ts` は MeshBuilder のプリミティブのみ。ループは `custom` フック1つ
- 共通土台は `kit/` を同梱（自己完結）
