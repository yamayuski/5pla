# 競りの前（fish-market）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

競りの前

## 一行ピッチ

夜明け前の魚市場。競りの準備中、氷の山のむこうから、誰かが魚を数える声がする。氷を崩した先には。

## 舞台

夜明け前の魚市場（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 魚市場で競りの箱を番号順に並べる。 |
| 1:00〜3:00 | 異変①箱が勝手に倒れる（1:10）②照明が瞬き足音が止まる（2:00）③氷の山の陰に長靴の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。数える声は氷の山の中から聞こえる。崩して確かめるしかない。 |
| 4:00〜5:00 | 氷の山を崩すと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 水音、氷、濡れた足音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（氷の山を崩す）、F: ライト

## エンディング

翌朝、競りが始まった。 氷の山の中から、番号札を付けられたあなたの長靴が、片方だけ見つかった。
