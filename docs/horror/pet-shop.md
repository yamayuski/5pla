# 布をめくらないで（pet-shop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

布をめくらないで

## 一行ピッチ

モールのペットショップで初めての閉店作業。子犬たちが一斉に、布を掛けた「大型犬用」の空のケージを見つめて固まる。布の下から聞こえるのは、人の声だった。

## 舞台

閉店後のショッピングモール内のペットショップ（8m × 10m）。東西の壁に2段のガラスのショーケース（子犬・子猫）、中央にレジとエサ棚、北壁中央に布を掛けた大型ケージと「布をめくらないでください」の札、その横に開かない STAFF ONLY の扉。南はモールの通路に面したガラス戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 静かな閉店後の店内。エサ棚からごはんを配る（E）。何もしなくても45秒で配り終える。 |
| 1:00〜3:00 | 異変①店内が急に静まり、動物たちが一斉に奥の布を掛けたケージを見つめて固まる（1:15）②布の下から格子を引っかく音と息づかい（2:00）③動物たちがケースの奥に縮こまって背を向け、ケースの灯りが消える。布の下から人の声「……あけて……」（2:40）。 |
| 3:00〜4:00 | 店のガラス戸が閉まってロック、遠くでモールの防犯シャッターが下りる音（3:25）。照明が落ち、赤い非常灯とライトだけ。ケージが内側から叩かれる。 |
| 4:00〜5:00 | 布をめくる（E）と、ケージの中に首輪をつけた人がうずくまっている。**それを見た瞬間**、目の前に飛び出す（ジャンプスケア）。めくらなくても消灯から約35秒で布が内側から引きずり落とされる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 動物たち（プリミティブの小動物）の向きで「何かがいる方向」を示す：正面 → 全員がケージを凝視 → 全員が奥に縮こまって背を向ける
- 「めくらないで」と書かれた布という、プレイヤー自身に禁忌を破らせる最後の操作
- ドローン音を止めた「急な静けさ」
- ガラス戸の slam → lock、消灯で赤い非常灯に
- 手続き音：引っかく音（rattle）、息づかい、ささやき、ケージを叩く音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（エサ棚・布）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「翌朝、店長は大型ケージに新しい布を掛け直した。札の『大型犬用』の下に、昨日のアルバイトの名前を書き足して。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。動物の向きはフック `petsStare` / `petsHide`
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
