# 地下三階（parking-b3）

## タイトル
地下三階

## 一行ピッチ
残業帰りの地下駐車場。停めたはずの区画に、車がない。

## 舞台
オフィスビルの地下三階駐車場（柱の並ぶコンクリートのワンフロア、蛍光灯、駐車中の車が数台）。南にエレベーター、北西に「精算機 故障中」でバーが下りたままの出口ゲート、北東の奥が自分の区画 B3-44。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 蛍光灯のうなりだけが響く深夜の駐車場。スマホのライトを頼りに北東の B3-44 へ歩く。着くと――区画が空っぽ。車がない。 |
| 1〜3分 | 小さな異変：①西側の蛍光灯がばちんと消える（1:05）②背後から自分のものではない靴音（1:40）③赤い車の防犯ブザーが一瞬鳴って止む（2:18）④誰も呼んでいないエレベーターが B3 で開く。中は空（2:50）。 |
| 3〜4分 | 逃げ道が塞がる：出口のシャッターが轟音とともに下り、エレベーターも閉まって動かない。照明が全部落ち、ライトも弱まる（3:20）。7 秒後、北東の奥でオレンジのハザードが点滅し始める。さっきまで無かった自分の車が、区画に停まっている。 |
| 4〜5分 | 車に近づく（zone）→ ライトが消え、ハザードの点滅だけに → 点滅のたびに車の向こうの女が近づいてくる（ストロボ接近）→ 目の前に（大ジャンプスケア）→ エンディング。5:20 までに近づかなければ保険の一発。 |

## 主な演出
- 広い暗闇とフォグ、懐中電灯（スマホのライト）の狭い円錐
- 蛍光灯の列が段階的に消え、最後はハザードランプの橙の点滅だけに
- 「あるはずのものが無い → 無かったはずのものが有る」の反転
- ラストはストロボ接近型：点滅するたびに人影の位置が近くなる（毎回こちらを向く）
- 手続き的な音：蛍光灯のうなり、靴音、防犯ブザー、エレベーターのチャイム、シャッターの轟音、心音

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- F：ライトの点け消し、E / クリック：調べる

## エンディング
「翌朝、B3-44 の白いセダンは、エンジンがかかったまま見つかった。運転席は空で、後部座席にだけ、長い髪が残っていた。このビルの地下は、二階までしかない。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / zone / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。自分の車の出現・ハザード点滅・シャッターだけ `custom` / `update` フック
- 共通土台は `kit/` を同梱（自己完結）
