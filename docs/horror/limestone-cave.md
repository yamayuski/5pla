# 鏡ヶ淵（limestone-cave）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

鏡ヶ淵

## 一行ピッチ

観光鍾乳洞のツアーではぐれ、木道をたどって奥の地底湖へ。うしろの足音は止まると一緒に止まり、奥からは「こちらへどうぞ」と係員の声だけが呼ぶ。

## 舞台

観光鍾乳洞の奥の区画「第二洞」（8m × 20m、天井3.5m）。鍾乳石と石筍に囲まれた洞内を、手すり付きの木道が奥の地底湖「鏡ヶ淵」まで続く。入口に鉄格子の扉、木道の途中に音声ガイドの台、天井に裸電球の列。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ひんやりした空気と水滴の音。木道を進み、音声ガイドを再生する（E）。「水面に映る顔が、ときどき自分と違って見える」。何もしなくても50秒でガイドがひとりでに鳴る。 |
| 1:00〜3:00 | 異変①背後の水滴の音が足音に変わる。止まると向こうも止まる（1:15）②奥から係員の声「こちらへどうぞ……」。団体の足音はもう聞こえない（2:00）③背後で鍾乳石が折れて落ち、電球が明滅する（2:40）。 |
| 3:00〜4:00 | 入口の鉄格子が閉まる音が洞内に反響する（3:25）。電球がすべて消え、ライトと、奥の地底湖の青い光だけになる。 |
| 4:00〜5:00 | 地底湖の看板を読む（E）と「水深 不明」。水音がして、湖の上に制服の女が立っている。**それを見た瞬間**、目の前に迫る（ジャンプスケア）。読まなくても消灯から約35秒で湖の上から声がして現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 一本道の木道（見えない柵で外れない）で、前へ進むしかない構成
- 背後の足音、奥から呼ぶ声という前後からの挟み撃ち
- 鍾乳石が落ちる（move＋地響き＋揺れ）
- 鉄格子の slam → lock、全消灯と地底湖の青い光
- 手続き音：水滴、足音、ささやき、落下音、地響き、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（音声ガイド・看板）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「ツアーの点呼で、一人足りないことに気づいたのは出口だった。第二洞は二十年前の落盤事故以来、案内していない。係員はそう言って、首を傾げた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ（鍾乳石・石筍は円錐、岩は潰した球）
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
