# 引っ越し前夜の空き部屋（move-out）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

引っ越し前夜の空き部屋

## 一行ピッチ

明日で出ていく1Kの最後の夜。落ちる段ボール、隅の人影、壁の小さな手形のあと、玄関が閉まり、薄く開いた押入れの襖の中には。

## 舞台

荷造りを終えた空っぽの1K（約6m × 8m）。段ボールの山、こたつ、北東に押入れ。玄関は南。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | がらんとした部屋を見て回る。50秒で段ボールが一つ勝手に落ちる。 |
| 1:00〜3:00 | 異変①隅に長髪の人影、目を逸らすと消える（1:35）②壁に小さな手形、爪でなぞる音（2:30）③インターホンが鳴るが誰も映らない（3:10）。 |
| 3:00〜4:00 | 玄関が閉まりロック、部屋の明かりが落ちる（3:35）。押入れの襖が指一本ぶん開いている。 |
| 4:00〜5:00 | 襖を開ける（E）と女が正座しており、ジャンプスケア。調べなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 何もない部屋の反響音、段ボールの落下、背後の気配
- lookAway で消える人影、壁の手形、閉ざされる玄関

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（押入れの襖）、F: ライト

## エンディング

「引っ越し当日の朝、業者が見たのは、空っぽの部屋と、押入れの中でうずくまる前の住人の荷物だった。部屋の主だけが、どこにもいなかった。」

## 実装メモ

- 押入れ襖は interact 対象、中の figure を visible で出す。段ボール落下は custom フック boxFall。
