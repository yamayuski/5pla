# 網の中（boat-house）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

網の中

## 一行ピッチ

夜の漁港の網小屋で漁網の修繕。引き上げた網が、重い。濡れた網の山の奥に。

## 舞台

夜の漁港の網小屋（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 破れた網を順に繕う。 |
| 1:00〜3:00 | 異変①浮きの束が落ちる（1:10）②照明が瞬き足音が止まる（2:00）③隅に濡れた合羽の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。息づかいは網の奥から聞こえる。かき分けるしかない。 |
| 4:00〜5:00 | 網をかき分けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 波の音、網の軋み、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（網をかき分ける）、F: ライト

## エンディング

翌朝、漁師たちは網小屋で繕いかけの網を見つけた。 網目のひとつひとつに、あなたの髪が絡まっていた。
