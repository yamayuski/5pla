# 空きカプセル（capsule-hotel）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

空きカプセル

## 一行ピッチ

終電を逃して泊まったカプセルホテル。消灯後の就寝フロアで、カーテンが揺れ、空の布団が温かく、出口のシャッターが閉まる。逃げ込んだ自分のカプセルには、先客がいた。

## 舞台

カプセルホテルの就寝フロア（幅2m × 長さ14mの通路、東側に二段カプセル5列）。自分は101（1列目下段）。南端に出口シャッター、北端に自販機。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 消灯後の寝息といびき。通路のスリッパを揃える（E）。何もしなくても40秒で進む。 |
| 1:00〜3:00 | 異変①103のカーテンが内側から揺れ、いびきが止まる（1:15）②202のカーテンが勝手に開き、温かそうな凹んだ布団だけがある（2:00）③照明が瞬き、通路の奥に浴衣の客が立っている。次の瞬間には消える（2:45）。 |
| 3:00〜4:00 | 出口のシャッターが轟音とともに閉まり施錠（3:25）。続いて照明が全て落ち、自分のカプセルへ戻るしかなくなる。背後に足音と息。 |
| 4:00〜5:00 | 自分のカプセルでカーテンを閉めようとする（E）と、中から**青白い顔が飛び出す**（ジャンプスケア）。何もしなくても消灯から40秒で発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 狭い通路とカーテンという「見えない中身」への不安
- カーテンの揺れ（フック `curtainSway`）、勝手に開くカーテン、シャッターの閉鎖と施錠
- 通路奥の客の一瞬の出現と消失、全消灯と懐中電灯の減光、霧の濃度上昇
- 手続き音：ささやき、足音、水滴、息、心音、ドローン

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（スリッパ・自分のカプセル）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、フロントは言った。『101号室は、昨夜から誰も泊まっていませんが』布団は、人の形に凹んだまま温かかったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
