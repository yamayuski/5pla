# 開かずの踏切（railroad-crossing）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

開かずの踏切

## 一行ピッチ

残業帰りの夜、いつまでも開かない踏切。向こう側で待つ人影が、少しずつ増えていく。

## 舞台

夜の住宅街の細い道（幅6m × 長さ44m）の途中にある踏切。遮断機は下りたまま、赤い警報灯が交互に点滅し、警報音が鳴り続ける。線路の向こう側に立つ人影。街灯は一本だけ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 警報音の中、踏切へ向かって歩く。遮断機は下りたまま。電車の音はしない。 |
| 1:00〜3:00 | 異変①向こう側に三人、こちらを向いて待っている（1:10）②二人増える（2:05）③線路の砂利の中から囁き「かえして」（2:40）④警報音のテンポが速くなる（3:05）。 |
| 3:00〜4:00 | 街灯が消え、赤い警報灯だけに（3:25）。電車が轟音とともに人影の前を通過（3:42）。警報音が止み、遮断機が上がり、人影が一斉にこちらへ渡ってくる（3:52）。 |
| 4:00〜5:00 | 人影の列が目の前まで近づく。**先頭の女を見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 警報音（bell）を `update` フックで一定間隔に鳴らし、赤色灯2つを交互に点滅。テンポを段階的に速める（`custom`: bellOn / bellFast / bellOff）
- 電車は TransformNode を `move` で横切らせ、通過直後に遮断機を上げて静寂へ落とす
- 向こう側の人影を `visible` で増やし、最後は `move` で全員を一斉に歩かせる
- 手続き音：警報音、電車の轟音、囁き、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、踏切の警報機は、電車が一本も通っていないのに、夜明けまで鳴り続けていたという。線路脇の電柱の根元には、会社帰りの鞄が一つ、まだ温かいまま置かれていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。警報音と点滅だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
