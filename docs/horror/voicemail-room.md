# 留守電 3件（voicemail-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

留守電 3件

## 一行ピッチ

残業から帰った夜、留守番電話の3件のメッセージを順に再生するたびに、声が近づき、3件目は自分の背後から聞こえる。

## 舞台

一人暮らしのリビング（7m × 8m、天井高2.5m）。ソファ、テレビ台、東壁の棚の上の留守番電話（赤いランプ）、壁の家族写真。暖色の室内灯。玄関は手前の壁。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 留守電の1件目を再生する（E）。亡くなった母の声「ちゃんとご飯食べてる？」。 |
| 1:00〜3:00 | 異変①壁の家族写真から水が滴る、顔の部分が濡れている（1:20）②2件目を再生（E）。「今、あなたの部屋の前にいるんだけど……」③玄関の前で足音が止まり、ドアを叩く音（2:30）。 |
| 3:00〜4:00 | 玄関のドアが開いて閉まり、電気が消えて留守電の赤いランプだけが光る（3:25、または2件目の約30秒後）。 |
| 4:00〜5:00 | 3件目を再生する（E）。「……おかえり。いま、あなたの後ろにいるよ」と録音と背後から同じ声。**約2.6秒後**、背後の何かが目の前に現れる（ジャンプスケア）。再生しなくても290秒で自動的に。 |

時間切れ救済: プレイ開始290秒（演出）／330秒（強制）でジャンプスケア → エンディング。

## 主な演出

- 3つの再生ボタンを順番に押す能動的な進行（`interact` を `requires` でつなぐ）
- 声を字幕で見せ、足音・ノック・息づかいの音で背後の気配を表現
- 手続き音：チャイム、ノイズ、水滴、足音、ノック、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 留守電のボタンを押す（1→2→3件目の順）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、会社に来ない社員を心配した同僚が部屋を訪ねると、鍵は内側から閉まっていた。留守番電話には『3件』の表示が残り、再生すると、聞き覚えのある声で最後にこう録音されていたという。『ただいま』」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
