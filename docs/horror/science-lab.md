# 理科室の標本（science-lab）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

理科室の標本

## 一行ピッチ

夜の理科室に忘れ物のノートを取りに入ると、標本瓶の目が開き、骨格標本が教卓へ近づき、棚の大きな瓶の中で何かが動く。

## 舞台

夜の校舎の理科室（10m × 14m、天井高3.2m）。2列の実験台、黒板と教卓、東壁の標本棚、隅の人体骨格。月明かりで緑に光る標本瓶、薬品のにおい。出入口は一か所の木の扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 奥の実験台のノートを取る（E）。最後のページに「出席番号 0番　まだ、帰ってない」。 |
| 1:00〜3:00 | 異変①隅の骨格が顎をカタカタ鳴らす（1:10）②標本瓶の目が開く（1:50）③誰も触っていないガスバーナーが青く燃える（2:30）④明滅のたびに骨格が教卓の前まで来る（3:05）。 |
| 3:00〜4:00 | 出入口の扉が閉まって開かず、照明が消える（3:25）。骨格は消え、棚の大きな瓶の中で何かが動く。 |
| 4:00〜5:00 | 大きな標本瓶をのぞく（E）と、瓶が割れて中身が飛び出す（ジャンプスケア）。のぞかなくても約55秒後に。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 標本瓶の目は2枚の看板を `visible` で切り替え
- 骨格標本は `visible` と `move` で台から降りて近づく
- 青いガスバーナーの炎は点光源で表現
- 手続き音：骨のカタカタ（rattle）、ささやき、ノイズ、打撃音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ノート・標本瓶）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、理科の教師は、標本棚の大きな瓶が割れて液体が床に広がっているのを見つけた。瓶のラベルには『出席番号 0番』とだけあり、中身は何だったのか、誰も覚えていない。濡れた足跡は、廊下の奥へ続いていたという。」と表示して終了。

- 共通土台は `kit/` を同梱（自己完結）
