# 出席番号13番（shoe-lockers）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

出席番号13番

## 一行ピッチ

忘れ物を取りに夜の昇降口へ入ると、自分の下駄箱の中に、知らない誰かの上履きが濡れて入っていた。

## 舞台

夜の学校の昇降口（約8m × 14m）。入口の扉、並ぶ下駄箱、13番の下駄箱、校内放送の機器。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の昇降口。自分の13番を開ける（濡れた上履き）。 |
| 1:00〜3:00 | 異変①校内放送「13番、まだ帰っていませんね」（1:10）②下駄箱を内側から叩く音（2:00）③「出して」の声（2:45）。 |
| 3:00〜4:00 | 扉が閉まり消灯（3:25）。列の奥に人影、背後に足音。 |
| 4:00〜5:00 | 13番を閉めようとすると人影が目の前に現れる（ジャンプスケア）。触らなくても330秒で発生。 |

## 主な演出

- 蛍光灯→消灯、扉の slam / lock
- 内側から叩かれる下駄箱、列の奥の人影
- 手続き音：ブザー、ノック、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝、13番の下駄箱には自分の上履きだけが揃えて入っている。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。
