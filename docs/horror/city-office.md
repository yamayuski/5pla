# 47番でお待ちの方（city-office）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

47番でお待ちの方

## 一行ピッチ

夜間受付の市役所で番号札を取ると、誰もいない待合に呼び出しだけが進み、ついに「47番」が呼ばれる。

## 舞台

市役所の夜間窓口ホール（12m × 14m、天井高3.2m）。蛍光灯、待合の椅子、奥にカウンターと3つの窓口、その上に電光掲示。入口は自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 発券機で番号札「47番」を取る（E）。前に46人も待っているはずなのに、ホールには誰もいない。 |
| 1:00〜3:00 | 異変①「43番の方、1番窓口へ」誰も立たない（1:10）②待合の椅子が順番に軋む（1:50）③「46番の方、2番窓口へ」背後で小さな「はい」（2:30）④3番窓口に灯りがつき、うつむいた職員が書き続けている（3:05）。 |
| 3:00〜4:00 | 「47番の方、3番窓口へ」。入口の自動ドアが閉まって開かず、照明が落ちて3番窓口だけが明るい（3:25）。 |
| 4:00〜5:00 | 3番窓口へ番号札を出す（E）と、職員が顔を上げて目の前に現れる（ジャンプスケア）。出さなくても約55秒後に。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 呼び出し表示は複数の看板を `visible` で切り替える
- 待合の椅子のきしみ、背後の返事、窓口の灯りで「見えない人の列」を表現
- 手続き音：呼び出しチャイム、きしみ、ささやき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（発券機・3番窓口）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、窓口の職員が番号札の発券機を開けると、47番の札だけが一枚、消えていた。夜間受付の記録に、来庁者は一人も残っていない。待合の47番の席に、まだ温もりが残っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
