# 閉館後のリンク（ice-rink）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉館後のリンク

## 一行ピッチ

閉館後のスケートリンクで、氷の奥から回り続ける人影が、照明が明滅するたびに少しずつ近づいてくる。

## 舞台

郊外のスケート場（18m × 26m、天井高7m）。手前がロビー（貸し靴の棚と鍵箱）、フェンスの奥が鏡のような氷のリンク。奥に整氷車。冷たい青白い照明と白い息。出口はガラスの自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 閉館後のロビーで貸し靴の鍵箱を戻す（E）。鍵が一本足りない。貸し出し帳の最後に「24番」。 |
| 1:00〜3:00 | 異変①オルゴール調のBGMが鳴り、リンクの一番奥で誰かが回っている（1:10）②照明が瞬き、人影がさっきより近い（1:50）③整氷車が運転手もいないのにひとりでに走りだす（2:30）④もう一度明滅し、氷を滑る刃の音がすぐそこで聞こえる（3:05）。 |
| 3:00〜4:00 | 出口の自動ドアが閉まって開かず、リンクの照明が全て落ちる（3:25）。回る人影だけがぼうっと白く、フェンスのすぐ向こうまで滑ってくる。 |
| 4:00〜5:00 | 回転がぴたりと止み、女がこちらを向いて立っている（3:37）。**見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- スケーターを `update` フックで回転させ続け、`move` で氷の上を滑らせて近づける（明滅と同期）
- 整氷車を TransformNode ごと `move` で走らせ、ヘッドライト（点光源）を点灯
- 回転が止まる瞬間の静寂（回転を止めて `face` でこちらへ向ける）
- 手続き音：オルゴール調のチャイム、ノイズ、重低音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（鍵箱）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、整氷車で氷を削っていた職員は、リンクの中央にくっきりと残る円形の跡に気づいた。何度削っても、その跡だけは消えなかったという。貸し靴の24番は、いまも戻っていない。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。スケーターの回転だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
