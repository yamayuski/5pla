# 釣瓶（old-well）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

釣瓶

## 一行ピッチ

夏休みの夜、祖父母の家の裏の古井戸へ水を汲みに行くだけ。なのに釣瓶の縄が井戸の底へ引き込まれ、井戸から勝手口まで濡れた裸足の足跡が続いていく。

## 舞台

田舎の祖父母の家の裏庭（屋外、16m × 16m）。南が母屋の裏壁と勝手口（軒下に裸電球）、中央に滑車付きの苔むした古井戸、西に柿の木、東に物置と物干し、周囲は生け垣。月明かりと霧。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 虫の声の夏の夜。勝手口から出て、井戸で釣瓶を引き上げる（E）。水に髪の毛が一本。何もしなくても50秒で釣瓶がひとりでに上がる。 |
| 1:00〜3:00 | 異変①虫の声が一斉に止み、井戸の底で水の跳ねる音（1:15）②釣瓶の縄が「がらがら」と井戸の中へ一気に引き込まれる（2:00）③井戸から勝手口まで、濡れた裸足の足跡が現れる（2:40）。 |
| 3:00〜4:00 | 勝手口が内側から閉められて鍵が掛かり、家の窓の灯りも消える（3:25）。軒下の電球も消え、霧が濃くなりライトが弱まる。井戸の底から自分の名前を呼ぶ声。 |
| 4:00〜5:00 | 井戸を覗き込む（E）と、水面から濡れた黒髪がゆっくり上がってくる。**それを見た瞬間**、目の前に飛び出す（ジャンプスケア）。覗かなくても消灯から約35秒で井戸の縁に手が掛かり、這い上がってくる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 唯一の安全地帯（家）を背に始め、そこから締め出される構成
- 釣瓶の上下（フック `bucketUp` / `bucketDrop`、縄の長さも変化）
- 足跡は TransformNode でまとめて一度に出現
- 勝手口の slam → lock、窓の灯りが消える、霧の濃度上昇とライトの減光
- 虫の声（ドローン）が止む「無音」の演出、水滴、ささやき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（井戸）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、祖母は裏庭の井戸に蓋をし、石を三つ載せた。『あの井戸はね、昔、汲みに行った子が一人帰ってこなかったの』。足跡は、勝手口の中まで続いていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。井戸の娘は井戸の中（y<0）に隠し、move で縁まで上げる
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
