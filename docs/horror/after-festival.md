# 宵宮のあと（after-festival）

## タイトル
宵宮のあと

## 一行ピッチ
夏祭りが終わった夜の神社に、落とした財布を探しに戻る。提灯が、ひとつずつ消えていく。

## 舞台
山あいの小さな神社の境内（屋外）。南の朱い鳥居から北の拝殿まで石畳の参道、両脇に提灯の列と片付け途中の屋台（やきそば・金魚すくい・お面・りんご飴・射的）、まわりは杉林。拝殿の前に賽銭箱と鈴。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 虫の声、片付け途中の屋台。提灯の灯る参道を拝殿まで歩き、賽銭箱の脇で財布を見つける（interact）。中身は無事――なのに小銭入れが濡れている。 |
| 1〜3分 | 小さな異変：①誰もいないのに祭囃子がかすかに聞こえる（1:02）②西側の提灯が手前から順にふっ、ふっと消えていく（1:38）③お面屋の狐面がひとつ足りず、空いた釘の下で子どもが笑う（お面屋を見たとき）④拝殿の鈴がひとりでに鳴る（2:45）。 |
| 3〜4分 | 逃げ道が塞がる：提灯がすべて消え、霧が濃くなり、鳥居にさっきまで無かったしめ縄が張られてくぐれない（3:20）。拝殿の中から子どもの声「……おいで。お面、かぶせてあげる」。 |
| 4〜5分 | 拝殿に近づく（zone）→ 鈴が鳴り、格子戸が内側からゆっくり開く。奥は真っ暗 → 狐面の女が目の前に（大ジャンプスケア）→ エンディング。5:20 の保険つき。 |

## 主な演出
- 屋外の広い暗闇（杉林・霧・月明かり）と、提灯の暖色の明かりの対比
- 提灯が順番に消えていく（custom フックで glow メッシュを時間差で消す）
- 「ひとつ足りない狐面」を見せておき、最後にそれをかぶった人影で回収
- 鳥居にしめ縄（結界）が現れて帰れなくなる、という和風の閉じ込め
- 手続き的な音：虫の声代わりのドローン、祭囃子（鈴・チャイム）、子どもの笑い声、鈴、ノック、囁き、心音

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる（財布）、F：ライト

## エンディング
「翌年の夏祭り。お面屋の狐面は、ひとつ増えていた。その面だけ、裏側がいつも少し湿っている。釘の下で、今年も誰かが笑っている。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after / zone、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。提灯の順次消灯としめ縄の出現だけ `custom` フック。狐面は figure の子メッシュとして追加
- 共通土台は `kit/` を同梱（自己完結）
