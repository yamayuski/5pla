# C-15 空室（net-cafe）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

C-15 空室

## 一行ピッチ

終電を逃して入ったネットカフェ。隣の C-15 は空室のはずなのに、仕切りを叩く音がして、PCに C-15 からメッセージが届く。

## 舞台

駅前のネットカフェのブース列（8m × 14m）。高さ1.9mの仕切りで区切られた個室が通路の両側に並ぶ。自分の席は東側の C-14（机・PC・リクライニングチェア）、隣が「空室」の C-15。南端に受付への出口、北端にドリンクバー。照明は落とし気味の通路灯と机のスタンドだけ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 空調といびきの聞こえる静かなブース。PCを点ける（E）とログイン画面。何もしなくても40秒でひとりでに起動する。 |
| 1:00〜3:00 | 異変①空室の C-15 側の仕切りを「コン、コン、コン」と叩く音（1:15）②PCに C-15 からメッセージ「となり、いますよね」（2:00）③ドリンクバーが勝手に注ぎ出し、通路を黒い人影が歩いていく（2:40）。 |
| 3:00〜4:00 | 出口の扉が閉まり電子錠がかかる（3:25）。停電して非常灯の赤だけになり、スマホのライトが点く。画面に新着メッセージが一つ。 |
| 4:00〜5:00 | メッセージを開く（E）と「うえ」。頭上の仕切りの向こうで笑い声、仕切りの縁から顔が覗いている。**見上げた瞬間**、目の前に飛び出す（ジャンプスケア）。開かなくても停電から約35秒で笑い声と顔が現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 仕切りで視界が狭く、背の高い壁の「向こう側」の気配だけで怖がらせる
- PC画面（DynamicTexture）の段階変化：起動 → C-15 からのチャット → 停電後の「うえ」
- 通路を横切る人影（move）とドリンクバーの作動音
- 出口の slam → lock、停電で非常灯（赤）に切り替え
- 手続き音：ノック、チャイム、足音、ノイズ、くすくす笑い、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（PC）、F: ライト（停電後に自動で点く）
- ヘッドホン推奨

## エンディング

「朝、清掃に入った店員は C-14 の伝票を見つけた。席には誰もいなかった。C-15 は三年前から使われていない。仕切りの上の縁にだけ、指の跡が並んでいる。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。他のブースは半透明の仕切り幕で塞ぎ、自分の席と通路だけ歩ける
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
