# 来室記録（school-nurse）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

来室記録

## 一行ピッチ

宿直の見回りで入った夜の保健室。揺れるカーテン、薬品棚の陰の体操服の子、新しい掲示のあと戸が閉まり、来室記録に自分の名前が書かれている。

## 舞台

夜の学校の保健室（約6m × 8m）。奥に机とベッド、西に薬品棚、東壁に掲示。入口は南の引き戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 消毒液の匂いの保健室を確認する。50秒でカーテンがひとりでに揺れる。 |
| 1:00〜3:00 | 異変①薬品棚の陰に体操服の子、目を逸らすと消える（1:35）②「本日の来室者：1名（まだ帰っていません）」の掲示（2:30）③校内チャイムが一度鳴る（3:10）。 |
| 3:00〜4:00 | 戸が閉まりロック、蛍光灯が落ち（3:35）、机のスタンドだけが残る。来室記録がめくれている。 |
| 4:00〜5:00 | 来室記録を見る（E）と最後の行に自分の名前。顔を上げるとベッドに生徒が座っており、ジャンプスケア。見なくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 揺れるカーテン、チャイム、背後の気配、閉ざされる戸
- lookAway で消える人影、増える掲示

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（来室記録）、F: ライト

## エンディング

「翌朝、保健の先生は来室記録の最後の行に、宿直の名前を見つけた。『帰宅：なし』。ベッドのカーテンは、一台だけ閉まっていた。」

## 実装メモ

- カーテンの揺れは custom フック curtainSway。掲示は visible で出す。
