# 録り直し（sound-booth）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

録り直し

## 一行ピッチ

夜のスタジオでナレーションの録り直し。再生すると、自分の声の後ろに別の声が重なっている。ブースの扉の奥に。

## 舞台

夜のレコーディングスタジオ（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 原稿を読んで録り直す。 |
| 1:00〜3:00 | 異変①譜面台が倒れる（1:10）②照明が瞬き足音が止まる（2:00）③ガラスの陰にヘッドホンの人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。続きの声はブースの中から聞こえる。開けるしかない。 |
| 4:00〜5:00 | ブースの扉を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 声の重なり、ノイズ、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ブースの扉を開ける）、F: ライト

## エンディング

翌朝、ミキサーは録音データに数分の無音を見つけた。 その最後に、小さく「録り直し」と、あなたの声が入っていた。
