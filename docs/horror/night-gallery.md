# 閉館後の美術館（night-gallery）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉館後の美術館

## 一行ピッチ

閉館後の美術館の長い展示室で、肖像画の目が開き、石像が近づき、最後に突き当たりの「婦人像」の額縁が空になる。

## 舞台

美術館の第一展示室（10m × 26m、天井高4m）。深紅の壁に金の額縁の肖像画が並び、中央に石像。入口は自動ドア。暖色の薄暗い照明。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 夜間警備のアルバイトとして受付パネルで巡回を記録する（E）。静かな展示室を奥へ歩く。 |
| 1:00〜3:00 | 異変①肖像画の目が開いてこちらを見ている（1:10）②背後で額縁が落ちて割れ、壁には何も残っていない（1:50）③右奥の台座に見覚えのない石像（2:30）④明滅のたびに石像が降りて近づく（3:05）。 |
| 3:00〜4:00 | 入口の自動ドアが閉まって開かず、照明が落ちる（3:25）。石像は消えている。 |
| 4:00〜5:00 | 奥へ進むと突き当たりの「婦人像」の額縁が空になる。**見た瞬間**（または約45秒後）、婦人が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 肖像画は2枚の看板を `visible` で入れ替えて目が開いたように見せる
- 石像は `move` と照明の明滅の同期で近づき、暗転で姿を消す
- 空になる額縁は look 判定のターゲットとして使い、見た瞬間に反応する
- 手続き音：ささやき、鈍い落下音、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（受付パネル）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、学芸員が最奥の『婦人像』を見上げて首をかしげた。絵の中の婦人は、昨日までと違い、こちらをまっすぐ見ていたという。夜間警備のアルバイトは、その日から来ていない。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
