# 507号室（danchi-507）

## タイトル
507号室

## 一行ピッチ
深夜、団地の五階の自宅に帰ってきた。ひとり暮らしの部屋に、内側からチェーンがかかっている。

## 舞台
古い団地の五階の外廊下。西端に階段室（エレベーターは点検中）、南側に 501〜507 号室の鉄の玄関ドアが並び、北側は腰までの手すりの向こうに夜の向かいの棟と街灯。突き当たりの 507 号室が自宅。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | どこかのテレビの音、遠くの犬。外廊下を突き当たりの 507 まで歩き、鍵を開ける――鍵は回るのに、数センチで止まる。中からチェーンがかかっている。 |
| 1〜3分 | 小さな異変：①蛍光灯が瞬き、テレビの音が止む（1:02）②503 の新聞受けが内側から押し開けられ、息づかい（1:40）③誰もいない 505 の前でインターホンが鳴る（2:18）④三輪車のあたりで子どもの笑い声（2:48）。 |
| 3〜4分 | 逃げ道が塞がる：階段室の鉄扉が閉まり開かなくなり、手前の照明が落ちる（3:20）。8 秒後、突き当たりでチェーンの外れる音がして 507 のドアがゆっくり開く。 |
| 4〜5分 | 507 から髪の長い女が出てきて、廊下をゆっくり歩いてくる（接近型）。照明が一つずつ消え、足音が近づく。3m 以内で女を見る、または歩き切った瞬間に目の前へ（大ジャンプスケア）→ エンディング。5:20 の保険つき。 |

## 主な演出
- 一直線の外廊下という「隠れる場所の無い」舞台。手すりの外は高さのある夜景（落ちられない）
- 自宅に入れない → 自宅から何かが出てくる、の反転
- 最後は逃げ場の無い接近型（52 秒かけて歩いてくる女。見ても見なくても来る）
- 手続き的な音：テレビの気配、蛍光灯のうなり、新聞受け、インターホン、子どもの笑い声、鉄扉、チェーン、足音、心音

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる（507 のドア）、F：ライト

## エンディング
「管理人の記録では、507 号室は三年前から空き部屋になっている。郵便受けには今も、あなたの名前の郵便物が届き続けている。内側から、チェーンをかけたまま。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / interact / after / look、requires / unless で 3 系統のジャンプスケアを排他）
- `level.ts` は MeshBuilder のプリミティブのみ。custom フックなし（女の接近は move アクションのみ）
- 共通土台は `kit/` を同梱（自己完結）
