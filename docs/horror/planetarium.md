# 閉館後のプラネタリウム（planetarium）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉館後のプラネタリウム

## 一行ピッチ

閉館後のドームで投影機を点検していると、天井の星が目と口の形に並び、しだいに巨大な顔になって見下ろしてくる。

## 舞台

プラネタリウムのドーム（10m × 14m、天井高4m）。3列の客席、中央奥に黒い投影機。天井一面に投影される星空だけが主な光源。出入口は重い防音扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 奥の投影機を起動する（E）。星空が灯り、点検は異常なし。（起動しなくても45秒で自動起動） |
| 1:00〜3:00 | 異変①無人の客席で座席が軋む（1:15）②星の並びが変わり、二つの目と口のように並ぶ（2:00）③投影機の頭が勢いよく回りだす（2:45）④客席の通路を足音が降りてくる（3:10）。 |
| 3:00〜4:00 | 出入口の扉が閉まって開かず、客席の灯りが消える（3:25）。星空だけがドームを照らす。 |
| 4:00〜5:00 | 星の顔が巨大な赤い目に変わる（3:31）。**天井を見上げた瞬間**（または約14秒後）、顔の主が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 天井の星空は水平に置いた看板3枚（通常→顔→巨大な顔）を `visible` で切り替える
- 投影機の頭は `update` フックで回転（ゆっくり→激しく）
- 「見上げる」という視線誘導を look 判定のターゲット（天井板）として使う
- 手続き音：チャイム、きしみ、ささやき、重低音、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック。上を向くには視点を上げる）
- E / クリック: 調べる（投影機）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、解説員が客席を整えていると、前から三列目の座席が一つだけ下りたままになっていた。座面はなぜか温かく、星空の記録映像には、天井を見上げる観客が一人だけ多く映っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。投影機の回転だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
