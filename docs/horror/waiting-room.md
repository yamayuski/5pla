# 夜間救急の待合室（waiting-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

夜間救急の待合室

## 一行ピッチ

付き添いで来た夜間救急の待合室。揺れる蛍光灯、長椅子の端の小さな人影、見覚えのない呼出番号のあと、戸が閉まり、発券機が点滅しはじめる。

## 舞台

夜間救急の待合室（約6m × 8m）。両側に長椅子、奥に受付と発券機、西壁に呼出表示。入口は南の戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 受付が無人の待合室で待つ。50秒で蛍光灯が勝手に揺れる。 |
| 1:00〜3:00 | 異変①長椅子の端に小さな人影、目を逸らすと消える（1:35）②呼出表示に「あなた」（2:30）③院内放送が一度だけ鳴る（3:10）。 |
| 3:00〜4:00 | 戸が閉まりロック、待合室の明かりが落ち（3:35）、発券機だけが緑に点滅する。 |
| 4:00〜5:00 | 番号札を取る（E）と「000番　あなた」。顔を上げると受付の奥に患者が立っており、ジャンプスケア。取らなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- サイレン・院内放送・背後の気配、閉ざされる戸
- lookAway で消える人影、呼出表示の異変

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（発券機）、F: ライト

## エンディング

「翌朝、交代の看護師が受付で見つけたのは、一枚の番号札だった。『000番　あなた』。診察記録には、昨夜の付き添いの名前が一件増えていた。」

## 実装メモ

- 蛍光灯の揺れは custom フック lampSwing。呼出表示は visible で出す。
