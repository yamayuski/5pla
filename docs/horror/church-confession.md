# 懺悔室（church-confession）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

懺悔室

## 一行ピッチ

夜の教会で鍵を預かった。誰もいない懺悔室の格子の向こうから、懺悔が聞こえてくる。その扉を開けると。

## 舞台

夜の古い教会の礼拝堂（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 誰もいない礼拝堂を戸締まり確認して回る。 |
| 1:00〜3:00 | 異変①懺悔室からささやき声（1:10）②照明が瞬き足音が止まる（2:00）③祭壇の前に祈る黒い人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。懺悔室の声は「次の方」と呼ぶ。扉を開けるしかない。 |
| 4:00〜5:00 | 懺悔室の扉を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 蝋燭、ささやき、石の反響、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（懺悔室の扉を開ける）、F: ライト

## エンディング

翌朝、神父は懺悔室の記録帳を開いた。 昨夜の最後の告白者の欄に、あなたの名前と、まだ犯していない罪が書かれていた。
