# 蛍の光が止まるまで（dept-closing）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

蛍の光が止まるまで

## 一行ピッチ

閉店後の百貨店の屋上階。迷子の放送が流れるはずのない時間に流れ、従業員用扉の向こうで子供の声がする。

## 舞台

百貨店の屋上遊園フロア（約8m × 16m）。入口に防火シャッター、中央にワゴンと遊具、奥に従業員用扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍の光が流れる屋上。ワゴンの迷子札を見る（40秒で自動で気づく）。 |
| 1:00〜3:00 | 異変①音楽が伸びていく（1:15）②動かない遊具に小さな影（2:05）③館内放送「お連れ様がお待ちです」（2:50）。 |
| 3:00〜4:00 | 入口の防火シャッターが降り消灯（3:25）。残る出口は奥の従業員用扉のみ。 |
| 4:00〜5:00 | 扉を開けると、向こうに立つ人影がジャンプスケア。開けなくても330秒で発生。 |

## 主な演出

- 照明の消灯、シャッターの slam / lock、懐中電灯
- 遊具の影、館内放送のささやき、扉のきしみ
- 手続き音：ブザー、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

迷子札に「みつかりました」と書き足され、名簿に名前が一人分増える。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。interact(扉)→after 型の結末。
