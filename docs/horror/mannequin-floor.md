# マネキンは動かない（mannequin-floor）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

マネキンは動かない

## 一行ピッチ

閉店後の百貨店で忘れ物を探すあいだ、背を向けて立つマネキンが、振り向くたび通路の近くに寄ってくる。

## 舞台

閉店後の百貨店・婦人服フロア（10m × 10m）。南にシャッター扉、洋服ラック、背を向けたマネキン4体、奥にレジ台と裏口ボタン。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 非常灯だけの売り場に入る。マネキンは全員こちらに背を向けている。蛍光灯のうなりが続く。 |
| 1:00〜3:00 | 異変①右手前のマネキンがこちらを向く（1:15）②左手前のマネキンが通路に近づく（2:00）③レジ台の電話が鳴り「……みつけた」（2:40）。 |
| 3:00〜4:00 | シャッターが落ちて閉じ込められ、入口に五体目のマネキン（3:20）。照明が落ち、通路脇のマネキンが寄ってくる（3:32）。レジ台の裏口ボタンを押すしかない。 |
| 4:00〜5:00 | ボタンを押して3秒後、背後に回り込んだ何かが目の前に飛び出す（ジャンプスケア）。押さなくても320秒で強制発生。 |

## 主な演出

- 目を離すと位置が変わるマネキン（顔なしの白い人形）
- シャッターのslam＋lock、照明の段階的な消灯、フォグ濃度上昇
- 手続き音：蛍光灯のうなり、軋み、電話、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、売り場には五体目のマネキンが増えていた。誰も搬入した覚えはなく、顔だけが、あの夜の店員に似ていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーをデータで記述（time / interact / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ
- 共通土台は `kit/` を同梱（自己完結）
