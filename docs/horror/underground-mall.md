# 地下街の閉店（underground-mall）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

地下街の閉店

## 一行ピッチ

終電間際の地下街。閉店のアナウンスの中、ショーケースのマネキンが、蛍光灯が瞬くたびに一体ずつ消えて、通路の先に立っている。

## 舞台

地下街の長い一本道（幅6m × 長さ44m、天井高3.2m）。西側にショーケース4つとマネキン、東側は閉店のシャッター、突き当たりが地上への出口階段。蛍光灯のみの冷たい白い光、床のタイルと自分の足音。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 出口の階段を目指して歩く。ショーケースのマネキンは通路のほうを向いて並んでいる。閉店のアナウンス。 |
| 1:00〜3:00 | 異変①手前の二体が首をひねってこちらを向く（1:15）②蛍光灯が瞬くと二番目のケースが空になり、通路の先に立っている（1:55）③再び瞬いて三体目が消え、先に立つ二体は全員こちらを向く（2:35）。 |
| 3:00〜4:00 | 出口のシャッターが降り、蛍光灯が全て落ちる。非常口の緑だけが光る（3:25）。通路の闇の奥から、四体目のマネキンが関節を鳴らして一歩ずつ歩いてくる（3:31〜）。 |
| 4:00〜5:00 | マネキンがすぐ近くまで迫る（約4:07）。**見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- ショーケースのマネキンを Figure で配置し、蛍光灯の明滅（flicker）に合わせて通路の先へ瞬間移動させる
- 出口のシャッターを `move` で降ろし、衝撃音と揺れで退路を断つ
- 蛍光灯グループの一斉消灯と、非常口の緑だけが残る暗転
- 手続き音：アナウンスのチャイム、ノイズ、足音、関節の軋み、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨
