# ゴミ出しの夜（trash-station）

## タイトル
ゴミ出しの夜

## 一行ピッチ
午前二時、出し忘れたゴミ袋を持ってマンションのゴミ置き場へ。袋の数が、さっきより増えている。

## 舞台
屋根付きの小さなゴミ置き場。蛍光灯、黒い袋、奥の大きな収集箱、入口の降りるシャッター。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 蛍光灯の唸りの中、奥の収集箱の蓋を開ける（interact）。中は空で、背後で袋の擦れる音。 |
| 1〜3分 | 小さな異変：袋を叩く音、収集車のクラクション、背後の足音、蛍光灯が一本消える。 |
| 3〜4分 | 入口のシャッターが降りて閉じ込められる。ライトが弱まり照明が落ちる。 |
| 4〜5分 | 完全な暗闇 → 袋を叩く音が近づき耳元で息 → 黒い人影が目の前に（大ジャンプスケア）→ エンディング。 |

## 主な演出
- 蛍光灯の明滅、シャッターで逃げ道を断つ、暗闇での音の接近

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる、F：ライト

## エンディング
袋は一つ多い。数えた住人は翌朝、収集箱の中。
