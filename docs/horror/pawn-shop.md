# 質草（pawn-shop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

質草

## 一行ピッチ

閉店後の質屋で在庫の棚卸し。質札の番号に、自分の名前を見つけた。奥の金庫を開けた先に。

## 舞台

閉店後の質屋（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ガラスケースの質札を台帳と照合していく。 |
| 1:00〜3:00 | 異変①腕時計がすべて同じ時刻で止まる（1:10）②照明が瞬き足音が止まる（2:00）③カウンターの奥に前の店主の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。台帳は最後の質草として金庫を指している。開けるしかない。 |
| 4:00〜5:00 | 金庫を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 時計の音、金庫のダイヤル、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（金庫を開ける）、F: ライト

## エンディング

翌朝、店主は台帳の最後に新しい一行を見つけた。 「質草：一名。流れ期限なし」。金庫の中の質札には、あなたの名前が書かれていた。
