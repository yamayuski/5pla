# 開かずの踏切（rail-crossing）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

開かずの踏切

## 一行ピッチ

電車が来ないのに警報が鳴り、後ろで誰かが数を数える。非常停止ボタンを押した瞬間、線路の真ん中に女の子が立っている。

## 舞台

終電後の田舎の踏切（約20m × 24m）。東西に走る線路、南北の警報機と遮断機、北の帰り道へ出る柵扉、押しボタン。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 虫の声だけの静かな踏切。北の道を目指す。 |
| 1:00〜3:00 | 異変①電車が来ないのに警報が鳴り遮断機が降りる（0:55）②線路の遠くに白い服の人影が一瞬（1:45）③警報が止み、背後で数を数える声（2:30）。 |
| 3:00〜4:00 | 北の柵扉が閉まってロック（3:15）、街灯が消え警報の赤だけが残る。非常停止ボタンを押すしかない。 |
| 4:00〜5:00 | ボタンを押すと、線路の真ん中に女の子が現れ、見た瞬間に迫る（ジャンプスケア）。押さなくても約35秒で現れる。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 警報灯の赤、遮断機の上下、街灯の消灯、霧の濃度上昇
- 数を数える声（ささやき音）が少しずつ近づく
- 手続き音：警報ブザー、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（非常停止ボタン）、F: ライト

## エンディング

翌朝、踏切脇に懐中電灯。警報機のカウンターは一晩で「10」を示していた。

## 実装メモ

packages/games/src/horror/rail-crossing/{config,level,index}.ts。遮断機は中心回転の簡易表現。
