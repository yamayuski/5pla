# 閉店後の美容室（hair-salon）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉店後の美容室

## 一行ピッチ

最後の一人として店を閉める夜、電気を消した美容室のシャンプー台に、予約のない客が寝かされていた。

## 舞台

駅前の小さな美容室（8m × 10m、天井高3m）。西の壁一面に鏡とスタイリングチェア3脚、北にシャンプー台2台、入口のそばにレジと照明スイッチ。ネオンの「営業終了」と外の街灯が頼り。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 閉店作業。レジを締め（E）、照明のスイッチを切る（E）。電気を消すとネオンの赤と街灯だけが残る（何もしなくても1:15に自動で消灯）。 |
| 1:00〜3:00 | 異変①誰も座っていない手前のスタイリングチェアが勝手に回り、こちらを向く（1:35）②コンセントを抜いたドライヤーが唸る（2:15）③奥のシャンプー台から水音。顔にタオルをかけられた客が寝ている（2:50）。 |
| 3:00〜4:00 | 入口のガラス戸が閉まって開かず、街灯も消える（3:25）。全チェアが回ってこちらを向き、台から垂れた白い手から水が滴り「……カットは……まだですか……」（3:33）。 |
| 4:00〜5:00 | タオルが落ちて客が起き上がる（3:49）。**その女を見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- スイッチ操作でプレイヤー自身が店の照明を落とす（暗闇の原因を自分で作る導入）
- スタイリングチェアを実際に Y 回転させる（`update` / `custom` フック）
- 寝ている客（TransformNode）→ 起き上がる客（人影）への差し替え
- 手続き音：ドライヤー、水滴、きしみ、ささやき、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（レジ・スイッチ）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、開店準備に来た店長は、シャンプー台がびしょ濡れなのに気づいた。予約表の最後の欄には、鉛筆でこう書かれていた。『23:50 カット・シャンプー　お名前：（空欄）』」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（interact / time / after / look、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。チェアの回転だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
