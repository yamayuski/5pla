# 延長しますか？（karaoke-box）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

延長しますか？

## 一行ピッチ

終電を逃して入った一人カラオケ。壁を叩く隣室、変わるモニターの歌詞、閉まる扉。ソファには、最初から二人目がいた。

## 舞台

カラオケボックスの個室（6m × 7m）。南壁に扉、東西にソファ、中央にテーブルとマイクとリモコン、北壁に大型モニター、天井にミラーボール。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 隣室の歌声が漏れる静かな個室。リモコンで曲を入れる（E）とミラーボールが回る。40秒で自動再生。 |
| 1:00〜3:00 | 異変①隣室の歌声が止み壁を内側から叩く（1:15）②モニターの歌詞が「たすけて／うしろにいる」に（2:05）③マイクからささやき（2:45）。 |
| 3:00〜4:00 | 扉が勝手に閉まりロック（3:25）。照明が赤に変わりライトが弱まる、背後で息づかい（3:35）。マイクを置き直すしかない。 |
| 4:00〜5:00 | 向かいのソファに白い服の女がマイクを握って座っている。**見た瞬間**目の前に現れる。見なくても約35秒で強制発生。 |

時間切れ救済: プレイ開始320秒で強制的にジャンプスケア → エンディング。

## 主な演出

- ミラーボールの紫から非常灯の赤への照明切り替え
- モニター表示の差し替え、扉の slam → lock、フォグ上昇
- 手続き音：ノック、ささやき、ノイズ、息づかい、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（リモコン・マイク）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、清掃の店員は誰もいない個室で、点いたままのモニターを見つけた。予約履歴には、深夜から延長された二名分の入室記録だけが残っていた。」と表示して終了。
