# 延長しますか（karaoke-box）

## タイトル
延長しますか

## 一行ピッチ
終電を逃して入った深夜のカラオケ。ひとりのはずの 7 号室に、入れていないデュエット曲が予約される。

## 舞台
駅前の古いカラオケ店の 7 号室（ソファ・テーブル・リモコン・モニター・ミラーボール・内線電話）と、その前の廊下。廊下の西には「使用中止」の張り紙がされた 6 号室。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 隣の部屋から下手な歌が漏れてくる、いつもの深夜カラオケ。テーブルのリモコンで曲を入れると、モニターにいつもの歌詞が流れる。 |
| 1〜3分 | 小さな異変：①まだ早いのに内線が鳴る。出ると「……お連れ様が、お見えです」（1:10）②ドアのガラスの向こうを白い服の人影がゆっくり横切る（1:52）③隣の歌が止み、壁のすぐ向こうでくすくす笑い（2:20）④入れていない曲『ふたりで（デュエット）』が予約される（2:45）。 |
| 3〜4分 | 逃げ道が塞がる：ドアが勢いよく閉まり鍵がかかる。廊下も部屋も消灯し、モニターの光だけに（3:20）。6 号室側の壁を叩く音、モニターに赤い歌詞「うしろに いるよ ずっと いるよ」が流れ出す。 |
| 4〜5分 | 内線でフロントに電話する（interact）→「……お時間です。延長、しますか」受話器の声がすぐ後ろからも聞こえる → 無音 2.4 秒 → 長い黒髪の女が目の前に（大ジャンプスケア）→ エンディング。5:20 までに電話しなければ保険の一発。 |

## 主な演出
- 明るい個室が少しずつ暗くなり、最後はモニターの青/赤い光だけで見せる
- ガラス窓つきドア越しの「横切る人影」（見えるのは一瞬、視野の端）
- モニターの表示の変化（いつもの歌 → 予約 → 赤い歌詞）で物語を進める
- 手続き的な音：内線の呼び出し音、ノイズ、足音、くすくす笑い、壁を叩く音、囁き、心音
- 最後は「受話器を取る」というプレイヤー自身の行動で一発が来る（ボイスと背後の気配 → 静寂 → 一発）

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる（リモコン・内線電話・ドア）

## エンディング
「翌朝、7 号室の伝票には『2 名様』と印字されていた。店員は誰も、二人目が入るところを見ていない。6 号室は、ずっと前から使われていない。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / interact / after、requires / unless で分岐と保険）
- `level.ts` は MeshBuilder のプリミティブと DynamicTexture の看板のみ。モニター表示は看板の表示切り替え
- 共通土台は `kit/` を同梱（自己完結）
