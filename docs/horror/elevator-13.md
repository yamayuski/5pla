# 十三階（elevator-13）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

残業帰りのエレベーターが、誰も押していない4階に何度も止まり、存在しない13階へ昇っていく。

## 舞台

12階建ての雑居ビル。7階のオフィス、エレベーターホール、北へ伸びる暗い廊下、そして2m四方のエレベーターのかご。
エレベーターは実際には動かさず、扉の開閉・階数表示・ホールの階数表示板・照明・霧を差し替えて「別の階に着いた」ことを演出する。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 残業を終えてオフィスを出る。壁の張り紙「13 のボタンは押さないでください」。エレベーターを呼び、乗って1階を押す。 |
| 1:00〜3:00 | 小さな異変①誰も押していない4階で止まる。扉の外の廊下から足音。②表示が 4→3→4 と戻り、また4階。ホールの電気が消え、廊下の奥に背の高い黒い人影。見つめると明滅とともに一瞬で距離を詰めてくる。③扉が閉まると耳元でささやき。表示が4から上へ上へ――13へ。 |
| 3:00〜4:00 | 13階に到着。かごの照明が落ち、霧に沈んだホールに扉が開く。かごからは出られない。「閉」を押す（放置しても閉まる）と、扉がゆっくり閉まる。 |
| 4:00〜5:00 | かごの明かりが戻り、ほっとした瞬間、かごの中に自分以外の息づかい。振り返る（かごの奥を向く）と人影が目の前に（ジャンプスケア）。振り返らなくても約8秒後に発生。 |

時間切れ救済: 人影を見なくても進行、13階の扉は自動で閉まる、開始330秒で強制ジャンプスケア。

## 主な演出

- 暗闇: 照明グループ（office / hall / corridor / car）を段階的に消す。13階はスマホのライト（減光）のみ。
- 懐中電灯: 13階到着で減光ライト。F でオン/オフ。
- フォグ: 13階で EXP2 フォグを一気に濃くして「別の場所」にする。
- 音（WebAudio 手続き生成）: 到着チャイム、巻き上げ機の低いうなり、廊下の足音、ささやき、息づかい、心音、スティンガー。
- ドア: エレベーター扉（左右スライド）。乗った後は不可視の壁で降りられない＝逃げ道が塞がる。
- 表示: DynamicTexture の階数表示（かご内・ホール）とホールの階数表示板を書き換え。
- 背後の気配: 明かりが戻った直後の息づかい。振り返り判定はかごの奥の壁への視線。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: ボタンを押す
- F: ライトのオン/オフ、Esc: 一時停止
- ヘッドホン推奨

## エンディング

暗転後「翌朝、警備員が止まったままのエレベーターを開けると、中には誰もいなかった。階数表示は、ずっと『13』を示していたという。」

## 実装メモ

- 起動: `/5pla/?horror=elevator-13`
- `config.ts`: 演出トリガーのデータ（各停止・昇降を after 連鎖で記述）。
- `level.ts`: ビルの構築と custom フック（扉の開閉、階数表示のカウント、到着階の書き換え）。
- `kit/`: 一人称ホラー共通土台（作品フォルダ内に同梱）。
- 共有ファイルの変更は `apps/web/src/main.ts` と `packages/games/src/horror/registry.ts` のみ（全ホラー候補 PR で同一内容）。
