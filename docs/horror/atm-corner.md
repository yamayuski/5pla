# 23時58分のATM（atm-corner）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

23時58分のATM

## 一行ピッチ

閉店2分前の無人ATMコーナー。休止中の機械が紙幣を吐き、シャッターが早く下り、警備センターは「そちらに二名映っております」と言う。

## 舞台

寂れた商店街の角にある無人ATMコーナー（5m × 4m）。北壁にATMが3台（右端は「休止中」）、東壁に警備センター直通のインターホン、南面はガラス張りで自動ドア。外は暗い歩道と街灯一本。24時に外側のシャッターが下りる。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の唸りだけの明るい小部屋。左端のATMで入金する（E）。何もしなくても45秒で画面が進む。 |
| 1:00〜3:00 | 異変①誰もいないのに自動ドアが開いてチャイム（1:15）②「休止中」の右端のATMが紙幣を吐き出す音、画面に「残高 0円」（2:00）。このあとガラスの方を見ると、外に白い服の女が一瞬だけ並んでいる③インターホンから「……まだ……ならんで……」（2:45）。 |
| 3:00〜4:00 | 閉店2分前なのにシャッターが下りてきて（3:20）、自動ドアもロック。シャッターが閉まりきると照明が落ち、赤い非常灯とスマホのライトだけになる。インターホンで警備センターを呼ぶしかない。 |
| 4:00〜5:00 | 警備センター「防犯カメラには、そちらに二名映っております。あなたの、すぐうしろに」。3台の画面が赤く「うしろの方も お引き出しですか」。**振り向いた瞬間**、目の前に女（ジャンプスケア）。呼ばなくても消灯から約35秒で画面が変わる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 明るく狭い「安全そうな」小部屋から始め、外の暗闇とガラス一枚で隔てる
- ATM画面（DynamicTexture）の段階変化、休止中の機械が勝手に動く
- 外の人影の一瞬の出現（look → 1.4秒で消える）
- シャッターが下りる（move）＋自動ドアの lock で閉じ込め、照明を赤い非常灯に
- 最後は「振り向き」型（ATMから視線を大きく外した瞬間に lookAway で発火）
- 手続き音：チャイム、紙幣の音（rattle）、ささやき、シャッターの轟音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ATM・インターホン）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / lookAway / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。シャッターは register した box を move で下ろす
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
