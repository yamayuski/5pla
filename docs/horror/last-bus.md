# 終バスの待合所（last-bus）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

終バスの待合所

## 一行ピッチ

終バスを待つ無人の待合所。揺れる蛍光灯、ベンチの端の傘の子、見覚えのない行き先のあと、自動ドアが閉まり、時刻表の「最終」が点滅しはじめる。

## 舞台

郊外のバス停の待合所（約6m × 8m）。両側にベンチ、奥に時刻表、西壁に掲示、入口は南の自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 無人の待合所で終バスを待つ。50秒で蛍光灯が勝手に揺れる。 |
| 1:00〜3:00 | 異変①ベンチの端に傘の子、目を逸らすと消える（1:35）②時刻表に「あなた」行き（2:30）③発車ベルが一度鳴る（3:10）。 |
| 3:00〜4:00 | 自動ドアが閉まりロック、灯りが落ち（3:35）、奥の時刻表だけが点滅する。 |
| 4:00〜5:00 | 時刻表を確かめる（E）と最終便の行き先があなたの名前。振り向くとベンチに白い女が座っており、ジャンプスケア。取らなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 蛍光灯の揺れ、発車ベル、背後の気配、閉ざされるドア
- lookAway で消える人影、時刻表の異変

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（奥の時刻表）、F: ライト

## エンディング

「翌朝、始発の運転手が見つけたのは、ベンチに置かれた折りたたみ傘だった。時刻表の最終便の行き先には、昨夜の乗客の名前が増えていた。」

## 実装メモ

`kamakura` の仕組みを流用し、舞台・文言・オチだけ差し替えた派生。シナリオは設定データ（config.ts）に分離。
