# 閉架書庫（closed-stacks）

## タイトル
閉架書庫

## 一行ピッチ
閉館後の大学図書館の地下で、本を一冊戻すだけのアルバイト。誰もいない書架が、ひとりでに動き出す。

## 舞台
大学図書館の地下・閉架書庫。入口すぐに受付机、奥に手回しハンドル式の移動書架が 5 列と東の壁際の固定書架。書架の間が細い通路で、一番東の通路が分類「913」の棚。その突き当たりに非常口の緑の明かり。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 空調の音と古い紙の匂い。懐中電灯で東端の「913」の通路へ行き、空いた隙間に本を戻す（隙間の奥に目が見えた気がする）。 |
| 1〜3分 | 小さな異変：①西の通路で本が落ちる音（1:06）②誰も触っていない書架のハンドルが回り、書架がわずかに動く（1:44）③受付の机に、さっき戻したはずの赤い本（2:20）④書架の奥から本を音読する声（2:52）。 |
| 3〜4分 | 逃げ道が塞がる：入口の扉が閉まり施錠、照明が落ちる（3:20）。暗闇のあちこちで書架が動き出し、床が揺れる。913 の通路の奥に非常口の明かりが見える。 |
| 4〜5分 | 913 の通路に入る（zone）→ 書架が迫り通路が閉じていく、揺れと轟音、非常口の明かりが消え、耳元で「……しずかに」→ 司書が目の前に（大ジャンプスケア）→ エンディング。5:20 の保険つき。 |

## 主な演出
- 狭い通路が並ぶ書架の圧迫感と、懐中電灯の届かない通路の奥
- 動く書架（TransformNode ごと move）：最初はわずかに、閉じ込め後は複数、最後は自分のいる通路が閉じる
- 「戻したはずの本が戻ってくる」小道具の反復
- 手続き的な音：本の落ちる音、ハンドルのガラガラ、書架の轟音、音読の囁き、扉、心音
- 最後は圧迫型（迫る壁＋揺れ＋囁き → 一発）

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる（本を戻す）、F：ライト

## エンディング
「翌朝、913 の棚に、見覚えのない赤い本が一冊増えていた。奥付の著者名は、あなたの名前だった。貸出記録は、一度も無い。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / interact / after / zone、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。書架は `shelf-<x>` の TransformNode にまとめ、config の move アクションだけで動かす（custom フックなし）
- 書架の移動量は通路幅（約 1.2m 以上）を保つよう小さめ。最後の一回だけプレイヤーの通路を閉じる
- 共通土台は `kit/` を同梱（自己完結）
