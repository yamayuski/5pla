# 最終上映（old-cinema）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最終上映

## 一行ピッチ

閉館する名画座の貸し切り上映。映画が始まると、客席に観客が増え、スクリーンに映ったのは客席にいる自分の後ろ姿だった。

## 舞台

古い名画座の場内（10m × 16m、天井高6m）。中央の通路の左右に3席×5列の赤いベルベットの座席、北の壁にスクリーン、入口の上に映写窓、南にロビー。灯りは非常口の緑とスクリーンの光だけ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ロビーから場内へ。客席の中ほどに進むとブザーが鳴り、灯りが落ちて映写機が回りだす。 |
| 1:00〜3:00 | 異変①前の列に、気配なく客が座っている（1:10）②映像が切り替わり、客席を後ろから撮った映像（1:50）③客席の半分が埋まり、誰も振り向かない（2:30）④画面に通路に立つ自分の後ろ姿が映る（3:00）。 |
| 3:00〜4:00 | 出口の扉が閉まり、鍵が回る。スクリーンに赤い二文字「うしろ」（3:25）。続いて画面が真っ白になり、逆光の中に長い髪の影が立ち、通路を歩いてくる（3:41）。 |
| 4:00〜5:00 | シルエットがゆっくり近づく。**影を見た瞬間**（またはスクリーン真っ白から約27秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- スクリーンは文字板5枚の visible 切り替えだけで「映像」に見せる（題名 → 客席 → 自分 → うしろ → 真っ白）
- 客の影はプリミティブの黒いシルエット。2段階で席が埋まる
- 逆光のシルエットを `move` で通路に沿って接近させる
- 手続き音：ブザー、映写機のノイズ、きしみ、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- ライトなし（スクリーンの光だけ）
- ヘッドホン推奨

## エンディング

「翌朝、取り壊し前の点検で映写室を開けると、映写機にフィルムはかかっていなかった。それなのに、客席の最前列には、人の形に潰れた座席が、びっしりと並んでいたという。」と表示して終了。
