# 占いの館（fortune-house）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

占いの館

## 一行ピッチ

雑居ビルの占いの館。予約表の最後の欄には、自分の名前。水晶玉をのぞくと、未来が映っていた。

## 舞台

雑居ビルの占いの館（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 薄暗い占いの館で掃除をしながら進む。 |
| 1:00〜3:00 | 異変①タロットが一枚落ちる（1:10）②照明が瞬き足音が止まる（2:00）③ヴェールの人が奥の席に座る（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。水晶玉が光り、予約の時間を告げる。のぞくしかない。 |
| 4:00〜5:00 | 水晶玉をのぞくと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 水晶玉の光、線香の煙、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（水晶玉をのぞく）、F: ライト

## エンディング

翌朝、館主が予約表を見て首をかしげた。 昨夜の最後の欄の鑑定結果には、あなたの筆跡で「本日、突き当たりで」とだけ書かれていた。
