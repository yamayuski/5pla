# 最後の客（midnight-taxi-stand）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最後の客

## 一行ピッチ

深夜のタクシー営業所で配車待機。無線から、誰かが住所を告げ続ける。配車表の裏に。

## 舞台

深夜のタクシー営業所（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 配車表を整理する。 |
| 1:00〜3:00 | 異変①鍵束が落ちる（1:10）②照明が瞬き足音が止まる（2:00）③車庫に帽子の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。声は配車表の裏から聞こえる。めくるしかない。 |
| 4:00〜5:00 | 配車表をめくると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 無線ノイズ、ドアの音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（配車表をめくる）、F: ライト

## エンディング

翌朝、配車記録に深夜三時の一件が残っていた。 乗車地は営業所、客の名前はあなただった。
