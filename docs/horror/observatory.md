# 天体観測会（observatory）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

天体観測会

## 一行ピッチ

閉館後の天文台で一人きりの土星観測。静かな望遠鏡が、ひとりでにこちらを向きはじめる。

## 舞台

公立天文台の夜。玄関ホール（4m × 6m）とドーム室（10m × 10m、天井高4.5m）。中央の台座に大型の望遠鏡、西に観測コンソールと星図、赤いライトだけの暗い室内。外は星空で、玄関は外に通じている。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 赤いライトだけの静かなドーム室。望遠鏡の接眼レンズをのぞく（E）と、金色の環を持つ土星が見える。穏やかな時間。 |
| 1:00〜3:00 | 異変①ドームが勝手に回りはじめる（1:15）②ドームの外壁の上を、誰かが歩く足音（1:55）③壁の星図が「うしろ」と赤字の紙に替わっている（2:30）④望遠鏡が勝手に動き、接眼レンズがこちらを向く（3:00）。 |
| 3:00〜4:00 | 玄関の扉が閉まり施錠される（3:25）。ドームの灯りが消え、接眼レンズの奥だけが赤く光る。レンズから囁き「みつけた……そっちから……みて……」。 |
| 4:00〜5:00 | もう一度接眼レンズをのぞく（E）と、レンズの向こうの「目」の持ち主が目の前に飛び出す（ジャンプスケア）。のぞかなくても約28秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 赤いライトのみ（天文台の暗順応）。懐中電灯は赤色
- 望遠鏡のリグ（TransformNode）が実際にプレイヤー方向へゆっくり回転する
- 星図のテクスチャ差し替え、ドーム回転の揺れと重低音、外壁の足音
- 手続き音：ドーム回転の轟音、足音、囁き、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（接眼レンズ）、F: ライト
- ヘッドホン推奨

## エンディング

「観測日誌の最後のページには『土星の環の向こうに、こちらを見ている目があった』とあった。翌朝、望遠鏡は接眼レンズを玄関のほうへ向けたまま、どうしても動かせなかったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。望遠鏡の回転だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
