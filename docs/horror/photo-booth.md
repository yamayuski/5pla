# プリクラ4まい（photo-booth）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

プリクラ4まい

## 一行ピッチ

閉店間際のゲームセンターで、ひとりでプリクラを撮るたびに、写真の自分の背後の「何か」が一枚ごとに近づいてくる。

## 舞台

深夜のゲームセンターのプリクラコーナー（12m × 9m、天井高3m）。ネオンと音楽、手前に筐体、奥に1〜4号機のプリクラ機が横一列に並ぶ。入口は自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 1号機の撮影ボタンを押す（E）。普通に撮れたが、ポーズが「2人用」になっている。 |
| 1:00〜3:00 | 異変①背後で女の子の笑い声（1:15）②2号機で撮ると肩の向こうに白いもの③音声ガイドが勝手に鳴る「つぎは もっと ちかくで とろうね」（2:20）④3号機で撮ると白いものが肩のすぐ後ろ、顔の輪郭が見える。 |
| 3:00〜4:00 | 入口の自動ドアが閉まって開かず、音楽が止まる（3:25、または3枚目の約4秒後）。プリクラ機の中だけが明るい。 |
| 4:00〜5:00 | 4号機の撮影ボタンを押すと（E）、耳元で息を吸う音。**約2.6秒後**、写真の顔が目の前に現れる（ジャンプスケア）。押さなくても285秒で自動的に。 |

時間切れ救済: プレイ開始285秒（演出）／330秒（強制）でジャンプスケア → エンディング。

## 主な演出

- 撮影のたびにプリント（看板）が出力され、写り込む影が近づく
- 1〜4号機を順番に撮る能動的な進行（`interact` を `requires` でつなぐ）
- 手続き音：シャッター音（チャイム）、笑い声、ノイズ、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 撮影ボタンを押す（1号機から順番に）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、店員が1号機から4号機までを点検すると、どの機械にも撮影履歴が残っていなかった。ただ、出力口の下にプリントが4枚きれいに揃って落ちていた。4枚目だけは、どう見ても、こちらが見られている写真だったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
