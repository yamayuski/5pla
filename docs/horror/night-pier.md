# 先客（night-pier）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

先客

## 一行ピッチ

眠れない夜、港の外れの堤防で夜釣り。フードを被った先客が一人、海を向いて座ったまま一度も動かない。ウキは真下へ引き込まれ、背後を濡れた裸足が歩く。

## 舞台

港の外れの堤防（屋外、幅3m × 長さ24m）。両側は夜の海とテトラポッド、先端に赤い灯台、陸側の付け根に階段と街灯一本。自分の竿と電気ウキ、少し先に先客の釣り人。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 波の音と、暗い海に揺れる緑の電気ウキ。竿を手に取る（E）。先客の竿はぴくりとも動かない。何もしなくても45秒で場面が進む。 |
| 1:00〜3:00 | 異変①ウキが沈むが引かない。まっすぐ底へ引き込まれていく（1:15）②背後のコンクリートを濡れた裸足が歩く音。振り向いても濡れた跡しかない（2:00）③先端の灯台の灯りが消え、先客がつぶやく「……まだ、釣れない……ずっと……」（2:45）。 |
| 3:00〜4:00 | 急に潮が満ち、陸へ戻る階段が黒い水の下に沈んで戻れなくなる（3:25）。霧が濃くなり、街灯も消えてヘッドライトだけ。 |
| 4:00〜5:00 | 先客に声をかける（E）と、フードの頭が首だけでゆっくりこちらへ回り、**目の前に迫る**（ジャンプスケア）。声をかけなくても消灯から約35秒で先客が振り向き、それを見た瞬間に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 最初から視界にいて動かない「先客」という持続的な不安（最後に振り向く）
- 電気ウキの浮き沈み（フック `floatSink`）、灯台の点滅と消灯（フック `beaconOff`）
- 屋外なので扉ではなく満ち潮で陸側を塞ぐ（フック `floodIn` で水面と見えない壁を出す）
- 霧の濃度上昇、街灯の消灯とライトの減光
- 手続き音：波（ドローン）、リールの音、濡れた足音、水滴、つぶやき、地鳴り、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（竿・先客）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、堤防には竿が二本、並んで立てかけてあった。地元の釣り人は言う。『あそこには昔から先客がいる。隣に座ると、交代させられるんだ』」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。人影はピック対象外なので、声をかける判定は透明な子メッシュで取る
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
