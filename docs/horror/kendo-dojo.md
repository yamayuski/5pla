# 夜稽古（kendo-dojo）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

夜稽古

## 一行ピッチ

稽古のあとの剣道場で一人、最後の雑巾がけ。誰もいない板の間に摺り足と竹刀の音が響き、名札掛けの最後の札が自分の名前に替わる。

## 舞台

町の剣道場（板張り、10m × 12m、天井3.4m）。北に神棚と灯明、掛け軸「心技体」、北西に太鼓、西に面を被せた防具が5つ並ぶ棚、東に名札掛けと竹刀立て。南に引き戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 汗と木の匂いの残る静かな道場。バケツの雑巾で床を拭き（E）、神棚に一礼。灯明が灯る。何もしなくても45秒でひとりでに灯る。 |
| 1:00〜3:00 | 異変①誰もいない板の間を摺り足の音が横切り、竹刀を打ち合わせる音（1:15）②竹刀が一本倒れ、名札掛けの最後の札が自分の名前に替わっている（2:00）③太鼓が一度だけ「どん」と鳴り、道場の真ん中から低い声「……れい」（2:40）。 |
| 3:00〜4:00 | 引き戸がぴしゃりと閉まり、外から心張り棒を掛ける音（3:25）。照明が落ち、神棚の灯明だけが揺れる。防具棚の面が一つ足りない。 |
| 4:00〜5:00 | 神棚の前で一礼する（E）と灯明が消え、背後の道場の真ん中に誰かが正座している気配。振り返って**防具姿を見た瞬間**、立ち上がって目の前に迫る（ジャンプスケア）。礼をしなくても消灯から約35秒で防具の擦れる音とともに現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 音だけの稽古（摺り足・竹刀・太鼓・号令）で「見えない門下生」を感じさせる
- 名札掛け（DynamicTexture）の札が自分の名前に替わる
- 引き戸の slam → lock、灯明だけの暗闇
- 最後は「礼をして頭を上げると背後に」型。正座の人影（床に沈めて座り姿に見せる）と飛び出し用の立ち姿を分けて使う
- 手続き音：足音、竹刀（knock）、太鼓（thud）、ささやき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（バケツ・神棚）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「朝稽古に来た先生は、道場の真ん中に一つだけ置かれた面を見つけた。名札掛けの一番端には、昔、夜稽古の最中に亡くなった門下生の名が、もう一度掛かっていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。防具は紺の箱と面金の板で表現
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
