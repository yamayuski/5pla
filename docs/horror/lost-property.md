# 預かり品番号000（lost-property）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

預かり品番号000

## 一行ピッチ

駅の遺失物取扱所の夜。受付台に置かれた預かり票には、品名「あなた」。裏口の向こうで袋のこすれる音がする。

## 舞台

駅の遺失物保管庫（約8m × 16m）。入口に窓口シャッター、中央に受付台と棚、奥に裏口。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 受付台の預かり票を見る（40秒で自動で気づく）。 |
| 1:00〜3:00 | 異変①放送が伸びていく（1:15）②棚の傘が倒れる（2:05）③構内放送「お預かりのお客様は窓口へ」（2:50）。 |
| 3:00〜4:00 | 入口のシャッターが降り消灯（3:25）。残る出口は奥の裏口のみ。 |
| 4:00〜5:00 | 裏口を開けると、向こうに立つ人影がジャンプスケア。開けなくても330秒で発生。 |

## 主な演出

- 照明の消灯、シャッターの slam / lock、懐中電灯
- 倒れる傘、構内放送のささやき、扉のきしみ
- 手続き音：ブザー、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

台帳に「お渡し済み」と記され、受取人欄は空白のまま。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。interact(扉)→after 型の結末。
