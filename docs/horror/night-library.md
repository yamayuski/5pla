# 返却期限（night-library）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

返却期限

## 一行ピッチ

閉館後の図書館。返却ポストに本が落ちる音が、何度も何度も聞こえてくる。ポストを開けた先には。

## 舞台

閉館後の市立図書館（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 閉館後の図書館で返却本を書架に戻す。 |
| 1:00〜3:00 | 異変①返却ポストに本が落ちる（1:10）②照明が瞬き足音が止まる（2:00）③書架の隙間から顔（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。残るのはポストの音だけ。中を確かめるしかない。 |
| 4:00〜5:00 | 返却ポストを開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- ページの擦れる音、書架の影、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（返却ポストを開ける）、F: ライト

## エンディング

翌朝、返却ポストの中から一冊の貸出カードが見つかった。 最後の借り手の欄に、あなたの名前と「返却期限：本日」の印があった。
