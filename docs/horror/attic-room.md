# 屋根裏の人形の家（attic-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

屋根裏の人形の家

## 一行ピッチ

祖母の屋根裏で見つけた人形の家には、自分そっくりの小さな人形がいて、その背後に別の人形が一歩ずつ近づいてくる。

## 舞台

祖母の家の屋根裏（8m × 10m、天井高2.8m）。梁、古い行李、揺り椅子、段ボール。奥の台の上に、この屋根裏を写した人形の家。橙の裸電球と埃っぽい空気。入口は階段側の木の扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 手前の古い行李を開ける（E）。底に祖母のメモ「あの家の中を、見てはいけません」。 |
| 1:00〜3:00 | 異変①人形の家の中に、自分と同じ服の小さな人形（1:10）②揺り椅子がひとりでに揺れる（1:50）③人形の家の奥に長い黒髪のもう一体（2:30）④明滅のたびに小さな人形が小さな自分に近づく（3:05）。 |
| 3:00〜4:00 | 階段の扉が閉まって開かず、明かりは人形の家の中だけになる（3:25）。小さな人形が小さな自分の真後ろに立つ。 |
| 4:00〜5:00 | 人形の家をもう一度見た瞬間（または約45秒後）、現実の自分の背後に本物の女が現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 縮小した人影（高さ0.14）を人形の家の中で `move` させ、現実とのリンクを匂わせる
- 揺り椅子は `update` フックで揺らす
- 人形の家の中だけが点く小さな点光源
- 手続き音：きしみ、笑い声、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（行李）、F: ライト
- ヘッドホン推奨

## エンディング

「遺品整理の業者は、屋根裏の台に置かれた人形の家を処分しようとした。中には小さな人形が二体、寄り添うように立っていた。一体は、行方不明の孫によく似た服を着ていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。揺り椅子の揺れだけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
