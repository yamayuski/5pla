# 204号室、在室6名（dorm-rollcall）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

204号室、在室6名

## 一行ピッチ

全寮制高校の夜の点呼当番。五人部屋で「在室5名」と書いたはずなのに、空きベッドに六つ目の布団の膨らみが現れ、点呼表の数字が自分の字で書き換わる。

## 舞台

全寮制高校の寮の一室・204号室（6m × 8m）。二段ベッドが3台（西に2台、東に1台）で6床、うち東の下段は空き。扉の脇の壁に点呼表、東に机と常夜灯、北に夜の窓。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 寝息と時計の音。布団の膨らみは五つ。扉の脇の点呼表に「在室5名」と記入する（E）と消灯し常夜灯になる。何もしなくても45秒で消灯時間になる。 |
| 1:00〜3:00 | 異変①ベッドが軋み、空いていた東の下段に布団の膨らみが現れる（1:15）②点呼表の「5」が「6」に書き換わっている。自分の字で（2:00）③常夜灯が瞬き、寝息が消える。五つの布団がぺたんこになり、残るのは東の下段の膨らみだけ（2:40）。 |
| 3:00〜4:00 | 扉が閉まりロック（3:25）。廊下で誰かが点呼の続きをしている。「……204、在室7名」。常夜灯が切れ、ライトも弱まる。 |
| 4:00〜5:00 | 東の下段の布団をめくる（E）と空っぽ。頭の上から笑い声、長い髪が肩に触れる。天井から逆さにぶら下がる女を**見上げた瞬間**、目の前に落ちてくる（ジャンプスケア）。めくらなくても消灯から約35秒で膨らみが平らになり現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 「数」の違和感で積み上げる：布団の膨らみ5→6→1、点呼表 5→6、廊下の声「7名」
- 寝息（ドローン）が途切れる無音
- 扉の slam → lock、常夜灯の消灯とライトの減光
- 天井から逆さにぶら下がる人影（z 軸で反転した人影）と、飛び出し用の別の人影 ghost
- 手続き音：ベッドの軋み、ささやき、息づかい、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（点呼表・布団）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝の点呼。204号室の五人は全員そろっていた。点呼表の当番欄だけが空白で、在室の欄には赤い字で『7名』と書かれていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。布団の膨らみは register した box の表示切り替え
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
