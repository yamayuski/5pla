# 鏡の迷路（mirror-maze）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

鏡の迷路

## 一行ピッチ

閉園後の遊園地のミラーハウス。はぐれた友達のスマホには、自分宛ての「うしろ」の文字。鏡の中の誰かが、半歩遅れて動く。

## 舞台

遊園地のミラーハウス（約8m × 16m）。入口に鉄扉、中央にスマホの台と鏡のパネル、奥に非常口。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ワルツが流れる館内。台の上のスマホを見る（40秒で自動で気づく）。 |
| 1:00〜3:00 | 異変①音楽が伸びていく（1:15）②鏡の中の自分が遅れる（2:05）③園内放送「お迎えにあがりました」（2:50）。 |
| 3:00〜4:00 | 入口の鉄扉が閉まり消灯（3:25）。残る出口は奥の非常口のみ。 |
| 4:00〜5:00 | 扉を押すと、向こうに立つ人影がジャンプスケア。開けなくても330秒で発生。 |

## 主な演出

- 照明の消灯、鉄扉の slam / lock、懐中電灯
- 鏡の中の影、園内放送のささやき、扉のきしみ
- 手続き音：ブザー、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

鏡が内側から曇り「みつけた」の指跡が残る。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。interact(扉)→after 型の結末。
