# 宛先不明（post-office）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

宛先不明

## 一行ピッチ

町の小さな郵便局で一人、夜の区分作業。夜間投函口に自分宛ての封筒が落ち、消印は明日。区分棚のラベルが全部「あなた」に変わっていく。

## 舞台

町の小さな郵便局の奥の作業場（8m × 10m）。南に窓口カウンター（シャッターは下ろしてある）と呼び鈴、中央に作業台、北に2列の区分棚と灯りの届かない通路、東に通用口、西壁に夜間投函口。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯と秒針の音。作業台の郵便物を区分する（E）。何もしなくても45秒で作業が片付く。 |
| 1:00〜3:00 | 異変①夜間投函口に封筒が落ちる。宛名は自分、消印は明日の日付（1:15）②シャッターを下ろした窓口の呼び鈴が二度鳴る（2:00）③蛍光灯が瞬き、区分棚のラベルが全部「あなた」に。棚の通路の奥で靴音（2:40）。 |
| 3:00〜4:00 | 通用口が閉まり、外から鍵を回す音（鍵は自分のポケットにあるのに）（3:25）。停電して非常口の緑の灯りとライトだけになり、作業台に見覚えのない小包が置かれている。差出人は「うしろ」。 |
| 4:00〜5:00 | 小包を開ける（E）と、区分棚の前に立つ自分の背中の写真。通路の奥から制服の配達員が歩み出てくる。**それを見た瞬間**、目の前に迫る（ジャンプスケア）。開けなくても停電から約35秒で靴音とともに現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 区分棚の通路という「見通せない暗がり」と、そこから聞こえる靴音
- 郵便物・ラベル・小包のラベル（DynamicTexture）で「宛先が自分になっていく」不気味さを積み上げる
- 通用口の slam → lock、停電で非常口の緑の灯りに切り替え
- 配達員は通路の奥から move で歩み出る
- 手続き音：投函の音（thud）、呼び鈴（bell）、靴音、紙の音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（郵便物の箱・小包）、F: ライト（停電後に自動で点く）
- ヘッドホン推奨

## エンディング

「朝便の担当者は、区分を終えた郵便物の中に、宛先のない小包を一つ見つけた。差出人の欄には、昨夜の夜勤者の名前が書かれていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。区分棚の穴は暗い板を並べて表現
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
