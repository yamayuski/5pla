# 乗船名簿（night-ferry）

## タイトル
乗船名簿

## 一行ピッチ
深夜のフェリーの二等船室。毛布をかぶって眠る客の数が、寄港もしていないのに増えていく。

## 舞台
夜の海を行くフェリー。カーペット敷きの雑魚寝部屋「二等船室 B」（丸窓、毛布の膨らみ、自分の荷物）と、北の扉の先の後部甲板（手すりの外は真っ暗な海）。南西の扉の先は、シャッターの下りた案内所前の小さなホール。船はゆっくり揺れ続けている。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | エンジンの振動と船の揺れ。毛布をかぶって寝ている客が 3 人。眠れないので甲板へ出て、港の明かりの無い暗い海を眺める。 |
| 1〜3分 | 小さな異変：①船内放送「まもなく、波ノ底港に着岸いたします」――航路に無い港（1:10）②船尾の下の海から名前を呼ぶ声（1:45）③船室の毛布の膨らみが 5 つに増えている（2:18）④長い汽笛、濃い霧が船を包む（2:48）。 |
| 3〜4分 | 逃げ道が塞がる：案内所へ続く扉が閉まり、甲板の明かりが落ち、船が大きく傾く（3:20）。放送「乗船名簿と、お客様の人数を確認いたします。船室へお戻りください」。続けて数える声「いち……に……さん……」「し……ご……ろく……」。 |
| 4〜5分 | 船室に戻る（zone）→ 照明が落ち、毛布の下から 7 人全員が起き上がってこちらを見る。「……なな。おそろいですね」→ 船員が目の前に（大ジャンプスケア）→ エンディング。5:20 の保険つき。 |

## 主な演出
- 船の揺れ（update フックでカメラを常にわずかにロール）、汽笛と揺れ（shake）
- 「数が増える」異変：毛布の膨らみ 3 → 5 → 起き上がる 7 人
- 船内放送とカウントダウンで、プレイヤーを最後の場所（船室）へ誘導
- 起き上がる客は、床から上半身だけが出る配置で「布団から身を起こす」姿に見せる
- 手続き的な音：エンジンのドローン、チャイム、海からの囁き、汽笛（rumble）、息づかい、心音

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：扉の開け閉め

## エンディング
「翌朝、フェリーは定刻に入港した。二等船室 B は空っぽで、乗船名簿の人数だけが、ひとり多かった。最後の行には、あなたの名前が書かれていた。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / zone / after、requires / unless で保険）。起き上がりは `SITTERS` からアクション列を生成
- `level.ts` は MeshBuilder のプリミティブのみ。船の揺れだけ `update` フック
- 共通土台は `kit/` を同梱（自己完結）
