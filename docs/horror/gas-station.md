# 後部座席（gas-station）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

後部座席

## 一行ピッチ

深夜三時、無人のセルフスタンドで給油するだけ。なのに、誰も乗っていないはずの自分の車が揺れ、店内放送が「お連れ様がお車でお待ちです」と告げる。

## 舞台

峠の手前、県道沿いの郊外のセルフ式ガソリンスタンド（屋外、約20m × 22m）。蛍光灯のキャノピーの下に給油機と自分の車、北に無人の売店（ガラス張り、自動ドア、インターホン用スピーカー）。南の県道は濃い霧で先が見えない。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯と虫の音だけの無人スタンド。給油機を調べて（E）満タンにする。表示は 38.20L。何もしなくても45秒で給油が終わる。 |
| 1:00〜3:00 | 異変①ノズルを掛けたのに給油機の数字がまた回り出す（1:15）。売店の看板を見ると、レジの奥に一瞬だけ人影②無人の車がぐらりと揺れ、中から窓を叩く音（2:05）③スピーカー「お連れ様が、お車でお待ちです」、給油機の表示が「お連れ様の分も精算しますか」に（2:50）。 |
| 3:00〜4:00 | 売店の自動ドアが閉まってロック、店内が消灯（3:25）。続いてキャノピーの灯りも消え、霧が濃くなり県道が見えなくなる。背後に足音。スマホのライトだけで車に戻るしかない。 |
| 4:00〜5:00 | 運転席のドアに手をかけると、ガラス越しに後部座席に座る人影が見える。**それを見た瞬間**、目の前に現れる（ジャンプスケア）。ドアを調べなくても消灯から約35秒で窓を叩かれ、人影が現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 明るいキャノピーの下から始め、売店→キャノピーと順に灯りを奪って暗闇にする
- 給油機の表示（DynamicTexture）が段階的に変わる：通常 → 数字が勝手に回る → 「お連れ様の分も精算しますか」
- 無人の車の揺れ（フックで車体を傾ける）と内側からのノック
- 売店の自動ドアの slam → lock、霧の濃度上昇で道路側を塞ぐ
- 手続き音：給油機のブザー、ノイズ混じりの店内放送、ささやき、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（給油機・運転席のドア）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「翌朝、県道沿いのスタンドに、給油口の開いたままの車が見つかった。レシートの合計は二人分。後部座席のシートだけが、ぐっしょりと濡れていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。車は TransformNode でまとめ、揺れはフック `carRock`、給油機の数字はフック `meterRun`
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
