# 乾燥機の中（laundromat）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

洗濯が終わるのを待つだけの深夜のコインランドリー。誰も入れていない3番乾燥機が、ひとりでに回りはじめた。

## 舞台

住宅街の無人コインランドリー（時刻 1:07）。店内は 8m × 12m。西壁に洗濯機5台、東壁に乾燥機5台、中央に折りたたみ台、奥に洗剤の自販機。入口は南の手動ドアで、外は街灯一本だけの暗いポーチ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の下で洗濯機を回す（E）。残り38分、ほかに客はいない。ただ待つだけの退屈と蛍光灯のうなり。 |
| 1:00〜3:00 | 異変①3番乾燥機が勝手に回りはじめ、見ると窓の内側に濡れた手形がある。②入口側の蛍光灯が1本落ちる。③入口から乾燥機まで濡れた足跡が出現し、背後を足音が横切る。④洗濯機が全台、同時に唸りだす。 |
| 3:00〜4:00 | 入口のドアが勝手に閉まって開かない。残りの蛍光灯が全滅し、スマホのライト（減光）だけになる。ささやき「おせんたく、おわったよ」。洗濯機が残り時間を無視して終了ブザー、取り出すと空で濡れた長い髪が絡んでいる。 |
| 4:00〜5:00 | すべての機械が停止、静寂。3番乾燥機だけが中から橙色に光り、中から叩く音。**3番を見た瞬間**、扉が叩きつけられ濡れ髪の女が飛び出す（ジャンプスケア）。見なくても約30秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 蛍光灯グループ（tube-a/b/c）を順に落として暗闇を作る。
- 洗濯機・乾燥機のドラムを実際に回転させる（洗濯物のブロックが窓の奥で回る）。
- 足跡・手形は最初は非表示で、見ていない間に出現する。
- 音は WebAudio 手続き生成（唸り・ブザー・ノック・ささやき・足音・心音）。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（洗濯機・ドア）、F: ライト、Esc: 一時停止
- ヘッドホン推奨

## エンディング

「翌朝、店長が3番の乾燥機から、ぐっしょり濡れた長い髪を取り出した。その機械は、先月から故障中の貼り紙が出ていたという。」と表示して終了。

## 実装メモ

- 起動: `/5pla/?horror=laundromat`
- `config.ts`: 演出トリガーのデータ。`level.ts`: マップと作品固有フック（ドラム回転）。`kit/`: 共通土台（同梱）。
- 「振り返り」ではなく「見る・調べる」で締める構成（ほかの候補との差別化）。
