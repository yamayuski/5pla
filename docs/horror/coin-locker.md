# 17番（coin-locker）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

17番

## 一行ピッチ

終電後の駅のコインロッカー通路で、荷物を預けた17番の扉が開かず、中から叩く音と声が近づいてくる。

## 舞台

駅地下のコインロッカー通路（6m × 22m、天井高3m）。西壁一面に3段のロッカーが並び、17番は通路の真ん中あたり。蛍光灯の青白い光と、入口のシャッター付き自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 17番に鍵を回す（E）。鍵は回るのに扉は内側から押さえられているように開かない。 |
| 1:00〜3:00 | 異変①17番の中からノックの音（1:10）②手前の扉がひとりでに開き、内側に爪痕（1:50）③さらに二枚の扉が次々と開く（2:30）④「……出して……」とかすれた声（3:05）。 |
| 3:00〜4:00 | 入口のシャッターが落ちて開かず、照明が全て消える（3:25）。17番が内側から激しく叩かれる。 |
| 4:00〜5:00 | 17番の扉を押さえる（E）と、扉が勢いよく開いて中に押し込められていた何かが飛び出す（ジャンプスケア）。押さえなくても約55秒後に扉が弾け開く。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- ロッカーの扉は `move` で手前へ開く。開くたびに17番へ近づく配置
- 17番の扉は最後に `move` で弾け開き、同時に `jumpscare`
- 手続き音：ノック、きしみ、ささやき、鈍い打撃音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（17番）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、駅員が17番のロッカーを開けると、中は空だった。扉の内側には数えきれないほどの爪の跡と、指の長さほどの小さな手形が残されていたという。預け入れ期限は、三年前の今日になっていた。」と表示して終了。
