# 音楽室の練習曲（music-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

音楽室の練習曲

## 一行ピッチ

夜の音楽室で忘れ物を探していると、ひとりでに鳴り出したピアノの前に誰かが座っていて、曲が止まった瞬間にこちらを向く。

## 舞台

夜の校舎の音楽室（10m × 12m）。机の列、奥にグランドピアノ、壁に作曲家の肖像画、揺れるメトロノーム。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 机の列を進みピアノのそばの忘れ物を探す。メトロノームが揺れている。 |
| 1:00〜3:00 | 異変①メトロノームが速くなる（1:00）②肖像画の視線と明滅（1:45）③ピアノが一音鳴る（2:30）④ピアノの前に背を向けた人影、演奏が始まる（3:05）。 |
| 3:00〜4:00 | 扉が閉まり電灯が消える（3:35）。ピアノだけが鳴り続ける。 |
| 4:00〜5:00 | 曲が止まり人影がこちらを向く（3:43）。**目を向けた瞬間**（約18秒後に自動）、目の前に現れる。 |

時間切れ救済: 330秒で強制的にジャンプスケア。

## 主な演出

- メトロノームの揺れ、ピアノの音、肖像画、明滅、消灯、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト

## エンディング

翌朝、ピアノの楽譜台に昨夜は無かった楽譜が置かれていた、という後日談を表示して終了。

## 実装メモ

- `config.ts` に演出データ、`level.ts` はプリミティブのみ。`kit/` 同梱
