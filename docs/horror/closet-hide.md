# クローゼットの中（closet-hide）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

クローゼットの中

## 一行ピッチ

「何があっても声を出さないで」と母に隠された子ども部屋のクローゼットの中から、スリットごしに部屋を歩き回る女を息を殺して見つめる。

## 舞台

子ども部屋のクローゼットの中（幅1.4m × 奥行1.2m）。扉は縦スリットの引き戸で、スリットごしに部屋（7m × 8m）が縦じまに見える。ほぼ月明かりだけ。プレイヤーはクローゼットから出られず、歩き回る女を見ているしかない。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 母に隠され、すき間から暗い部屋を見る。廊下でゆっくりした足音（0:30）。 |
| 1:00〜3:00 | 異変①部屋の扉がひとりでに開く（1:10）②白い服の女が入って部屋を探し歩く（1:45）③女がベッドの布団をめくる「……どこ……？」（2:30）④女がクローゼットのほうへ向きを変える（3:05）。 |
| 3:00〜4:00 | 照明が落ち、女がスリットのすぐ向こうに立つ（3:25）。 |
| 4:00〜5:00 | スリットが外から叩かれる（3:40）。**顔を見てしまった瞬間**（または約9秒後）、女が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 縦スリットの引き戸（細い板の隙間）から覗き見る視界で、閉所の圧迫感を出す
- 女は `move` と `face` で部屋を歩き回り、最後にスリットの前に立つ
- 懐中電灯は無効、明かりはほぼ月明かりのみ
- 手続き音：足音、きしみ、ささやき、息づかい、ノック、心音

## 操作方法

- WASD / 矢印: 視点を動かす（クローゼットの中だけ動ける）、マウス: 視点
- 声を出さずに待つ（操作は視点のみ）
- ヘッドホン推奨

## エンディング

「翌朝、救急隊員がクローゼットを開けたとき、中の子どもは無事だった。ただ、一晩中、扉の外の誰かの呼びかけに、小さな声で返事をし続けていたという。」と表示して終了。
