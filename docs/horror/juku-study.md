# 自習室は22時まで（juku-study）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

自習室は22時まで

## 一行ピッチ

受験生が一人で残った塾の自習室。時計が巻き戻り、誰もいないうしろの席から鉛筆の音がして、ホワイトボードに「まだ帰らないで」と書かれる。

## 舞台

雑居ビル3階の学習塾の自習室（8m × 8m）。仕切り付きの自習ブースが3列×3行、全席が北のホワイトボードを向いている。自分の席は最前列の左。北壁にデジタル時計、南東に廊下への扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 21:52、空調の音だけの自習室。自分の席で問題集を開く（E）と卓上ライトが点く。何もしなくても40秒でひとりでに点く。 |
| 1:00〜3:00 | 異変①時計が 21:52 から 21:25 に戻っている（1:15）②すぐうしろの空席から、鉛筆を走らせる音とささやき（2:00）③空席の卓上ライトが一斉に点き、ホワイトボードが「まだ帰らないで うしろの席の子が まだ」に変わる（2:40）。 |
| 3:00〜4:00 | 扉が閉まり、廊下で警備員が鍵を掛けて遠ざかる（3:25）。消灯して非常口の緑の灯りとライトだけ。机の上に答案用紙が一枚置かれている。 |
| 4:00〜5:00 | 答案用紙を読む（E）と「うしろの席を見て」。うしろで鉛筆を置く音。振り返って**うしろの席の生徒を見た瞬間**、目の前に迫る（ジャンプスケア）。読まなくても消灯から約35秒で椅子を引く音とともに現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 全員が前を向く教室配置で「うしろ」を意識させ続ける（音はすべてうしろの席から）
- 時計・ホワイトボード・答案用紙（DynamicTexture）の段階変化
- 空席の卓上ライトが一斉に点く（発光メッシュの TransformNode をまとめて表示）
- 扉の slam → lock、消灯で非常口の緑の灯りに切り替え
- 手続き音：鉛筆の音（rattle）、ささやき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（自分の机）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「翌日、塾の講師は自習室の最前列に、解きかけの問題集を見つけた。そのうしろの席は、十年前の冬から、誰も座らないことになっている。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。生徒は座っている分だけ縮めた人影
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
