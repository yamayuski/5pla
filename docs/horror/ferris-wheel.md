# 最後のゴンドラ（ferris-wheel）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最後のゴンドラ

## 一行ピッチ

閉園間際、一人で乗った観覧車のゴンドラ。頂上が近づくほど、向かいの座席に誰かがいる気配が濃くなる。

## 舞台

観覧車のゴンドラ内部（約3m × 7m の簡易空間）。扉、非常ボタン、インターホン、向かいの座席。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 夜景のゴンドラ。非常ボタンを確認する（ランプは緑だが揺れ始める）。 |
| 1:00〜3:00 | 異変①インターホン「二名様で……」（1:10）②向かいの座席の軋み（2:00）③「ずっと乗ってましたよ」（2:45）。 |
| 3:00〜4:00 | 扉が閉まり消灯（3:25）。向かいの座席に人影、背後に足音。 |
| 4:00〜5:00 | 非常ボタンを押すと人影が目の前に現れる（ジャンプスケア）。押さなくても330秒で発生。 |

## 主な演出

- 消灯、扉の slam / lock、ゴンドラの揺れ
- 向かいの座席の人影
- 手続き音：ブザー、軋み、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

地上に戻ったゴンドラは空。係員は「最初から二名分の切符でした」と言う。

## 実装メモ

key-shop と同じ構造（config.ts の演出データ + level.ts のレベル構築）。
