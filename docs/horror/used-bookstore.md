# 値付け前（used-bookstore）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

値付け前

## 一行ピッチ

閉店間際の古書店で一冊探すだけ。落ちる本、棚の奥の人影、閉店の鐘のあと、帳場には「本日の入荷」としてあなたの名前の本が置かれている。

## 舞台

雨の夜の古書店（約8m × 10m）。背の高い書棚が2列並ぶ通路、奥に帳場と柱時計。入口は南のガラス戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 紙の匂いのする静かな店内。店主の姿はなく、奥へ進む。50秒で棚から本が一冊落ちる。 |
| 1:00〜3:00 | 異変①通路の奥に長髪の人影、目を逸らすと消える（1:35）②両側の棚の本がひとりでにめくれる（2:30）③柱時計が閉店の鐘（3:10）。 |
| 3:00〜4:00 | 入口が閉まりロック、店の明かりが落ち（3:35）、懐中電灯のみ。帳場に「本日の入荷」の本。 |
| 4:00〜5:00 | 本を開く（E）と題名はあなたの名前。顔を上げると店主が立っており、ジャンプスケア。調べなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 狭い書棚の通路、背後・左右に気配
- 本の落下、人影の覗き（lookAway で消える）、鐘の音、ページの擦れる音
- 閉店で照明を順に奪い、帳場の灯りだけを最後に消す

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（帳場の本）、F: ライト

## エンディング

「翌朝、古書店の帳場に、値札のない新しい本が一冊置かれていた。題名は、昨夜閉店間際に入った客の名前。背表紙は、まだ温かかった。」

## 実装メモ

- config.ts に演出をデータで記述、level.ts は MeshBuilder のプリミティブのみ、共通キット @5pla/horror-kit を使用
