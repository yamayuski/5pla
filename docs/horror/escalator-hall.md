# 動かない階段（escalator-hall）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

動かない階段

## 一行ピッチ

閉店後の駅ビルの吹き抜け。止まったエスカレーターの上に立つ人影から目を逸らした瞬間、それは背後にいる。

## 舞台

閉店後の駅ビル吹き抜け（約6m × 12m）。両側にベンチと広告、奥に故障中のエスカレーター、入口は南のシャッター。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 無人の吹き抜けを歩く。50秒で案内灯が勝手に揺れる。 |
| 1:00〜3:00 | 異変①エスカレーター上に人影、目を逸らすと消える（1:35）②フロアガイドに存在しない階（2:30）③到着音が一度鳴る（3:10）。 |
| 3:00〜4:00 | シャッターが降りロック、灯りが落ち（3:35）、奥の人影がこちらを向く。 |
| 4:00〜5:00 | 人影から目を逸らすと背後に女が現れジャンプスケア。逸らさなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 揺れる案内灯、到着音、閉ざされるシャッター
- lookAway で消える人影と背後の気配

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、F: ライト

## エンディング

「翌朝、警備員が見つけたのは、止まったエスカレーターの途中に置かれた忘れ物の鞄だった。フロアガイドには、存在しない階が書き足されていた。」

## 実装メモ

設定データ（config.ts）と構築（level.ts）を分離。`@5pla/horror-kit` のみ使用。
