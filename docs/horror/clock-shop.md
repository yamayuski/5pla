# 二時十四分（clock-shop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

二時十四分

## 一行ピッチ

亡き祖父が四十年前に修理に出した懐中時計を、閉店後の時計店へ受け取りに行く。店じゅうの時計が一斉に二時十四分で止まり、逆に回り出し、柱時計の中からガラスを叩く音がする。

## 舞台

商店街の古い時計店（7m × 8m）。東西の壁一面に大小の掛け時計、北に「非売品」の大きな柱時計、中央に修理台とスタンドの灯り、奥に作業場ののれん。南はガラス戸で、外側にシャッター。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 少しずつずれた秒針の音が重なる店内。修理台の懐中時計を手に取る（E）。針は二時十四分で止まっている。何もしなくても45秒で蓋がひとりでに開く。 |
| 1:00〜3:00 | 異変①店じゅうの時計が一斉に止まり、全部が二時十四分を指す。秒針の音が消える（1:15）②時計の針がすごい速さで逆回りし始める（2:00）③柱時計の振り子が止まり、中からガラスを叩く音とささやき（2:45）。 |
| 3:00〜4:00 | ガラス戸の外でシャッターが下り（3:25）、店の灯りが消える。閉まりきると修理台の灯りも消え、柱時計の文字盤だけがぼんやり白い。 |
| 4:00〜5:00 | 柱時計の扉を開ける（E）と、二時を打つ音とともに中に白髪の老人が立っている。「……お待たせしました」。**それを見た瞬間**、目の前に迫る（ジャンプスケア）。開けなくても消灯から約35秒で扉がひとりでに開く。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 時計の針を TransformNode で実際に回す：通常 → 一斉に2:14で停止 → 高速で逆回り（フック `clocksStop` / `clocksBack`）
- 秒針（ドローン）が一斉に止む「無音」、柱時計の振り子停止（フック `pendulumStop`）
- シャッターが下りる（move）、灯りを店→修理台の順に消す
- 最後は柱時計の扉（door）を自分で開けさせる
- 手続き音：秒針、チャイム、鐘、ガラスを叩く音、ささやき、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（懐中時計・柱時計の扉）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「時計店の店主は、四十年前の夜、二時十四分に柱時計の前で亡くなっていた。翌朝、修理台には動き出した懐中時計と、新しい預かり札が一枚。受取人の欄に、あなたの名前。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。柱時計は中が見える箱（背板・側板）で組み、扉はガラス
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
