# 留守電（answering-machine）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

留守電

## 一行ピッチ

帰宅した一人暮らしの部屋で、留守番電話を再生した。流れてきたのは、自分の声で「今、ドアの前にいる」。

## 舞台

1Kの狭い部屋（6m × 8m）。南が玄関、北の机に留守番電話、ベッド、棚、カレンダー。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 暗めの部屋を歩き、奥の机で点滅する留守番電話を確認する。再生すると自分の声のメッセージが流れる。 |
| 1:00〜3:00 | 異変①玄関のドアを外から叩く音②機械が勝手に次の録音を再生③囁き「うしろ」と一瞬の停電。 |
| 3:00〜4:00 | 玄関ドアがひとりでに閉まり施錠、照明が全て消えて霧が濃くなる。 |
| 4:00〜5:00 | ベッド脇の暗がりに髪の長い女が壁を向いて立つ。**見た瞬間**（または約10秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 留守電の再生をトリガーに、以降の異変がすべて連鎖する
- 照明グループの消灯、玄関ドアの勝手な施錠、霧の濃度上昇
- 手続き音：ノイズ、ノック、囁き、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、管理人が部屋を訪れると、留守番電話の再生ランプが点滅していた。録音は昨夜の日付で一件だけ。部屋の中を歩き回る足音と、『やっと、気づいた』という自分の声が残っていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ
- 共通土台は `kit/` を同梱（自己完結）
