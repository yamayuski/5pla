# ほうそうしつ（school-broadcast）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

夜の校舎に忘れ物を取りに戻ったら、誰もいないはずの放送室から「ほうそうしつまで、きてください」と呼ばれた。

## 舞台

深夜の中学校。南端の昇降口から北へ伸びる長さ36mの廊下（東にロッカー、西に三年A組・B組）、突き当たりが放送室。放送室の東側はガラスの仕切りで、「準備室」が見えるが、出入口は存在しない。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 昇降口から入り、三年B組を目指して暗い廊下を歩く。下校のチャイムが鳴るなど、小さな違和感だけで緊張を溜める。 |
| 1:00〜3:00 | 異変①ロッカーが中から叩かれたように鳴る。②B組の机でスマホを回収すると、昇降口の扉が叩きつけられ、廊下の灯りが手前から消えていく。③黒板に赤字「みーつけた」。④校内放送「ほうそうしつまできてください」。⑤背後の笑い声。 |
| 3:00〜4:00 | 放送室に入った途端に扉が閉まる。ON AIR のランプが点き、マイクからは自分の足音と呼吸が流れる。ガラスの向こうの準備室に少女が立つ。「ほうそうを、とめて」→ 姿は消える。 |
| 4:00〜5:00 | 卓上の赤いボタンで放送を止める（E）。静寂の3秒後、少女が目の前に飛び出す（ジャンプスケア）。押さなくても約30秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 昇降口→廊下→放送室の順に照明グループを落とし、「出口から暗くなっていく」恐怖。
- 黒板の文字、ON AIR、準備室の赤い照明を表示/非表示の切り替えで演出。
- 音は WebAudio 手続き生成（チャイム・ノイズ・ロッカーの衝撃音・笑い声・ささやき・心音）。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E/クリック: 調べる、F: ライト、Esc: 一時停止
- ヘッドホン推奨

## エンディング

「翌朝、校内放送のスイッチは入ったままだった。録音には足音と小さな女の子の笑い声が残っていた。放送室の隣に、準備室などという部屋はない。」

## 実装メモ

- 起動: `/5pla/?horror=school-broadcast`
- 「ボタンを押した後の静寂 → 目の前に出現」で締める構成（振り返り型ではない）。
