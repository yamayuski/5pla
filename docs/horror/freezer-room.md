# 冷凍庫の中（freezer-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

冷凍庫の中

## 一行ピッチ

閉店後の飲食店の冷凍庫に閉じ込められ、揺れる吊り肉の列の中に、背を向けた人影が紛れ込んでいる。

## 舞台

飲食店のバックヤードと業務用の大型冷凍庫（6m × 12m、天井高2.8m）。霜で白い壁、天井のレールに吊られた肉、奥にアイスの箱。冷気の白いもや。扉の内側に赤い非常ボタン。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 冷凍庫の奥のアイスを取る（E）。箱の内側に霜で書かれた指の跡。 |
| 1:00〜3:00 | 異変①冷気が濃くなり、自分のほかに白い息が見える（1:10）②壁の霜に「たすけて」の文字（1:50）③吊られた肉がいっせいに揺れる（2:30）④肉の列の中に背を向けた人影（3:05）。 |
| 3:00〜4:00 | 冷凍庫の扉が閉まって開かず、照明が消えて赤い非常灯だけになる（3:25）。 |
| 4:00〜5:00 | 非常ボタンを押す（E）とブザーが鳴り、吊られた人影がこちらを向く。**目が合った瞬間**（または約10秒後、押さなくても約70秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 吊り肉は TransformNode を `update` フックで揺らす
- 霜の文字は2枚の看板を `visible` で切り替え、フォグ濃度の変化で冷気を表現
- 赤い非常灯とブザー（buzz）、息づかい、ささやき、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（アイスの箱・非常ボタン）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、出勤した店長が冷凍庫を開けると、白い霜に覆われた床に人の形の跡がくっきりと残っていた。アルバイトの姿はどこにもなく、吊られた肉が一つだけ増えていたという。レールの端には、見覚えのあるエプロンが掛かっていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。吊り肉の揺れだけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
