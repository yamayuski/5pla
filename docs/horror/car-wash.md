# 泡の向こう（car-wash）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

泡の向こう

## 一行ピッチ

深夜の無人コイン洗車場。料金を入れていないのに洗車機が迫り、泡のカーテンの向こうに誰かが立っている。

## 舞台

国道沿いの屋根付きコイン洗車ベイ（約6m × 16m）。入口にシャッター、中央に洗車機のアーチ、奥に泡のカーテンと非常停止ボタン。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の白いベイ。料金箱に硬貨を入れて洗車開始（40秒で自動開始）。 |
| 1:00〜3:00 | 異変①壁に内側からの手形（1:10）②料金不要なのに洗車機がこちらへ動き出す（2:00）③泡の向こうから「あらって」の声（2:45）。 |
| 3:00〜4:00 | 入口シャッターが落ちて消灯（3:25）。泡の向こうに人影、背後に足音。 |
| 4:00〜5:00 | 奥の非常停止ボタンを押すと洗車機は止まり、人影が目の前に現れる（ジャンプスケア）。押さなくても330秒で発生。 |

## 主な演出

- 蛍光灯→消灯、シャッターの slam / lock
- 動くアーチ、手形、泡のカーテン越しの人影
- 手続き音：ブザー、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝、びしょ濡れの車と、内側が手形で曇ったガラスだけが見つかる。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリとフック（archMove / archStop）。
