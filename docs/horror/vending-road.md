# 自販機の灯り（vending-road）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

自販機の灯り

## 一行ピッチ

終バスを逃して歩く夜道。道沿いの自動販売機の灯りが、一台ずつ消えていき、最後の一台の取り出し口から白い指が這い出してくる。

## 舞台

田舎の夜道（幅5m × 長さ約38m）。両側は塀と暗い家並み。道の東の路肩に自動販売機が3台（約10m間隔）。灯りは自販機の白い光だけ。濃い霧。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 最初の自販機で飲み物を買う（E）。「あたたか〜い」のはずの缶が氷のように冷たい。 |
| 1:00〜3:00 | 異変①二台目が誰も触れていないのに缶を吐き出し、全品「売切」（1:30）②背後の最初の自販機の灯りが消え、濡れた足音が一つ近づく（2:10）③二台目の取り出し口の蓋が内側から開き、白い指がかかる（2:50）。 |
| 3:00〜4:00 | 二台目の灯りも消え、霧が濃くなる。前方で光っているのは最後の一台だけ（3:25）。 |
| 4:00〜5:00 | 最後の自販機のボタンを押す（E）と、ガコンの音とともに取り出し口の蓋が持ち上がり、白い指が這い出し、女が飛び出す（ジャンプスケア）。近づかなくても約60秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 自販機の光を点光源のグループで制御し、背後から順に消して闇を前方に偏らせる
- 取り出し口の手は小さな箱の組み合わせで、TransformNode ごと visible 切り替え
- 缶が落ちる音を連続で鳴らし、見えない何かの存在を示す
- 手続き音：缶の落下音、濡れた足音、取り出し口のガタつき、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（自販機）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、道沿いの三台の自動販売機は、どれも電源が抜かれたままだった。そのうち一台の取り出し口には、昭和の頃の古い缶が一本、温かいまま残っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
