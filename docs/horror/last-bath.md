# しまい湯（last-bath）

## タイトル
しまい湯

## 一行ピッチ
閉店間際の銭湯で、最後の客になった。番台のおばあさんが、いつの間にかいない。

## 舞台
昭和から続く町の銭湯。南に畳敷きの脱衣所（ロッカー・籠・扇風機・番台）、のれんの戸の先にタイル張りの洗い場（東に鏡つきカラン4つ、西にシャワー）、北端に湯船と富士山の壁画。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 番台のおばあさんに「ごゆっくり」と言われ、洗い場へ。湯船の前で富士山の壁画を眺める。水滴の音だけの、のどかな時間。 |
| 1〜3分 | 小さな異変：①誰もいない洗い場で「カコーン」と桶の音（1:05）②西の端のシャワーがひとりでに出る（1:45）③脱衣所で濡れた足音、照明が瞬く。番台から、おばあさんが消えている（2:25）。湯気が急に濃くなる（2:55）。 |
| 3〜4分 | 逃げ道が塞がる：脱衣所の戸が閉まり開かなくなる（3:20）。脱衣所と洗い場手前の照明が落ちる。12秒後、シャワーが止まり、最奥の鏡の裏から「コン、コン」。 |
| 4〜5分 | 最奥の鏡の前に立つ（zone）→ 曇った鏡に赤い指文字「おかえり」→ 静寂 1.6 秒 → 蒼白の番台のおばあさんが目の前に（大ジャンプスケア）→ エンディング。5:20 までに鏡へ行かなければ保険の一発。 |

## 主な演出
- 湯気（フォグ）が時間とともに濃くなり視界を奪う
- 番台のおばあさんが最初は見えている → 気づくと消えている（不在の怖さ）
- 手続き的な音：桶、シャワー（ノイズ）、濡れた足音、戸の閉まる音、鏡を叩く音、囁き、心音
- ラストは「鏡の文字 → 心音も環境音も止める無音 → 一発」の緩急
- 懐中電灯は使わない（銭湯の電灯の明暗だけで見せる）

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる

## エンディング
「その銭湯は先月、番台のおばあさんが亡くなって店を閉めていた。入口には今も『ごゆっくり』の札が掛かっている。今夜も、しまい湯の客を待っている。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / zone / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。シャワーの水流の出し入れだけ `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
