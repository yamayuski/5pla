# 最終バスのあと（rainy-busstop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最終バスのあと

## 一行ピッチ

雨の夜、廃止されたはずの田舎のバス停で朝を待っていると、遠い街灯の下の傘の女が、稲光のたびに近づいてくる。

## 舞台

雨の夜の田舎道（屋外、幅12m × 長さ40m）と、道ばたのバス停の小屋。遠くに街灯が一つだけ。濃い雨と霧、雨音。バスは一度だけ止まらずに通り過ぎる。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 時刻表を確認する（E）。最終は23:50。「このバス停は10年前に廃止されました」の注記。 |
| 1:00〜3:00 | 異変①遠い街灯の下に傘をさした女（1:10）②稲光とともに女が近づく（1:50）③バスが止まらずに走り抜ける、窓の中は全席に傘の人（2:30）④再び稲光、女がバス停の近くまで来ている（3:05）。 |
| 3:00〜4:00 | 街灯とバス停の灯りが消え、雨と霧で視界が閉ざされる（3:25）。 |
| 4:00〜5:00 | 傘の女がベンチの隣まで来て立ち止まり、傘が持ち上がる（3:33）。**顔を見た瞬間**（または約14秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 傘の女は人影に円錐の傘を取り付け、`move` と明滅（稲光）で近づける
- バスは TransformNode ごと `move` で一度だけ高速で通過し、ヘッドライトの点光源が走る
- 濃い霧（`fog`）、雨音を模したドローン、足音、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（時刻表）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、始発のバスの運転手は、廃止されたはずのバス停のベンチに、濡れた傘が一本置かれているのを見た。傘の下の座面だけが、ひどく冷たく濡れていたという。時刻表の最終は、いつの間にか一本増えていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
