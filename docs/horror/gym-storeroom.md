# 体育倉庫（gym-storeroom）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

体育倉庫

## 一行ピッチ

部活のあとの体育倉庫の鍵当番。誰も積んでいないのに跳び箱が一段ずつ高くなり、巻いたマットの中から「もういいかい」と声がする。

## 舞台

学校の体育倉庫（6m × 7m、天井高3m）。奥に跳び箱の山、右にボールカゴ、左の隅に巻いたマット、高窓から射す月明かり。入口は手前の鉄扉。狭い密室で逃げ場がない。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ボールカゴのボールを数える（E）。二十四個のはずが二十五個。一つだけ濡れて冷たい。 |
| 1:00〜3:00 | 異変①ボールがひとりでにカゴから転がり出し、こちらへ（1:10）②背後で「どすん」。跳び箱が一段高くなっている（1:45）③巻いたマットの中から笑い声「もういいかい」（2:25）④また一段。跳び箱が天井に届きそう（3:00）。 |
| 3:00〜4:00 | 鉄扉が閉まり、外から鍵がかかる。月明かりも消える（3:25）。巻いたマットが床を這ってこちらへ近づく（3:35）。 |
| 4:00〜5:00 | マットがばさりとほどけ、体操服の少女が身体を起こす（3:49）。**見た瞬間**（または約6秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 跳び箱の段を visible で増やし、ドスンの音と揺れで「誰かが積んでいる」ことを示す
- 巻いたマット（TransformNode）を `move` で這わせ、最後に差し替えて少女を出す
- 月明かり（ライトグループ）の消灯、狭い密室の閉塞感
- 手続き音：ボールの転がる音、衝撃音、笑い声、ガタつき、心音

## 操作方法

- WASD / 矢印: 移動（狭い）、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ボールカゴ）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、体育教師が倉庫を開けると、マットは巻かれたまま、きちんと隅に立てかけてあった。ただ、巻いたマットの端から、小さな体操服の袖が、一筋はみ出していたという。三十年前、かくれんぼのまま見つからなかった生徒の名は、今も卒業アルバムに載っている。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
