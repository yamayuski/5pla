# 案山子の道（crow-field-road）

## タイトル
案山子の道

## 一行ピッチ
終バスを降りた夜の田んぼ道。目を離すたびに、道端の案山子が近づいてくる。

## 舞台
バス停から自宅の門まで続く一本道の田んぼ道。道の脇に案山子が立ち、北端の門に呼び鈴と門灯がある。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | バスを降り、虫の声と遠くの門灯を頼りに歩く。道端の案山子は三体。目的は家の門の呼び鈴。 |
| 1〜3分 | 小さな異変：①案山子が道に寄っている（1:10）②前方にも案山子が増える（1:45）③背後の案山子がこちらを向く（2:20）④さらに増え、藁の擦れる音（2:50）。 |
| 3〜4分 | 逃げ道が塞がる：揺れとフォグ、案山子が道の両脇にずらりと並ぶ（3:25）。 |
| 4〜5分 | 門の呼び鈴を押す（interact）と門灯もライトも消え、背後の案山子が目の前に飛び出す（大ジャンプスケア）→ エンディング。 |

## 主な演出
- 目を離すと近づく案山子（move）、増殖、振り向き
- 暗いフォグと遠い門灯
- 手続き音：藁の擦れ、足音、含み笑い、呼び鈴

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる（呼び鈴）、F：ライト

## エンディング
「その田んぼに、案山子は一体も立てられていない。毎年、秋の夜道を歩く人の数だけ、増えるだけだ。」
