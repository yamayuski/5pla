# 閉館後の水族館（night-aquarium）

## タイトル
閉館後の水族館

## 一行ピッチ
シアターで寝過ごし、閉館後の水族館に取り残された。大水槽の中の「何か」から、目を離してはいけない。

## 舞台
夜の水族館。南端のシアター前から、壁に水槽がはめ込まれた青暗い大水槽ホール（約20m）を抜け、北の水槽トンネル（約12m、西側はガラス越しの大水槽）の先に出口がある。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 閉館後の館内で目を覚ます。水槽の青い光、魚がゆらゆら泳ぐ、ポンプと水滴の音。出口を目指して歩く。 |
| 1〜3分 | 小さな異変：①水槽の魚が一匹残らず消える（1:10）②西の水槽のガラスが内側から叩かれ、手形が残る（1:55）③水槽の照明が落ち、背後で濡れた息づかい（2:35）。 |
| 3〜4分 | 逃げ道が塞がる：出口のシャッターが落ちて施錠、ホールの照明も消え懐中電灯が点く（3:15）。トンネルの大水槽の中に、女が立っている。見つけると「目を離さないで」。女はゆっくりガラスへにじり寄ってくる。 |
| 4〜5分 | 5秒以上見つめたあと、視線を逸らした瞬間（55°以上）、背後で轟音→水死体の女が目の前に（大ジャンプスケア）→エンディング。5:20 までに起きなければ保険の一発。 |

## 主な演出
- 青いフォグと光る水槽パネル、魚の泳ぎ（update フック）
- 手形の出現、照明の段階的な消灯、懐中電灯の強制点灯
- 「見ている間は大丈夫、目を逸らすと来る」lookAway 型のラスト（他候補の look/interact 型と差別化）
- 手続き的な音：ポンプの低音、水滴、ガラスを叩く音、囁き、息、心音、シャッターの轟音

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる
- F：懐中電灯 ON/OFF

## エンディング
「翌朝、清掃員がトンネル水槽のガラスに手形を見つけた。手形は、水槽の内側についていた。その大水槽には、二十年前から魚しか入れていない。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / look / after / lookAway、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。魚の泳ぎ・魚の消失・水槽消灯・女のにじり寄りを `custom` / `update` フックに分離
- 共通土台は `kit/` を同梱（自己完結）
