# 返却ビデオ（video-rental）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

返却ビデオ

## 一行ピッチ

閉店後のレンタルビデオ店で、ラベルのない返却テープを再生すると、今この店にいる自分の背後に、もう一人が近づいていく映像が映る。

## 舞台

閉店後のレンタルビデオ店（10m × 14m、天井高3m）。棚が3列、奥にカウンターとテレビとデッキ。ピンク色のネオンと、ノイズだけの古いBGM。出入口は自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | カウンターのデッキで黒いテープを再生する（E）。映るのはこの店の防犯映像で、ホラーの棚の前に自分と同じ服の人が立っている。（再生しなくても50秒で自動再生） |
| 1:00〜3:00 | 異変①映像の中の自分の背後にもう一人、髪で顔を隠している（1:45）②ホラーの棚からテープが何本も落ちる（2:30）③映像に「REC ● 現在」の文字。今の映像だ（3:05）。 |
| 3:00〜4:00 | 出入口のシャッターが落ち、店内の灯りが消えてテレビの光だけが残る（3:25）。 |
| 4:00〜5:00 | 画面を見つめると、自分の真後ろに顔が重なり、背後に息がかかる。**画面から目を離した瞬間**（または約9秒後）、背後の何かが目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- テレビ画面は4枚の看板を `visible` で切り替える（砂嵐→防犯映像→人影→現在）
- 「画面を見ている間は動けない」look → lookAway の連鎖
- 手続き音：ノイズ（static）、ささやき、落下音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ビデオデッキ）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、店長が返却ボックスを確認すると、黒いテープが一本もなくなっていた。防犯カメラの映像には、閉店後の店内で棚の前に立つ人影と、その背後に重なるもう一つの人影が朝まで映り続けていたという。その映像は、再生するたびに、人影が一歩ずつ近づく。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
