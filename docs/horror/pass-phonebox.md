# 峠の電話ボックス（pass-phonebox）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

霧の峠道で車が止まった。助けを呼びに辿り着いた電話ボックスで、鳴っていたのは自分あての電話だった。

## 舞台

深夜の山間の林道（約80m）。両側は杉林、右手にガードレール。ハザードを点滅させた車、道端に並ぶ赤いよだれかけの地蔵六体、峠の待避所にぽつんと光る緑の電話ボックス。その先は倒木で通れない。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 車が止まり、携帯は圏外。懐中電灯を手に、霧の林道を峠の電話ボックスへ歩く。森のきしみ、自分の足音だけ。 |
| 1:00〜3:00 | 小さな異変①道端の地蔵六体（鈴の音）。②通り過ぎると背後で砂利を踏む足音。振り返ると、地蔵が道の真ん中に並んでいる（lookAway で移動）。③はるか後ろで誰もいない車のクラクション、ハザードが消える。電話ボックスの電話が鳴り始める。 |
| 3:00〜4:00 | 受話器を取ると「いま、どこ？」→「そこから、うごかないで」。扉が叩きつけるように閉まり、懐中電灯が切れる。ボックスのまわりを地蔵が囲んでいる。先の道は倒木で塞がれている。 |
| 4:00〜5:00 | 「みつけた。……うしろの、ガラス」。背後（扉側）のガラスをノックする音。振り返ると白髪の老婆が目の前に（ジャンプスケア）。振り返らなくても約8秒後に発生。 |

時間切れ救済: 電話は鳴り続ける、開始330秒で強制ジャンプスケア。

## 主な演出

- 暗闇とフォグ: 屋外。青白い弱い環境光 + 濃い EXP2 フォグで、懐中電灯の届く範囲しか見えない。
- 懐中電灯: 最初から所持。電話ボックスで閉じ込められた瞬間に切れる（F で点けようとしても点かない）。
- 音（WebAudio 手続き生成）: 足音（砂利）、鈴、クラクション、電話のベル、受話器の砂嵐、ささやき、ガラスのノック、心音、スティンガー。
- ドア: 電話ボックスの扉が勝手に閉まりロック。
- 背後の気配: 背後の足音と「目を離すと近づく地蔵」。最後は扉側のガラスへの振り返りで発火。
- 森は InstancedMesh で量産（疑似乱数シード固定で毎回同じ配置）。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 受話器を取る
- F: 懐中電灯のオン/オフ、Esc: 一時停止
- ヘッドホン推奨

## エンディング

暗転後「翌朝、峠の電話ボックスで、受話器が外れたまま揺れているのが見つかった。その電話機の回線は、十年前に撤去されていた。ボックスのまわりには、六体の地蔵が並んでいたという。」

## 実装メモ

- 起動: `/5pla/?horror=pass-phonebox`
- `config.ts`: 演出トリガーのデータ。
- `level.ts`: 林道・森（インスタンス）・車・地蔵（グループで移動）・電話ボックスの構築、ハザード点滅（update フック）、クラクション（custom）。
- `kit/`: 一人称ホラー共通土台（作品フォルダ内に同梱）。
- 共有ファイルの変更は `apps/web/src/main.ts` と `packages/games/src/horror/registry.ts` のみ（全ホラー候補 PR で同一内容）。
