# 回る遊具（night-park）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

回る遊具

## 一行ピッチ

終電後の近道に抜けた夜の児童公園。ブランコがひとりでに揺れ、回転遊具が回りだし、北の門が閉まる。

## 舞台

住宅街の小さな児童公園（20m × 24m）。南が入口、北の出口は門。ブランコ、すべり台、砂場、ベンチ、中央の回転遊具。古い水銀灯が二本、濃い夜の霧。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 水銀灯のじりじり鳴る公園を、北の出口へ向かって歩く（近道のつもりで）。 |
| 1:00〜3:00 | 異変①風もないのにブランコが揺れはじめる（1:10）②すべり台の上から子どもの笑い声（1:55）③正面の回転遊具が軋みながら勝手に回りだす（2:35）。 |
| 3:00〜4:00 | 北の門ががしゃんと閉まる（3:25）。水銀灯が全て消え、回転遊具の回転がどんどん速くなる。 |
| 4:00〜5:00 | 軋みがぴたりと止み、回転遊具の上にうつむいた子どもが座っている（3:53）。**見た瞬間**（または約9秒後）、顔を上げて目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- ブランコと回転遊具を実際に動かす（`update` / `custom` フック：swingOn / merryOn / merryFast / merryOff）
- 回転を急に止めて静寂を作り、その瞬間に人影を出す
- 水銀灯（ライトグループ）の一斉消灯、霧の濃度上昇
- 手続き音：ブランコの軋み、子どもの笑い声、回転遊具の轟音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、公園の回転遊具の上に、赤い靴が片方だけ置かれているのが見つかった。近所の人の話では、その遊具は二十年前に撤去されたはずだという。公園の門は、内側から鍵がかかっていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。遊具の動きだけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
