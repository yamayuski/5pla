# 三小節目（school-music-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

三小節目

## 一行ピッチ

夜の音楽室。誰もいないグランドピアノが、同じ二小節だけを繰り返している。三小節目の鍵盤に触れた瞬間。

## 舞台

夜の学校の音楽室（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 夜の音楽室で机の上の楽譜を探す。 |
| 1:00〜3:00 | 異変①ピアノが二小節だけ鳴る（1:10）②照明が瞬き足音が止まる（2:00）③ピアノの前に制服の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。ピアノは三小節目から先を弾かない。鍵盤に触れて止めるしかない。 |
| 4:00〜5:00 | ピアノの鍵盤に触れると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- ピアノの音、肖像画、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ピアノの鍵盤に触れる）、F: ライト

## エンディング

翌朝、音楽の先生がピアノの蓋を開けた。 鍵盤の上に、まだ温かい指の跡が、十本ぶん残っていた。
