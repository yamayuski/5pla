# 仕込みの時間（closed-bakery）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

仕込みの時間

## 一行ピッチ

午前三時のパン屋で仕込み。発酵器の中で、生地が人の形に膨らんでいく。窯の扉の奥に。

## 舞台

午前三時のパン屋（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 生地をこねて成形する。 |
| 1:00〜3:00 | 異変①麺棒が転がる（1:10）②照明が瞬き足音が止まる（2:00）③ラックの陰に粉まみれの人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。呻きは窯の中から聞こえる。開けるしかない。 |
| 4:00〜5:00 | 窯の扉を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 窯の音、粉の擦れる音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（窯の扉を開ける）、F: ライト

## エンディング

翌朝、開店前の店に並んだパンは、どれも人の手の形をしていた。 窯の前に、あなたのエプロンだけが落ちていた。
