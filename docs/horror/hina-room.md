# しまい忘れた雛（hina-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

しまい忘れた雛

## 一行ピッチ

三月半ば、祖母の家の奥座敷で出しっぱなしの雛人形を片付けるだけ。なのに人形が壁を向き、お雛様が消え、十五の顔が一斉にこちらを向く。

## 舞台

古い日本家屋の奥座敷（6畳強、6m × 6m）。北壁に赤い毛氈の七段飾り、最上段に金屏風と雪洞、部屋の隅に行灯。出入口は南の襖一枚だけ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 雪洞の灯りに白い顔の人形が並ぶ静かな座敷。行灯を点ける（E）。何もしなくても40秒でひとりでに灯が入る。 |
| 1:00〜3:00 | 異変①灯りが揺れたあと、人形が全員壁の方を向いている（1:15）②最上段のお雛様が消え、畳の上を小さな足音が遠ざかる（2:00）③人形が「かたかた」と一斉にこちらを向き、背後で笑い声（2:45）。 |
| 3:00〜4:00 | 襖がぴしゃりと閉まり、外から押さえられたように開かない（3:25）。行灯と雪洞が消え、赤い闇とライトだけ。空いた座布団の方から「……しまわないで……」。 |
| 4:00〜5:00 | 空いた座布団に触れる（E）とまだ温かい。部屋の隅で衣擦れの音、等身大の雛人形が座っている。**それを見た瞬間**、目の前に迫る（ジャンプスケア）。触れなくても消灯から約35秒で現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 15体の人形（プリミティブの人影を縮小）の向きを段階的に変える：正面 → 全員が壁 → 全員がプレイヤーへ
- お雛様だけが消える「欠け」の違和感と、小さな足音
- 襖の slam → lock、灯りを行灯・雪洞から赤い闇＋ライトへ
- 手続き音：人形の揺れる音（rattle）、小さな足音、笑い声、ささやき、衣擦れ（creak）、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（行灯・最上段の座布団）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「翌朝、祖母は閉めきった奥座敷の襖を開けた。雛人形はすべて箱に収まっていた。最上段の座布団には、お雛様の代わりに、見慣れた顔の人形が一つ座っていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。人形の向きはフック `dollsTurnAway` / `dollsFace`
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
