# 蛍の光（home-center）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

蛍の光

## 一行ピッチ

閉店後のホームセンターで棚卸しのバイト。レジの奥に背を向けて立つ店員は、閉店の音楽が鳴っても動かない。出口のシャッターが降りたとき、声をかけるしかなくなる。

## 舞台

閉店後のホームセンター売り場（12m × 22m）。中央通路と両側の棚、店内ラジオ、従業員口のシャッター、奥のレジと店員。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の唸りと、レジに立つ背を向けた店員。売り場を見て回る。「閉店時間をすぎました」と機械的な声（0:40）。 |
| 1:00〜3:00 | 異変①ラジオが勝手につき、間延びした「蛍の光」（1:15）②背後をカートが押されていく音（2:00）③蛍光灯が一瞬消え、店員の向きが変わっている気がする（2:45）。 |
| 3:00〜4:00 | 従業員口のシャッターが降りて退路が塞がる（3:25）。売り場の照明が落ち、レジの明かりだけが残る。 |
| 4:00〜5:00 | レジの店員に声をかける（E）と首だけが後ろへ回り、**目の前に迫る**（ジャンプスケア）。声をかけなくても消灯から約35秒で振り向き、その4秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 最初から視界にいる背を向けた店員という持続的な不安
- 勝手につくラジオ（フック `radioOn`）、降りるシャッター（フック `shutterDown`）
- 蛍光灯の点滅と消灯、フラッシュライトの減光
- 手続き音：ノイズ、カート、足音、シャッター、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（店員）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、開店前の売り場で、棚卸しの端末だけが見つかった。防犯カメラには、レジに立つ二人目の店員が、閉店から開店までずっと映っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。人影は透明な子メッシュでインタラクト判定
- 共通キット `@5pla/horror-kit` を使用
