# 最後の一周（night-skate-rink）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最後の一周

## 一行ピッチ

閉館後のスケートリンク。整氷機が走る音のあと、氷の上に刻まれた足跡が一周ぶん増えている。その中心に。

## 舞台

閉館後のスケートリンク（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 冷え切ったリンクの周りを歩いて点検する。 |
| 1:00〜3:00 | 異変①氷の上の足跡が増えている（1:10）②照明が瞬き足音が止まる（2:00）③反対側にスケート靴の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。ひび割れの音が中央から聞こえる。確かめるしかない。 |
| 4:00〜5:00 | 中央の氷をのぞくと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 氷の軋み、白い息、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（中央の氷をのぞく）、F: ライト

## エンディング

翌朝、整氷係はリンクの中央に凍りついたスケート靴を見つけた。 靴の中には、昨夜の点検表を握ったあなたの手袋が残っていた。
