# 刷り上がり（print-shop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

刷り上がり

## 一行ピッチ

夜中の印刷所で急ぎの刷り直し。刷り上がった紙の束に、明日の日付と自分の名前の訃報が混じっている。輪転機の奥に。

## 舞台

夜中の小さな印刷所（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 刷り上がりを数えて箱に詰める。 |
| 1:00〜3:00 | 異変①紙の束が棚から落ちる（1:10）②照明が瞬き足音が止まる（2:00）③紙の山の陰にインクまみれの人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。最後の紙は輪転機の中から出てくる。確かめるしかない。 |
| 4:00〜5:00 | 輪転機をのぞくと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 機械音、紙の擦れる音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（輪転機をのぞく）、F: ライト

## エンディング

翌朝、新聞の隅に小さな記事が載った。 「印刷所で従業員一名行方不明」。記事の活字は、まだ濡れていた。
