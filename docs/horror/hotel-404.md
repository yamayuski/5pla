# 404号室（hotel-404）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

404号室

## 一行ピッチ

出張先のビジネスホテルで、浴室から誰もいないのにシャワーの音がする。半透明のカーテンの向こうに、人影が立っていた。

## 舞台

安いビジネスホテルのシングルルーム（6m × 7m）。ベッド、机とテレビ、枕元の電話、廊下に面した入口。北西に狭いユニットバス（浴槽に半透明のシャワーカーテン）。壁が薄く、空調の音と遠いエレベーターの音。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | チェックイン直後。荷物を置き、浴室を確かめに行く（扉は閉まったまま、隙間から水の滴る音）。 |
| 1:00〜3:00 | 異変①浴室の電気が点き、誰もいないのにシャワーの音（1:10）②枕元の電話が鳴る。出る（E）と「お連れ様が、お風呂でお待ちです」（1:50）③テレビが勝手に点き、砂嵐に浴室のような映像（2:30）④浴室の扉がひとりでに開き、シャワーカーテン越しに人影が立っている（2:55）。 |
| 3:00〜4:00 | 入口のドアが閉まりチェーンが掛かる。部屋の電気とテレビが消え、浴室の明かりだけが残る（3:25）。カーテンの向こうの人影がゆっくり前に出て、ビニールが顔の形に押し出される。 |
| 4:00〜5:00 | **カーテンを見た瞬間**（または約9秒後）、カーテンが裂け、女が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 半透明のカーテン越しの人影（alpha 付きマテリアルと、背後の人影の `move` による押し出し演出）
- 浴室の電気・部屋の電気・テレビを別々のライトグループで制御
- 枕元の電話（interact）と手続き音：電話ベル、シャワーの水音、ささやき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（電話）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、チェックアウトの時間になっても出てこない客を、従業員が起こしに行った。404号室の浴槽には、誰も使っていないはずの湯が、なみなみと張られていた。このホテルに、404号室という部屋はない。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
