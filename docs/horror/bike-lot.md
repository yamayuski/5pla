# 自転車は一台ずつ（bike-lot）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

自転車は一台ずつ

## 一行ピッチ

終電後に地下駐輪場へ自転車を取りに行くと、精算機は「13番　出庫済み」と表示した。自分の自転車は、まだそこにあるのに。

## 舞台

駅前の地下駐輪場（約8m × 14m）。入口シャッター、並ぶ自転車、精算機、管理室の電話。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の駐輪場。精算機で13番を確認（出庫済み表示）。 |
| 1:00〜3:00 | 異変①管理室の電話「お帰りは一台ずつです」（1:10）②自転車が一台ずつ倒れる音（2:00）③「のせて」の声（2:45）。 |
| 3:00〜4:00 | シャッターが落ち消灯（3:25）。列の奥に人影、背後に足音。 |
| 4:00〜5:00 | 精算を止めようとすると人影が目の前に現れる（ジャンプスケア）。触らなくても330秒で発生。 |

## 主な演出

- 蛍光灯→消灯、扉の slam / lock
- 倒れていく自転車、列の奥の人影
- 手続き音：ブザー、ノック、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝、精算機は「13番　出庫済み」。荷台には濡れた手形が二つ残る。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。
