# 土蔵の長持（dozo-chest）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

土蔵の長持

## 一行ピッチ

祖母の家の古い土蔵。壁を叩く音、変わる掛け軸、閉まる扉。長持の蓋の下で、誰かがずっと待っていた。

## 舞台

土蔵の内部（6m × 7m）。南壁に扉、東西にソファ、中央にテーブルと長持と行燈、北壁に大型掛け軸、天井に電気。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 遠くの風鈴の音が漏れる静かな個室。行燈を点ける（E）と明かりが灯る。40秒で自動再生。 |
| 1:00〜3:00 | 異変①遠くの風鈴の音が止み壁を内側から叩く（1:15）②掛け軸の歌詞が「たすけて／うしろにいる」に（2:05）③長持からささやき（2:45）。 |
| 3:00〜4:00 | 蔵の扉が閉まりロック（3:25）。照明が赤に変わりライトが弱まる、背後で息づかい（3:35）。長持を置き直すしかない。 |
| 4:00〜5:00 | 隅に白い着物の女が立っている。**見た瞬間**目の前に現れる。見なくても約35秒で強制発生。 |

時間切れ救済: プレイ開始320秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 行燈の橙から赤への照明切り替え
- 掛け軸表示の差し替え、扉の slam → lock、フォグ上昇
- 手続き音：ノック、ささやき、ノイズ、息づかい、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（行燈・長持）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、祖母は開いた蔵を見つけた。長持の底に、五十年前の日付で、あなたの名前があった。」と表示して終了。
