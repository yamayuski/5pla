# 閉店後のひろば（toy-store）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉店後のひろば

## 一行ピッチ

閉店後の玩具店にオルゴールを取りに来たら、ぬいぐるみの目が全部こちらを向き、シャッターが落ちる。

## 舞台

商店街の古い玩具店（約8m × 12m）。入口にシャッター、棚が並ぶ通路、奥の台座にオルゴール。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 暖色の灯りの店内。奥のオルゴールを探して歩く。 |
| 1:00〜3:00 | 異変①棚から笑い声（1:05）②ぬいぐるみの目が一斉にこちらを向く（1:50）③背後でブリキの玩具が歩く音と明滅（2:35）。 |
| 3:00〜4:00 | シャッターが落ちて消灯（3:20）。通路に女の子の人影、オルゴールが勝手に鳴り出す。 |
| 4:00〜5:00 | オルゴールを止めると女の子が目の前に現れる（ジャンプスケア）。止めなくても330秒で発生。 |

## 主な演出

- 消灯とシャッターの slam / lock、目玉看板、人影
- 手続き音：ささやき、足音、ブザー、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝シャッターは閉まったまま。店主は誰にも頼んでいないと言い、オルゴールはまだ鳴っている。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。フックなし。
