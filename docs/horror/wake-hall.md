# 通夜の番（wake-hall）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

通夜の番

## 一行ピッチ

祖母の通夜の夜、一人で番を任された。線香を絶やさずにいると、遺影の顔が変わり、棺の蓋が内側から叩かれる。

## 舞台

斎場の広い和室（10m × 14m、天井高3.4m）。畳に座布団、北の祭壇に棺と遺影、花、線香立てと二つのろうそく。入口の土間には弔問客の靴。灯りはろうそくの炎が頼り。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 線香とろうそくの匂い。祭壇の線香立てに線香をあげる（E）。遺影の祖母は、いつもの笑顔。 |
| 1:00〜3:00 | 異変①遺影の顔が一瞬だけ崩れ、目が黒く窪んで口が裂けて見える（1:10）②棺の内側から蓋を叩く音（1:45）③入口の土間に、知らない黒い革靴が何足も増えている（2:20）④左のろうそくが消え、棺から掠れた声「もう、いいよ」（2:55）。 |
| 3:00〜4:00 | 入口の戸が閉まって開かず、ろうそくが全て消える（3:25）。棺の蓋がずず……とずれ、白い指が縁を掴む。 |
| 4:00〜5:00 | 蓋が外れて落ち、白い着物の祖母が起き上がる（3:47）。**見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 遺影は 2 つのグループ（笑顔／崩れた顔）を visible で一瞬だけ切り替える
- 棺の蓋を TransformNode にして `move` で段階的にずらし、最後に外す
- ろうそくの光（ライトグループ）を一つずつ消して暗闇に近づける
- 手続き音：ノック、囁き、足音、蓋の衝撃音、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（線香立て）
- ヘッドホン推奨

## エンディング

「翌朝、叔母が斎場に着くと、祖母の棺は空になっていた。蓋は閉じられたまま、内側から爪で引っかいた跡だけが残っていたという。線香は、一本も絶えていなかった。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
