# 夜のプール（school-pool）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

夜のプール

## 一行ピッチ

置き忘れたゴーグルを取りに忍び込んだ夜の校内プール。水の底に、仰向けのまま沈んでいる誰かがいる。

## 舞台

学校の室内プール（デッキ16m × 22m、水面7m × 14m、水深1.6m）。南に更衣室、北に飛び込み台、水中照明の青い光、コースロープ、塩素の匂い。デッキの照明は薄暗い。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 更衣室を抜けてプールサイドへ。水際に置き忘れたゴーグルを拾う（E）。水面が不自然なほど静か。 |
| 1:00〜3:00 | 異変①水の底に、仰向けの人影が沈んでいる（1:10）。ゆっくり水中を南へ移動し始める②どこかで笛の音（2:15）③水中照明が瞬き、コースロープが勝手に揺れる（2:50）。 |
| 3:00〜4:00 | 更衣室の扉が叩きつけられて開かない（3:25）。デッキの灯りが消え、青い水の光だけに。沈んでいた人影が、水底をすべってこちらの岸へ寄ってくる。 |
| 4:00〜5:00 | 水面が盛り上がり、閉じていた目が開く（4:05）。**その女を見た瞬間**（または約8秒後）、水から飛び出して目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 水面は半透明の板、槽は薄い箱で構成。水中の女は同じ床下に仰向けで配置し、`move` で水底を移動させる
- 水中ライトだけを残す暗転（デッキ照明グループを消灯）
- 手続き音：水滴、笛、低い重低音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ゴーグル）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、水泳部の顧問がプールの底から拾い上げたのは、三十年前の古いゴーグルだった。レンズの内側は、なぜかまだ濡れていた。更衣室の扉には、内側から無数の爪の跡が残っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
