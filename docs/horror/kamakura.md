# かまくらの灯り（kamakura）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

かまくらの灯り

## 一行ピッチ

付き添いで来たかまくらの灯り。揺れる雪洞、雪壁の端の小さな人影、見覚えのない呼出番号のあと、戸が閉まり、奥のろうそくが点滅しはじめる。

## 舞台

かまくらの灯り（約6m × 8m）。両側に雪壁、奥に広場と奥のろうそく、西壁に立て札。入口は南の戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 広場が無人の広場で待つ。50秒で雪洞が勝手に揺れる。 |
| 1:00〜3:00 | 異変①雪壁の端に小さな人影、目を逸らすと消える（1:35）②立て札に「あなた」（2:30）③鐘が一度だけ鳴る（3:10）。 |
| 3:00〜4:00 | 戸が閉まりロック、広場の明かりが落ち（3:35）、奥のろうそくだけが緑に点滅する。 |
| 4:00〜5:00 | ろうそくを吹き消す（E）と「000番　あなた」。顔を上げると広場の奥に白い女が立っており、ジャンプスケア。取らなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- サイレン・鐘・背後の気配、閉ざされる戸
- lookAway で消える人影、立て札の異変

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（奥のろうそく）、F: ライト

## エンディング

「翌朝、交代の看護師が広場で見つけたのは、一枚の番号札だった。『000番　あなた』。診察記録には、昨夜の付き添いの名前が一件増えていた。」

## 実装メモ

- 雪洞の揺れは custom フック lampSwing。立て札は visible で出す。
