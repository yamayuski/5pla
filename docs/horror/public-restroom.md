# 個室は四つ（public-restroom）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

個室は四つ

## 一行ピッチ

夜の公園の公衆トイレ。個室は四つ、使っているのは自分だけのはずが、三番目からノックが返ってくる。

## 舞台

公園の古い公衆トイレ（6m × 8m）。北側に個室が四つ、西壁に手洗い場と鏡。蛍光灯が二本、湿った霧。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の唸る中、手洗い場の鏡の前で顔を洗う。水の滴る音だけが響く。 |
| 1:00〜3:00 | 異変①三番目の個室から内側のノック（1:15）②一番奥の個室のドアがひとりでに開き水が流れる（2:00）③壁の向こうの「まだ入ってます」という声（2:45）。 |
| 3:00〜4:00 | 入口の扉ががしゃんと閉まり施錠。蛍光灯が全て消え、四番目の個室のノックが激しくなる（3:25）。 |
| 4:00〜5:00 | ノックが止み、四番目の個室のドアが開いて人影が立っている（3:51）。**見た瞬間**（または約9秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 個室ドアの自動開閉、ノック音、蛍光灯の一斉消灯と霧の増加
- 閉じ込め（入口施錠）、ノックの加速
- 手続き音：水滴、ノック、囁き、衝撃音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト

## エンディング

翌朝、清掃員が個室が五つあることに気づく。扉のない最奥の個室だけが内側から施錠されていた。

## 実装メモ

kit/ の汎用エンジン＋データ駆動トリガー（config.ts）。
