# 終電のあとで（last-train）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

終電を寝過ごした地下鉄ホームで駅員を呼んだら、来たのは「むかえ」だった。

## 舞台

地下鉄・黄泉坂（よみざか）駅の島式ではない片面ホーム（全長約60m）。線路側はホームドア、反対側はタイル壁。
南寄りに改札へ続く短い通路があり、通路の先はシャッターで閉ざされている。時刻は 0:42。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ベンチで目を覚ます。「本日の運転は終了しました」の放送。蛍光灯のうなりだけが響く日常の延長。改札へ向かうとシャッターが下りており、北端のインターホンで駅員を呼ぶ。 |
| 1:00〜3:00 | 小さな異変①インターホンから「いま、そちらに、むかいます」→ 南側の照明が落ちる。②来るはずのない「まもなく電車がまいります」の接近放送とトンネルの地鳴り、霧が濃くなる。暗いホーム南端に女が立っている（見つめると明滅して消える）。③耳元のささやき、背後の足音。改札のシャッターが上がる音。 |
| 3:00〜4:00 | 通路に入った瞬間、背後でシャッターが叩きつけるように閉まり、ホームの照明が全滅。スマホのライトは弱々しい。無人の電車がトンネルから入ってくる。通路のインターホンが鳴り、出ると「むかえに、きました。うしろに、います」。 |
| 4:00〜5:00 | 背後の息づかい。振り返る（ホーム側を向く）と、女が目の前に飛び込んでくる（ジャンプスケア）。振り返らなくても約10秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 暗闇: 環境光はごく弱く、照明はグループ単位（north / center / south）で消える。
- 懐中電灯: 最初は駅の照明のみ。閉じ込められた時点でスマホのライト（減光状態）が点く。F でオン/オフ。
- フォグ: 接近放送とともに EXP2 フォグが濃くなる。
- 音（すべて WebAudio で手続き生成）: 発車メロディ風チャイム、インターホンの呼出音と砂嵐、トンネルの地鳴り、ささやき、足音、息づかい、心音、シャッターの衝撃音、最後のスティンガー。
- ドア: 改札シャッターが上がる → 叩きつけるように閉まる。
- 背後の気配: "behind" 指定の立体音響（ささやき・足音・息）。振り返り判定は不可視マーカーへの視線（look トリガー）。
- ジャンプスケア: 人影を正面 1.6m に出して 0.16 秒で 0.5m まで詰める + 白フラッシュ + 色収差 + 画面揺れ + 爆音 → 暗転。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる・インターホン
- F: ライトのオン/オフ
- Esc: 一時停止（クリックで再開）
- ヘッドホン推奨

## エンディング

暗転後、「翌朝、始発の運転士はホームのベンチに座る人影を見たという。近づくと、誰もいなかった。黄泉坂駅に、終電はない。」と表示して終了（「もう一度」でリロード）。

## 実装メモ

- 起動: `/5pla/?horror=last-train`
- `packages/games/src/horror/last-train/config.ts` が演出トリガーのデータ（time / zone / look / after / interact 条件 + アクション配列）。
- `level.ts` がマップ構築、`kit/` が汎用の一人称ホラー土台（将来 `horror/kit` へ共通化する想定で、作品ごとに同梱）。
- 共有ファイルの変更は `apps/web/src/main.ts` の `?horror=` 分岐と `packages/games/src/horror/registry.ts`（`import.meta.glob` で自動登録）のみ。どのホラー候補 PR も同一内容なので、複数マージしてもコンフリクトしない。
