# 閉院のあと（dental-closed）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉院のあと

## 一行ピッチ

忘れ物を取りに入った閉院後の歯科医院で、診察台に「次の方」が待っていた。

## 舞台

閉院後の歯科医院（8m × 8m）。南壁に出入口、中央に診察台、器具トレイ、洗面台、ラジオ、待合のソファ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 無影灯だけの院内に入り、診察台のそばの鞄を探す（E）。抜けた歯が置かれている。 |
| 1:00〜3:00 | 異変①洗面台の水が勝手に流れる（1:10）②トレイのドリルが唸る（2:00）③ラジオの囁きと壁に「あーん」の文字（2:45）。 |
| 3:00〜4:00 | ドアが叩きつけられ施錠（3:25）。無影灯が消え、背後で息づかい（3:37）。 |
| 4:00〜5:00 | 無影灯が戻ると診察台に歯科医が座っている。**見た瞬間**ジャンプスケア。見なくても強制発生。 |

時間切れ救済: 330秒で強制ジャンプスケア。

## 主な演出

- 無影灯の消灯・再点灯、ドアの slam → lock、フォグ上昇、手続き音（ドリル風ノイズ、水滴、息づかい、心音）

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、診察台で眠る患者が見つかった。口の中の歯は、すべて抜かれていた。その医院は、三年前に閉院している。」

## 実装メモ

- 演出は `config.ts` のデータトリガー、`level.ts` はプリミティブのみ。共通土台は `kit/` 同梱。
