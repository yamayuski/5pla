# 隧道（old-tunnel）

## タイトル
隧道

## 一行ピッチ
山道で車が止まった。助けを呼ぶために入った古いトンネルの壁に、赤黒い手形が増えていく。

## 舞台
山道の旧トンネル「鬼首隧道」（昭和九年竣工）。ナトリウム灯がまばらに灯る一直線のトンネルで、中ほどの壁に非常ボタン、北の出口は「通行止め」の鉄柵で塞がれている。坑口の外に、エンストした自分の車。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 止まった車を降り、オレンジの灯りと水滴の音のトンネルへ。中ほどの非常ボタンを押す（interact）と、雑音と誰かの息づかいだけで応答は無い。車へ戻ろうとする。 |
| 1〜3分 | 小さな異変：①壁を叩く音、煤けた壁に赤黒い手形（1:08）②坑口の外で、止まったはずの車のクラクション（1:42）③自分の足音が半拍遅れてもう一つ聞こえ、手形が増える（2:16）④坑口側の灯りと車のライトが消える（2:48）。 |
| 3〜4分 | 逃げ道が塞がる：轟音と揺れ、坑口の天井が崩れて岩で埋まる（3:20）。手形が一気に増え、ライトが弱まり、灯りは通行止めの柵側に一つだけ。 |
| 4〜5分 | 最後の灯りとライトが消え、完全な暗闇（4:05）→ 両側の壁を叩く「ぺた、ぺた」が近づき、耳元で息づかい → 作業員の亡者が目の前に（大ジャンプスケア）→ エンディング。 |

## 主な演出
- 一直線のトンネルとフォグ、間隔の空いたナトリウム灯の暖色
- 手形が段階的に増える（2 → 4 → 8）。手形は TransformNode にまとめた小さな箱で構成
- 落盤（揺れ＋轟音＋岩）で戻り道を断つ
- 最後は暗闇型：何も見えない状態で音だけが近づき、一発（視覚より聴覚で怖がらせる）
- 手続き的な音：水滴、ノック（壁を叩く）、クラクション、二重の足音、落盤の轟音、息づかい、心音

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる（非常ボタン）、F：ライト

## エンディング
「鬼首隧道は昭和九年、工事中の落盤で多くの作業員が生き埋めになった。掘り出されなかった彼らは、今も内側から壁を叩いている。翌朝、坑口の脇で、エンジンのかかったままの車が見つかった。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / interact / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）。手形と落盤は TransformNode 単位で visible 切り替え
- 共通土台は `kit/` を同梱（自己完結）
