# 廃病院の巡回（hospital-patrol）

## タイトル
廃病院の巡回

## 一行ピッチ
閉鎖された病院を夜間巡回する警備員。誰もいないはずの402号室から、ナースコールが鳴りやまない。

## 舞台
閉鎖された総合病院の4階。南端の非常口から北端の402号室まで続く長い廊下（約24m）、東側のナースステーション、西側の病室401・403。床にはカルテが散らばり、壁際に車椅子と点滴スタンドが残っている。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 巡回開始。蛍光灯が弱く灯る廊下、遠くで水滴の音。病室やナースステーションを覗いて「ただの廃墟」に慣れさせる。 |
| 1〜3分 | 小さな異変：①壁際の車椅子が軋みながら廊下の中央へ転がる（1:15）②402号室の上の赤ランプが点き、ナースステーションのコールパネルにも「●402」（2:00）③背後でスリッパの足音（2:40）。 |
| 3〜4分 | 逃げ道が塞がる：非常口の扉が勢いよく閉まり施錠（3:15）。廊下の蛍光灯が落ち、懐中電灯だけになる。15秒後、ナースコールのベルと「……たすけて……」という囁き。目的が「402号室を確認する」に変わる。 |
| 4〜5分 | 402号室の扉に手をかける（E）→ 扉が内側から弾け開き、白衣の看護師が目の前に飛び込む（大ジャンプスケア）→ エンディング。5:20 までに開けなければ廊下で同じ看護師が襲う（保険）。 |

## 主な演出
- 暗闇と懐中電灯（SpotLight）、薄緑のフォグで病院らしい冷たさ
- 手続き的な音：水滴、車椅子の軋み、ナースコールのチャイムとベル、背後の足音、囁き、心音
- ドア：非常口の自動施錠（slam）、402号室の内側からの破裂的な開扉
- 車椅子が誰もいないのに動く（update フックで補間）
- 赤いナースコールランプとコールパネルの表示変化

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる・扉を開ける
- F：懐中電灯 ON/OFF

## エンディング
「402号室は十年前から空室だった。ナースコールの配線は、とうに切れていたという。翌朝、入口の鍵は内側から開いていた。」

## 実装メモ
- `config.ts` に演出トリガーを全てデータで記述（time / after / interact、requires / unless で保険のジャンプスケア）
- `level.ts` は MeshBuilder のプリミティブのみ。作品固有の演出（車椅子移動・コールパネル・402の開扉）は `custom` フックに分離
- 共通土台は `kit/` を同梱（自己完結）
