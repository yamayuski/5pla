# うしろの正面（bamboo-kagome）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

うしろの正面

## 一行ピッチ

夏祭りの帰り、近道の竹林の小径。手まりが転がり出て、四方から「かごめかごめ」が聞こえ、気づけば着物の子どもたちが自分の周りを回っている。歌の最後で、振り向いてはいけない。

## 舞台

夜の裏山の竹林（屋外、12m × 20m）。南北に細い小径が通り、中ほどに小さな広場と赤いよだれかけの地蔵、足元の小さな灯り。竹の葉の天井から月明かりがわずかに漏れ、霧が立ちこめる。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 笹の鳴る音。小径を進み、広場の地蔵に手を合わせる（E）。足元に小さな草履が六足。何もしなくても50秒で鈴が鳴る。 |
| 1:00〜3:00 | 異変①風が止み、竹林の奥で子どもの笑い声（1:15）②竹の間から手まりが転がり出て、小径の真ん中でぴたりと止まる（2:00）③四方から「かごめかごめ」の歌（2:40）。 |
| 3:00〜4:00 | 小径の入口と出口に竹が倒れて道が塞がる（3:25）。灯りが消え、着物の子ども6人が手をつないで自分の周りを回り始める。「動かずに、歌が終わるのを待つ」。 |
| 4:00〜5:00 | 輪が止まり、正面の子が笑う。「……うしろの正面、だあれ」。**振り向いた瞬間**、目の前に女の子（ジャンプスケア）。振り向かなくても8秒後に背後から息がかかり、同じく発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 童歌「かごめかごめ」を最後の一行まで引っ張る構成（字幕＋ささやき）
- プレイヤーを中心に子どもの輪が出現して回る（フック `ringForm`）、止まると正面役の子をカメラの正面に置く（フック `ringStop`）
- 最後は「振り向き」型（正面の子から視線を外した瞬間）。振り向かなくても逃れられない
- 倒れた竹で入口・出口を塞ぐ、灯りの消灯とライトの減光
- 手続き音：笑い声、手まりの音、ささやき、倒竹、息づかい、無音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（地蔵）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、竹林の地蔵の前で、祭りの帰りの子が一人見つかった。眠ったまま、何も覚えていなかった。地蔵の足元の草履は、七足に増えていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / lookAway / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。竹は固定シードの擬似乱数で配置（毎回同じ）
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
