# 消えた焚き火（camp-tent）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

トイレに行ったきり戻らない友達を迎えに行って戻ると、焚き火は消え、テントの中にみんなの影が並んでいた。

## 舞台

山あいのキャンプ場（深夜0時）。中央に焚き火、西に自分のテント、北へ約18mの暗い小道を進むとトイレ棟（個室3つ）。周囲は霧と森。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 焚き火のそばで薪をくべ（E）、友達の帰りを待つ。火の爆ぜる音だけの穏やかな時間。待ちきれず迎えに行く。 |
| 1:00〜3:00 | 暗い小道を北へ。①枝の折れる音 ②森の奥から友達の声 ③背後の砂利を踏む足音。トイレ棟で一番奥の個室から三回ノック。洗面台に友達のランタン（まだ温かい）。 |
| 3:00〜4:00 | トイレの入口が勝手に閉まり照明が落ちる。奥の個室の扉がひとりでに開くが、空っぽ。しばらくして鍵が外れる。戻ると焚き火は消え、テントの周りに人影が全員こちらを向いて立っている。 |
| 4:00〜5:00 | 自分のテントに逃げ込むとチャックが下ろされる。テントの壁に外の人影が映る。**それを見た瞬間**、管理人（十年前に閉鎖したはずの）が目の前に現れる（ジャンプスケア）。見なくても約12秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 焚き火の点光源を揺らし、薪で明るくなり、最後に消える（光源の明暗でテンポを作る）。
- 小道では懐中電灯が頼り。トイレ内は照明グループを落とす。
- 人影の群れ（影絵風シルエット）の表示切り替え、音は WebAudio 手続き生成。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E/クリック: 調べる、F: ライト、Esc: 一時停止
- ヘッドホン推奨

## エンディング

「ここは十年前に閉鎖しましたよ。誰が、入れたんです？」と管理人の言葉で締める。

## 実装メモ

- 起動: `/5pla/?horror=camp-tent`
- 屋外＋屋内（トイレ・テント）の往復、「帰り道が一番怖い」構成。
