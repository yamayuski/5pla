# 貯水槽点検（water-tank）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

貯水槽点検

## 一行ピッチ

マンション屋上の貯水槽点検。水位は満タンなのに、水面から誰かの息づかいが聞こえる。点検口を開けた先に。

## 舞台

マンション屋上の貯水槽室（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 屋上の貯水槽室で配管とバルブを点検する。 |
| 1:00〜3:00 | 異変①配管の奥を叩く音（1:10）②照明が瞬き足音が止まる（2:00）③配管の陰に濡れた髪の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。叩く音は点検口の内側から。開けて確かめるしかない。 |
| 4:00〜5:00 | 点検口を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 水音、叩く音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（点検口を開ける）、F: ライト

## エンディング

翌朝、管理会社は水質検査の結果に首をかしげた。 貯水槽の底から、昨夜の点検報告書が見つかった。署名欄は、水にふやけたあなたの名前だった。
