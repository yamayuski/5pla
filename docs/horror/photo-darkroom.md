# 現像室（photo-darkroom）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

現像室

## 一行ピッチ

祖父の写真館の暗室で、形見のフィルムを現像すると、一枚ごとに写真の中の少女が近づいてくる。

## 舞台

写真館の暗室（6m × 8m、天井高2.6m）。赤いセーフライトだけの暗い部屋。作業台に薬品のバット、引き伸ばし機、奥に写真を干す紐。入口は遮光扉。酢酸の匂いと水滴の音。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 引き伸ばし機にフィルムをセットして焼き付ける（E）。夏祭りで笑う浴衣の少女の写真が干し紐に。 |
| 1:00〜3:00 | 異変：一枚ずつ写真が増える。①同じ場所、少女がこちらを向く（1:20）②少女が目の前まで来ている（2:00）③撮影者の影が赤い光の中に写り込む（2:40）④肩に白い手を載せられた、自分と同じ白衣の後ろ姿（3:15）。 |
| 3:00〜4:00 | 入口の遮光扉が閉まって内側から施錠される（3:35）。干し紐の端に、ついさっきまで無かった六枚目（3:43）。 |
| 4:00〜5:00 | 六枚目を見ると、真っ暗な暗室の中で背後に白い顔。セーフライトが消え、**写真から目を離した瞬間**（または約22秒後）に背後から少女が現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 写真は文字板（sign）の visible 切り替えで、物語を「写っている内容」のテキストで見せる
- 赤いセーフライトの一色の世界、最後にそれが消えて完全な暗闇に
- 「見る → 目を離す」という lookAway 型の最後の一発
- 手続き音：水滴、ささやき、ガタつき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（引き伸ばし機）
- ヘッドホン推奨

## エンディング

「翌朝、写真館の暗室で、干し紐にかかった六枚の写真が見つかった。最後の一枚だけ、何も写っていない真っ黒な印画紙だったが、触れると、まだ濡れていた。祖父は、あの夏祭りの少女の写真を、生涯一枚も現像しなかったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
