# ひとり、多い（vet-clinic）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

ひとり、多い

## 一行ピッチ

夜の動物病院の見回り。入院札は4枚、ケージは3つ。最後の一つを確かめた瞬間、中にいたのは。

## 舞台

夜間の動物病院（約12m × 16m）。受付と待合、処置室の扉、奥の入院室にケージが並ぶ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 消毒液のにおいの静かな院内。奥の入院室を見回る。 |
| 1:00〜3:00 | 異変①犬が誰もいない隅にうなる（1:10）②照明が瞬き足音が止まる（2:00）③ガラス越しに白い服の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、受付の灯りが落ちる。ケージは3つ、入院札は4枚。最奥のケージを確かめるしかない。 |
| 4:00〜5:00 | 最奥のケージをのぞくと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 犬のうなり声、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（最奥のケージ）、F: ライト

## エンディング

翌朝、入院台帳に書いた覚えのない四つ目の名前が、自分の筆跡で書かれていた。
