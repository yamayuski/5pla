# 点検廊（dam-gallery）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

点検廊

## 一行ピッチ

ダムの堤体内の点検廊で水位計を読んで回る夜勤。あるはずのない水が足元から染み出し、水かさが増していく。

## 舞台

ダム堤体内の細長い点検廊（幅3m × 長さ40m、天井高2.6m）。濡れたコンクリート、籠付きの電球、西壁の太い配管、東壁に水位計が3か所。入口は水密扉、奥は鋼鉄の扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 水位計を三か所読んで回る（E）。一つ目は異常なし。二つ目は0.2m（堤体内に水位があるはずがない）。 |
| 1:00〜3:00 | 異変①ポンプが唸りだし、床に黒い水が染み出す（1:10）②壁の配管を内側から叩く音が移動してくる（1:55）③先に読んだ水位計の表示が「0.7m あなたの くび」に書き換わる（2:35）。 |
| 3:00〜4:00 | 入口の水密扉が閉まり、水かさが一気に増す。手前の電球から順に落ちていく（3:25）。廊下の奥の水面が盛り上がり、女が水から立ち上がって歩いてくる（3:39）。 |
| 4:00〜5:00 | 女が近づいてくる。**見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 床の水（半透明の箱）を `update` フックで徐々に上げる「じわじわ浸水」（floodOn / floodFast）
- 床の下から現れる女（Figure を床下に置き、`move` で立ち上がらせる）
- 水位計の差し替え、配管のノック音の移動、電球グループの順次消灯
- 手続き音：ポンプの重低音、ノック、ささやき、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（水位計）、F: ライト
- ヘッドホン推奨

## エンディング

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。水位の上昇だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
