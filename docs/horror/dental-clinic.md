# 閉院のあと（dental-clinic）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉院のあと

## 一行ピッチ

診察券を取りに戻った閉院後の歯科医院で、誰もいない診察台が回り始め、「次の方、どうぞ」と声がする。

## 舞台

閉院後の歯科医院の診察室（8m × 8m）。南壁中央が出入口、受付カウンタ、待合椅子、診察台と無影灯、器具トレー、壁のレントゲン写真。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 消毒液のにおいと水滴の音の中、受付の電話横で診察券を探す（E）。他人の名前の券だと気づく。 |
| 1:00〜3:00 | 異変①ドリルが一瞬唸る（1:15）②無影灯が点き診察台が勝手に向きを変える（2:00）③レントゲン写真に自分の名前と「歯が一本多い」（2:45）。 |
| 3:00〜4:00 | 出入口が勝手に閉まり施錠（3:25）。停電し、無影灯だけが診察台を照らす。背後で息づかい、「次の方、どうぞ」（3:35）。 |
| 4:00〜5:00 | 診察台にマスクの歯科医が現れる（4:00）。**見た瞬間**目の前に現れる（ジャンプスケア）。見なくても320秒付近で強制発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア。

## 主な演出

- 無影灯・停電・フラッシュライトの弱体化
- 出入口の slam → lock、フォグ増加
- 手続き音：ドリル、水滴、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、診察室には誰もいなかった。ただ診察台には、まだ温かい来院記録が一枚。今夜の患者の欄には、あなたの名前があった。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ
- 共通土台は `kit/` を同梱（自己完結）
