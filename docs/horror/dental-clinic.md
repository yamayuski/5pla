# 閉院後の診察室（dental-clinic）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉院後の診察室

## 一行ピッチ

閉院間際の歯科医院。壁を叩く音、変わるレントゲン、閉まる扉。診察台の向こうには、最初から先生が立っていた。

## 舞台

歯科の診察室（6m × 7m）。南壁に扉、東西にソファ、中央にテーブルとトレイとリモコン、北壁に大型レントゲン、天井に無影灯。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 遠くのドリル音が漏れる静かな個室。リモコンで曲を入れる（E）と無影灯が回る。40秒で自動再生。 |
| 1:00〜3:00 | 異変①遠くのドリル音が止み壁を内側から叩く（1:15）②レントゲンの歌詞が「たすけて／うしろにいる」に（2:05）③トレイからささやき（2:45）。 |
| 3:00〜4:00 | 扉が勝手に閉まりロック（3:25）。照明が赤に変わりライトが弱まる、背後で息づかい（3:35）。トレイを置き直すしかない。 |
| 4:00〜5:00 | 向かいの診察台の向こうに白衣の人影がトレイを握って座っている。**見た瞬間**目の前に現れる。見なくても約35秒で強制発生。 |

時間切れ救済: プレイ開始320秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 無影灯の紫から非常灯の赤への照明切り替え
- レントゲン表示の差し替え、扉の slam → lock、フォグ上昇
- 手続き音：ノック、ささやき、ノイズ、息づかい、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（リモコン・トレイ）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、衛生士は倒れたままの診察台を見つけた。カルテには十年前に閉院した医院の患者として、あなたの名前があった。」と表示して終了。
