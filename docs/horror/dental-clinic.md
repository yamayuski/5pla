# 深夜の歯科医院（dental-clinic）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

深夜の歯科医院

## 一行ピッチ

激しい歯の痛みで駆け込んだ深夜の歯科医院で、誰もいない診察室のドリルが回り、レントゲンの歯が一本増えていく。

## 舞台

街角の歯科医院（8m × 16m、天井高3m）。手前が待合室（受付ベル）、仕切りの奥が診察室（診察台・無影灯・レントゲン写真）。白と青緑の無機質な蛍光灯と消毒液のにおい。入口は自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 待合室の受付ベルを鳴らす（E）。奥から「少々お待ちください」とくぐもった声。 |
| 1:00〜3:00 | 異変①誰もいない診察室からドリルの音（1:10）②診察台がきしみながらひとりでに回る（1:50）③壁のレントゲン写真が自分の名前になり歯が一本増えている（2:30）④診察室の隅にマスクの医師が背を向けて立つ「口を開けてください」（3:05）。 |
| 3:00〜4:00 | 入口の自動ドアが閉まって開かず、照明が全て落ちる（3:25）。医師は消える。奥の壁のライトスイッチを入れるしかない。 |
| 4:00〜5:00 | スイッチを入れると無影灯がつき、診察台に誰かが横たわる。**約2秒後**（スイッチを入れなくても約60秒後）、起き上がった顔が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 診察台を `update` フックで少しずつ回転させる
- レントゲン写真は2枚の看板を `visible` で入れ替えて「歯が一本増える」
- 無影灯は group `op` のライトで、スイッチを入れると点灯
- 手続き音：ドリル（buzz）、ベル、きしみ、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（受付ベル・ライトスイッチ）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、出勤した歯科医師は、診察台に残る手形に気づいた。深夜の急患など受け付けていないはずなのに、受付のカルテにはひとり分の新しい名前があった。歯の数は、33本と書かれていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。診察台の回転だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
