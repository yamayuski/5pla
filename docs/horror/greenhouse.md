# 一夜花（greenhouse）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

一夜花

## 一行ピッチ

七年に一度だけ咲く巨大な花の開花を、夜の熱帯温室で一人記録する。ガラスに内側から手形が並び、葉が奥から順に揺れて近づき、つぼみの中から鼓動が聞こえる。

## 舞台

植物園の熱帯温室（屋内・ガラス張り、10m × 16m）。中央の通路の両側に背の高い熱帯植物、最奥に赤黒い巨大なつぼみと名札「開花予定：今夜」、記録用のカメラ三脚。湿気でガラスは曇り、外は真っ暗。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | むっとする湿気と水滴の音。通路の奥まで歩き、カメラで録画を始める（E）と花に照明が当たる。何もしなくても50秒でタイマーが作動する。 |
| 1:00〜3:00 | 異変①西のガラスを叩く音、曇ったガラスに手形が並ぶ……内側から（1:15）②奥から手前へ、植物の葉が順番に揺れていく。何かが植え込みの中をこちらへ歩いてくる（2:00）③つぼみの中から鼓動とささやき（2:45）。 |
| 3:00〜4:00 | 入口のガラス戸が閉まり自動で施錠（3:25）。照明が落ちて赤い非常灯、霧のような湿気が満ちる。暗がりの奥で花が開く。 |
| 4:00〜5:00 | 花の中を覗く（E）と、花びらの中心から濡れた黒髪の頭が持ち上がってくる。**それを見た瞬間**、目の前に迫る（ジャンプスケア）。覗かなくても開花から約35秒で花の中から立ち上がる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 一本道の通路と両側の植え込みで「見えない何か」が近づく：葉の揺れを奥から手前へ順番に伝える（フック `rustle`）
- 曇ったガラスの手形は内側から（＝温室の中に誰かいる）
- 花びらの開閉アニメーション（フック `bloomOpen`）
- ガラス戸の slam → lock、消灯と霧の濃度上昇
- 手続き音：水滴、ノック、足音、鼓動、ささやき、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（カメラ・花の鉢）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「朝、職員が温室に入ると、花はもう閉じていた。録画は午前二時で途切れている。花は今年、例年より一回り大きく育ったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。花びらは TransformNode のヒンジで開く
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
