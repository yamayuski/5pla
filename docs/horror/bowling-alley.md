# ストライク（bowling-alley）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

ストライク

## 一行ピッチ

閉店後のボウリング場で片付けをしていると、誰も投げていないのに2番レーンのピンがセットされ、奥のマスキングユニットが上がっていく。

## 舞台

深夜のボウリング場（16m × 22m、天井高4.2m）。4本のレーンが奥へ伸び、ピンデッキの手前にマスキングユニット。手前にボールラックとベンチ、頭上にスコア画面、紫のネオン。入口は手前の自動扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 閉店後の片付け。ボールラックのボールを戻す（E）。指穴に長い髪の毛が絡んでいる。 |
| 1:00〜3:00 | 異変①2番レーンの奥でピンのセット音（1:10）②頭上のスコア画面が「PLAYER 2：あなた」に切り替わる（1:50）③ボールリターンの奥から黒いボールが戻ってきてトレイに乗る（2:25）④奥のレーンの照明が消え、囁き「つぎは あなたの ばん」（3:00）。 |
| 3:00〜4:00 | 入口の扉が閉まる（3:25）。2番レーンの奥のマスキングユニットがゆっくり持ち上がっていく。ピンの間に濡れた髪の女が立っている（3:41）。 |
| 4:00〜5:00 | **女を見た瞬間**（または約10秒後）、女がレーンを一直線に駆けて、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- マスキングユニットを `move` で持ち上げ、奥のピンデッキに人影を見せる
- 見た瞬間に女がレーンを高速で駆けてくる（`move` 2.4秒）という「見たことへの報い」型
- ボールリターンのボール、スコア画面の差し替え、レーン照明の段階的消灯
- 手続き音：ピンのセット音、ボールリターンの転がる音、囁き、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ボールラック）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、2番レーンのスコアには、誰も投げていないはずの『X』が十回、並んでいた。ピンセッターの奥からは、一人分の濡れた足跡が、入口の扉へと続いていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
