# かかしの道（scarecrow-road）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

かかしの道

## 一行ピッチ

夜の田舎道を歩いて帰る途中、畑のかかしが目を離すたびに道へ近づいてくる。

## 舞台

街灯の少ない夜の田舎道（6m × 40m）。両側に畑、道の先に行き止まりの看板。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 畑のかかしを横目に道を進む。静かな虫の声。 |
| 1:00〜3:00 | 異変①藁のこすれる音（1:00）②かかしが増える・明滅（1:45）③背後の足音（2:30）④道脇にかかしが現れる（3:05）。 |
| 3:00〜4:00 | 街灯が消え、かかし全員がこちらを向く（3:35）。 |
| 4:00〜5:00 | 行く手に三体目のかかし。**目を向けた瞬間**（約18秒後に自動）に目の前へ。 |

時間切れ救済: 330秒で強制的にジャンプスケア。

## 主な演出

- 近づくかかし、街灯の消灯、足音、心音、明滅

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト

## エンディング

翌朝、かかしが一本増えていて、あなたの靴を履いていた、という後日談を表示して終了。

## 実装メモ

- `config.ts` に演出データ、`level.ts` はプリミティブのみ。`kit/` 同梱
