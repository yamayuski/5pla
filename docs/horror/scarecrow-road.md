# かかしの道（scarecrow-road）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

かかしの道

## 一行ピッチ

実家へ帰る夜の田んぼ道。道の両脇に並ぶかかしが、振り返るたびに、こちらを向いていく。

## 舞台

田んぼに挟まれた一本道（幅5m × 長さ約50m）。道の両脇の田んぼに、麦わら帽子のかかしが5体ずつ。奥に農家の灯り、手前にバス停の標識。月明かりだけの濃い夜、蛙の声と稲穂の音。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | バス停から実家へ歩く。かかしは全員、田んぼのほうを向いて立っている。 |
| 1:00〜3:00 | 異変①手前の四体のかかしが、道のほうを向いている（1:10）②田んぼの奥から、藁の擦れる音と囁き声。蛙の声が止む（1:50）③中ほどのかかしも向きが変わり、全員がこちらを見ている（2:25）④遠く、道の真ん中にかかしが一体立っている（3:00）。 |
| 3:00〜4:00 | 奥の農家の灯りが消え、濃い霧が出る（3:25）。道の真ん中のかかしが、棒の足で一歩ずつ近づいてくる（3:30〜）。 |
| 4:00〜5:00 | 道の真ん中のかかしがすぐそこまで来ている（約4:05）。**見た瞬間**（または約8秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- かかし10体を Figure で配置し、`face` アクション（プレイヤー方向へ向ける）で「振り返ると向きが変わっている」を段階的に作る
- 道の真ん中のかかしを `move` で長い時間をかけて近づける
- 蛙の声が止む「静寂」、濃くなる霧、農家の灯りの消灯
- 手続き音：藁の擦れる音、囁き、足音、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、田んぼ道に並ぶかかしは、十体のはずが十一体になっていた。一体だけ、麦わら帽子の下に、本物の人間の髪が生えていたという。実家の玄関の鍵は、内側から開いていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
