# かかしの一本道（scarecrow-road）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

かかしの一本道

## 一行ピッチ

終バスを逃して歩く夜の農道。振り向くたびに、脇に立つかかしが少しずつ道へ近づいている。

## 舞台

街灯のない農道（幅6m × 長さ26m）。両脇に垣根とかかし3体、奥に鉄の門。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 虫の声の中、一本道を歩き出す。脇にかかしが立っている。 |
| 1:00〜3:00 | 異変①手前のかかしが道に近づく（1:10）②藁を踏む音と右のかかしの移動（2:00）③耳元のささやき（2:50）。 |
| 3:00〜4:00 | 奥の鉄門が勝手に閉まり施錠（3:25）。ライトが弱まり、道の真ん中に見知らぬかかしが現れる。 |
| 4:00〜5:00 | **そのかかしを見た瞬間**、目の前に現れる（ジャンプスケア）。見なくても320秒で強制発生。 |

## 主な演出

- フォグ、懐中電灯、藁のこすれる音、門のslam/lock

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、F: ライト

## エンディング

「翌朝、農道には誰もいなかった。畑のかかしは、昨日より一体多く並んでいたという。」

## 実装メモ

- `config.ts` にトリガーをデータで記述、`kit/` 同梱
