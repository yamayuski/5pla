# 景品はあなた（arcade-claw）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

景品はあなた

## 一行ピッチ

終電を逃して入った深夜のゲームセンター。誰も操作していないクレーンゲームのアームが動きだし、景品ボックスの中に誰かが入っていた。

## 舞台

24時間営業のゲームセンター（12m × 14m、天井高3.2m）。ネオンと電子音。中央の列にクレーンゲーム台が3台、壁沿いにビデオゲームの筐体、入口に降ろせるシャッター。店員はおらず、客も自分だけ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 手前のクレーンゲームで遊ぶ（E）。アームがぬいぐるみを掴んで、落とす。 |
| 1:00〜3:00 | 異変①誰も操作していないのに3台のアームが一斉に動きだす（1:10）②全台の画面表示が「あそんで」に変わる（1:55）③一番奥の台の取り出し口で、ごとんと音がして笑い声（2:35）。 |
| 3:00〜4:00 | 入口のシャッターが降りて開かない。フロアの照明が落ち、台の画面だけが光る（3:25）。一番奥の台の景品ボックスの中で何かが動き、ガラスを内側から叩く（3:34）。 |
| 4:00〜5:00 | **ボックスの中の女を見た瞬間**（または約28秒後）、ガラスを割るように目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- アームを実際に横へ動かす（`update` / `custom` フック）。景品や画面の表示を `visible` で差し替え
- ガラス（半透明）越しの狭い箱の中に女を閉じ込めて見せる
- 手続き音：電子音のブザー、チャイム、笑い声、ノック、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（クレーンゲーム）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、店長がクレーンゲームの景品の補充に行くと、一番奥の台の景品の中に、見覚えのないスマートフォンが一つ紛れ込んでいた。ロック画面の通知は、百件を超える不在着信だった。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。アームの動きだけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
