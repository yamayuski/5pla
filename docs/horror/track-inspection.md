# 点検は二人一組（track-inspection）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

点検は二人一組

## 一行ピッチ

終電後の地下鉄の保線通路。点検は二人一組のはずなのに、相棒の姿が見えない。信号の箱を開けた先に。

## 舞台

地下鉄の保線用通路（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 地下鉄の保線通路で設備を点検していく。 |
| 1:00〜3:00 | 異変①無線に謎の声が入る（1:10）②照明が瞬き足音が止まる（2:00）③通路の奥に作業服の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。無線の声は信号機の箱を指している。開けるしかない。 |
| 4:00〜5:00 | 信号機の箱を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 無線の雑音、トンネルの風、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（信号機の箱を開ける）、F: ライト

## エンディング

翌朝、保線区の点呼で係長が言った。「昨夜の入線は、あなた一人です」 信号機の箱の中から、相棒のヘルメットが見つかった。内側に、あなたの名前が書いてあった。
