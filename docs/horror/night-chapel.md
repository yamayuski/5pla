# 告解室（night-chapel）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

告解室

## 一行ピッチ

古い教会の夜の戸締まり当番。祭壇のろうそくを消すと、聖母像がこちらを向き、壁際の告解室から「告白をお聞きします」という声がする。

## 舞台

町外れの古い教会の礼拝堂（10m × 20m、天井高6m）。中央の通路の左右に長椅子が6列、高窓のステンドグラス、北の祭壇に十字架と二本のろうそく、西の壁際に木造の告解室。入口は南の大扉。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 祭壇の二本のろうそくを消す（E）。ステンドグラスから青い月明かりだけが残る。 |
| 1:00〜3:00 | 異変①誰もいないパイプオルガンが一音だけ鳴る（1:15）②祭壇脇の聖母像が、いつの間にかこちらを向いている（1:55）③前の長椅子に祈る黒い人影が三つ現れる（2:35）④告解室から内側のノック「告白をお聞きします」（3:05）。 |
| 3:00〜4:00 | 大扉が閉まって開かず、月明かりも消える（3:25）。祈っていた人影が全員こちらを振り返る。告解室の戸がひとりでに開く（3:37）。 |
| 4:00〜5:00 | 暗がりに黒い司祭服の男が座っている。**見た瞬間**（または約12秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 聖母像（人影の流用）を `face` アクションでこちらに向ける「目を離した隙に向きが変わる」演出
- 告解室の戸を実際に開閉し、暗がりに人影を座らせる
- ステンドグラスの青い光（ライトグループ）を最後に消して闇に落とす
- 手続き音：オルガンの低音、きしみ、ささやき、ノック、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ろうそく）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、教会の神父は告解室の中で、見知らぬ男の告白の記録を見つけた。日付は、五十年前。最後の一行は『次は、あなたの番です』。祭壇のろうそくは、二本とも、まだ温かかった。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
