# 格安物件の内見（model-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

格安物件の内見

## 一行ピッチ

相場の半額の部屋を内見中、不動産屋が電話に出て席を外した間に、部屋の中で少しずつ異変が増え、笑顔のままの男が戻ってくる。

## 舞台

家具のない1LDK（8m × 11m、天井高2.6m）。西にクローゼット、東に掃き出し窓とカーテン、奥に台所。暖色の室内灯。玄関のドアは外の廊下に面している。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 不動産屋が「少し、電話をしてきます」と出ていく（0:25）。台所の蛇口をひねる（E）と、最初だけ赤茶色に濁る。 |
| 1:00〜3:00 | 異変①クローゼットの戸がひとりでに開く（1:15）②窓のカーテンがひとりでに端へ寄る（1:55）③クローゼットの奥で携帯の着信音（2:35）④背後の床板のきしみ（3:10）。 |
| 3:00〜4:00 | 玄関のドアが閉まって鍵がかかり、全部の明かりが消える（3:25）。ノックと「いかがでしたか？」（3:37）。 |
| 4:00〜5:00 | 鍵が回りドアが開き、逆光の中に笑顔のままの不動産屋が立って近づいてくる。**目を向けた瞬間**（または約9秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- クローゼットの戸は `door` アクション、カーテンは `move` で動かす
- 玄関の外の廊下の灯りと逆光、笑顔のままの不動産屋が `move` で近づく
- 手続き音：水滴、きしみ、ささやき、着信音（phone）、足音、ノック、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（蛇口）、F: ライト
- ヘッドホン推奨

## エンディング

「後日、不動産会社に問い合わせると、『その物件も、そんな社員も、うちにはいません』と言われた。部屋の住所は、三年前に取り壊された建物のものだった。契約書には、あなたのサインが、すでに入っていたという。」と表示して終了。
