# 試着は最後のお客様まで（fitting-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

試着は最後のお客様まで

## 一行ピッチ

閉店間際の無人の服屋。奥の試着室から「サイズ、ありますか」と声がして、閉まったカーテンの中に誰かが立っている。

## 舞台

駅ビルの小さなアパレル店（約8m × 14m）。入口に自動ドア、服のラック、奥に試着室が3つ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 明るい店内。レジのベルを鳴らしても返事がない（40秒で自動で鳴る）。 |
| 1:00〜3:00 | 異変①ハンガーが一斉に揺れる（1:15）②左の試着室のカーテンが開く（2:05）③中央のカーテンから声「サイズ、ありますか」（2:50）。 |
| 3:00〜4:00 | 入口が閉まり消灯（3:25）。中央のカーテンが消え、白い服の女が立っている。 |
| 4:00〜5:00 | 女から目を逸らした瞬間にジャンプスケア。逸らさなくても約45秒後、330秒で発生。 |

## 主な演出

- 店内照明の消灯、自動ドアの slam / lock、懐中電灯
- ハンガーの揺れ、カーテン、中央の試着室の人影
- 手続き音：ベル、きしみ、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

朝、試着室に畳まれた客の服と「お客様のサイズです」のタグだけが残る。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリとフック（swingHangers）。lookAway 型の結末。
