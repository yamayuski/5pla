# サウナ室（sauna-room）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

サウナ室

## 一行ピッチ

深夜営業のスパのサウナ室。砂時計を返して我慢していると、奥の隅に、壁を向いて立つ女がいた。

## 舞台

深夜営業スパのサウナ室（5m × 5m、天井高2.6m）。杉の板張り、二段のベンチ、北に石を積んだストーブ、壁に温度計と砂時計。蒸気で視界が白く、熱気で息が重い。出入口は手前のガラス戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | サウナストーンに水をかける（E）と蒸気が立ちのぼり、視界が白くなる。ほかの客はいない。 |
| 1:00〜3:00 | 異変①奥の隅にバスタオルを巻いた女が、壁を向いて立っている。入ってきた音はしなかった（1:10）②温度計が勝手に95度、110度と上がる（2:00）③砂時計の砂が全部落ちている。まだ三分のはずなのに（2:40）④女の肩が上下し、呼吸の音が自分のものと重ならない（3:05）。 |
| 3:00〜4:00 | ガラス戸が閉まり、取っ手が回らない。温度計は130度。灯りが落ち、ストーブの赤だけが残る（3:25）。女がゆっくりこちらを向き、湯気の中を近づいてくる（3:35）。 |
| 4:00〜5:00 | 女が目の前まで来る。**見た瞬間**（または約6秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 蒸気をフォグ濃度（fog アクション）で表現し、ロウリュのたびに視界を白く落とす
- 温度計・砂時計を文字板の差し替えで見せる
- 壁を向いて立つ人影が、`face` + `move` でゆっくり近づく
- 手続き音：蒸気のノイズ、軋み、息づかい、ささやき、心音

## 操作方法

- WASD / 矢印: 移動（狭い）、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ストーブの石）
- ヘッドホン推奨

## エンディング

「翌朝、清掃員がサウナ室の扉を開けると、ベンチに、乾ききった女物のバスタオルが一枚だけ畳まれていた。温度計は百三十度を指したまま、前の晩から、一度も下がっていなかったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
