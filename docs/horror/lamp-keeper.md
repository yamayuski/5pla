# 灯台の夜（lamp-keeper）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

灯台の夜

## 一行ピッチ

嵐の夜、無人の灯台で灯りを回し続けるだけのはずが、階段を濡れた足音が一段ずつ上ってくる。

## 舞台

灯台最上階の管理室（6m × 6m）。南壁中央が階段への扉、奥に灯室の装置、東壁に無線機、机に灯台日誌。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 嵐の灯台に入る。装置を調べて灯りを点ける（E）。何もしなくても55秒で点く。 |
| 1:00〜3:00 | 異変①最上階の窓を外から叩く音（1:15）②階段から濡れた足音（2:00）③無線機が勝手に鳴る（2:40）。 |
| 3:00〜4:00 | 突風で階段の扉が閉まり開かない（3:20）。灯りが消え、背後で息づかい。装置を調べて灯りを戻すしかない。 |
| 4:00〜5:00 | 灯りが戻ると装置の前にずぶ濡れの灯台守が立っている。**見た瞬間**ジャンプスケア。見なくても約30秒で強制発生。 |

時間切れ救済: 320秒で強制ジャンプスケア。

## 主な演出

- 机のランプのみの暗い部屋、フラッシュライト、フォグ、扉のslam+lock、手続き音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

「夜明けに交代が着いたとき、灯台の灯りは消えていた。日誌の最後の行には「異常なし」と、濡れた文字が増えていたという。」
