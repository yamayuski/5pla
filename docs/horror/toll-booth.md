# 深夜の料金所（toll-booth）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

深夜の料金所

## 一行ピッチ

廃止予定の高速料金所を深夜に巡回する。勝手に上下するバー、隅の人影、増える通行記録のあと、戸が閉まり、精算ボタンが赤く点滅しはじめる。

## 舞台

深夜の料金所事務所（約6m × 8m）。奥に精算窓口、西壁に通行記録票、天井に揺れるバー。入口は南の戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 冷えた事務所を点検する。50秒で外のゲートバーが勝手に上下する。 |
| 1:00〜3:00 | 異変①ブースの奥に小さな制服の人影、目を逸らすと消える（1:35）②通行記録に「あなたの車」（2:30）③放送が一度だけ鳴る（3:10）。 |
| 3:00〜4:00 | 戸が閉まりロック、事務所の明かりが落ち（3:35）、窓口の精算ボタンだけが赤く点滅する。 |
| 4:00〜5:00 | 精算ボタンを押す（E）と「料金　あなた」のレシート。顔を上げると窓の奥に係員が立っており、ジャンプスケア。押さなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 警告音・放送・背後の気配、閉ざされる戸
- lookAway で消える人影、増える通行記録

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（精算ボタン）、F: ライト

## エンディング

「翌朝、交代の職員が窓口で見つけたのは、一枚のレシートだった。『料金　あなた』。通行記録には、昨夜の巡回員の名前が一件増えていた。」

## 実装メモ

- ゲートバーの揺れは custom フック barSwing。記録票は visible で出す。
