# 合鍵（key-shop）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

合鍵

## 一行ピッチ

深夜の合鍵屋で店番をしていると、誰もいない作業台から「開けてください」と声がして、鍵を削る音が止まらない。

## 舞台

駅前の合鍵屋（約8m × 14m）。入口にシャッター、壁一面の鍵、奥の作業台、手前の合鍵マシンと店の電話。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の店内。合鍵マシンを確認する（刃が勝手に回る）。 |
| 1:00〜3:00 | 異変①電話「あなたの家の合鍵」（1:10）②作業台から鍵を削る音（2:00）③「開けてください」の声（2:45）。 |
| 3:00〜4:00 | シャッターが落ちて消灯（3:25）。作業台に人影、背後に足音。 |
| 4:00〜5:00 | マシンを止めようとすると人影が目の前に現れる（ジャンプスケア）。触らなくても330秒で発生。 |

## 主な演出

- 蛍光灯→消灯、シャッターの slam / lock
- 赤く光る合鍵マシン、作業台の人影
- 手続き音：ブザー、ノック、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝、無人の店と、店主の家と同じ形の合鍵が残る。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。
