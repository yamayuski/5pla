# 百の鳥居（torii-road）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

百の鳥居

## 一行ピッチ

祖母の遺言で夜の参道を登ると、鳥居の数が合わなくなり、鳥居の下に立つ白い装束の人影が、明滅のたびに近づいてくる。

## 舞台

夜の山の参道（屋外、幅6m × 長さ54m）。朱の鳥居が奥へ連なり、石灯籠の橙の灯りが点々と並ぶ。突き当たりに小さな社。濃い霧、虫の声。入口の札には「振り返るべからず」。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 参道を進む。鳥居の数を数えながら奥の社を目指す。 |
| 1:00〜3:00 | 異変①背後で足音、自分の歩調と少しずれている（1:05）②明滅した一瞬で入口に近い鳥居が三つ消える（1:50）③遠い鳥居の下に白い装束の人影、背を向けている（2:30）④明滅のたびに人影が近づく（3:05）。 |
| 3:00〜4:00 | 灯籠が全部消え、後ろの鳥居が闇に溶ける。濃い霧で前に進むほかない（3:25）。 |
| 4:00〜5:00 | 人影が鳥居をくぐってこちらを向いて歩いてくる（3:31）。**目を向けた瞬間**（または約18秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 鳥居は TransformNode のグループで、`visible` で背後の鳥居を消していく
- 神職の人影は `move` と明滅で段階的に近づき、最後に `face` でこちらを向く
- 灯籠の消灯、霧の濃化（`fog`）、鈴、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、麓の宮司が参道を確かめると、鳥居は全部で九十九基しかなかった。足りないはずの一基は、どれほど探しても見つからなかったという。参道の入口には、ひとり分の足跡だけが、奥へ向かって続いていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
