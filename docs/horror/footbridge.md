# 歩道橋（footbridge）

## タイトル
歩道橋

## 一行ピッチ
終電後の近道の歩道橋。押しボタンを押した瞬間から、背後で手すりを叩く音が付いてくる。

## 舞台
深夜の国道をまたぐ細長い歩道橋。白い街灯が点々と並び、中ほどに押しボタン箱がある。橋の下には車が一台も通らない。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | 白い街灯と静けさの中、橋の中ほどの押しボタンを押す（interact）。信号は変わらず、背後で手すりを握る音。 |
| 1〜3分 | 小さな異変：①手すりを叩く音（1:08）②橋の下でトラックのクラクションが鳴り続ける（1:42）③足音が半拍遅れてもう一つ（2:16）④南側の街灯が消える（2:48）。 |
| 3〜4分 | 橋の両端に鉄の柵が降り（3:20）、揺れと轟音で閉じ込められる。街灯が順に消える。 |
| 4〜5分 | ライトも消えて完全な暗闇 → 両側の手すりを叩く音が近づき、耳元で息づかい → 白い服の人影が目の前に（大ジャンプスケア）→ エンディング。 |

## 主な演出
- 一直線の橋、フォグ、点々と並ぶ街灯が順に消える
- 両端に出現する柵で逃げ道を断つ
- 暗闇型：音だけが近づく

## 操作方法
- クリックで開始（ポインターロック）
- WASD / 矢印キー：移動、マウス：視点
- E / クリック：調べる、F：ライト

## エンディング
「この歩道橋は、夜ごと誰かを待っているという。渡りきれた者は、いない。翌朝、橋の中ほどに、片方だけの靴が揃えて置かれていた。」
