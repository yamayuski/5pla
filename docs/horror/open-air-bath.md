# 貸切露天風呂（open-air-bath）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

貸切露天風呂

## 一行ピッチ

山の宿の貸切露天風呂で、ほかに客はいないはずの湯船に、人の頭が一つ、また一つと浮かび、静かに近づいてくる。

## 舞台

山の宿の露天風呂（屋外、デッキ12m × 8m、奥に湯船8m × 8m。湯船には入れない）。木の柵、石の縁、灯籠の橙の灯り、濃い湯気、硫黄のにおい。脱衣所への戸は後ろで閉まる。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 湯船の縁で湯加減を見る（E）。ぬるい湯の中で、指先に細い髪が一本絡みつく。 |
| 1:00〜3:00 | 異変①湯船の奥に人の頭が浮かぶ、背を向けている（1:10）②右手にもう一つ頭が浮かぶ（1:55）③奥の頭が波も立てずに近づく（2:35）④明滅のあと二つの頭がこちらを向く（3:05）。 |
| 3:00〜4:00 | 脱衣所の戸が閉まって開かず、灯籠が全部消えて濃い湯気に包まれる（3:25）。 |
| 4:00〜5:00 | 二つの頭が沈み、目の前の縁に三つ目の頭が浮かぶ（3:32）。**目を向けた瞬間**（または約12秒後）、湯から飛び出す（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 湯面に浮かぶ頭は TransformNode のグループで、`move` と `face` で近づく・振り向く
- 濃い湯気（`fog`）と灯籠の消灯、水滴音、ささやき、心音
- 湯船は透過した水面と見えない壁で入れないようにしている

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（湯船の縁）、F: ライト
- ヘッドホン推奨
