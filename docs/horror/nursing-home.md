# 空室のナースコール（nursing-home）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

空室のナースコール

## 一行ピッチ

老人ホームの夜勤で、空室のはずの4号室からナースコールが鳴り、車椅子がひとりでに近づいてくる。

## 舞台

老人ホームの居室廊下（5m × 24m、天井高2.8m）。西側に居室の扉1〜4号室、東側にナースステーションとコール盤。4号室は先月から空室。暖色の薄暗い非常灯。出入口は自動ドア。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ナースステーションのコール盤を確認する（E）。異常なし。4号室は空室。 |
| 1:00〜3:00 | 異変①2号室からナースコール（1:10）②2号室の扉がひとりでに開き、ベッドは空でシーツがへこんでいる（1:50）③奥の車椅子が無人でこちらへ走ってくる（2:30）④空室の4号室からナースコール（3:05）。 |
| 3:00〜4:00 | 出入口の自動ドアが閉まって開かず、廊下の灯りが落ちる（3:25）。4号室からベルの音。 |
| 4:00〜5:00 | 4号室の扉を開ける（E）と、ベッドの上の人影が飛びかかる（ジャンプスケア）。開けなくても約60秒後に扉が開く。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- コール盤の表示は看板を `visible` で切り替える（呼出なし→2号室→4号室）
- 居室の扉は `door` アクションでひとりでに開く
- 車椅子は TransformNode ごと `move` で廊下を走る
- 手続き音：ナースコールのベル、きしみ、ゴロゴロ音（rumble）、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（コール盤・4号室の扉）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、早番の職員がコール盤を見ると、4号室の呼び出しランプが点いたままだった。4号室のベッドには誰も寝ていないのに、シーツが温かかったという。夜勤の職員は、その日から連絡がつかない。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
