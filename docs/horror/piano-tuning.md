# 調律（piano-tuning）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

調律

## 一行ピッチ

閉館後の音楽ホールでピアノの調律。弾いていないのに、鍵盤がひとつずつ、こちらの足音に合わせて鳴る。蓋の下に。

## 舞台

閉館後の音楽ホールの舞台袖（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 鍵盤の音を一つずつ確かめる。 |
| 1:00〜3:00 | 異変①椅子が倒れる（1:10）②照明が瞬き足音が止まる（2:00）③客席の陰に正装の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。和音は蓋の下から鳴っている。開けるしかない。 |
| 4:00〜5:00 | ピアノの蓋を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- ピアノの音、客席のざわめき、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ピアノの蓋を開ける）、F: ライト

## エンディング

翌朝、調律師の道具箱だけが舞台に残されていた。 ピアノの弦の一本は、あなたの声と同じ高さで鳴り続けていた。
