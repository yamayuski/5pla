# 残業中（overtime-office）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

残業中

## 一行ピッチ

午前二時、オフィスに一人残って報告書を仕上げる。人感センサーの照明が奥から消え、誰も触れていない複合機が紙を吐き出し、社内チャットに「まだいますか」と届く。

## 舞台

オフィスビル12階の営業フロア（12m × 12m）。島型のデスクが2列、北西に空席の課長席、北東に複合機、東は一面の窓で夜景。南にエレベーターホールへのガラス扉（セキュリティ付き）。天井灯は3列で、奥から順に消える人感センサー式。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 空調の唸りと夜景。自分の席で報告書を保存する（E）。何もしなくても45秒で自動保存。 |
| 1:00〜3:00 | 異変①奥の照明が消える。動くものに反応するはずのセンサーなのに（1:15）②誰も操作していない複合機が紙を吐き出し、床に散らばる（2:00）③画面に社内チャット「おつかれさまです　まだいますか」、課長席の椅子がきいと回る（2:45）。 |
| 3:00〜4:00 | 「セキュリティを開始します」。ガラス扉が閉まりロック、中ほどの照明も消える（3:25）。続いて最後の照明が消え、非常口の緑の灯りとライトだけ。複合機の前に一枚だけ表を向いた紙。 |
| 4:00〜5:00 | 紙を拾う（E）と、防犯カメラの画像。デスクで画面を見つめる自分と、その真後ろに立つ人。撮影時刻は今。自分の席の方を振り返り**その人を見た瞬間**、目の前に迫る（ジャンプスケア）。拾わなくても消灯から約35秒で椅子の軋む音とともに現れる。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 照明が奥→中→手前と一列ずつ消え、暗闇が近づいてくる
- 画面・複合機のパネル・印刷物（DynamicTexture）での「誰かいる」サイン
- ガラス扉の slam → lock（セキュリティ開始のチャイム付き）
- 最後は「さっきまで自分がいた場所に誰かがいた」と知らされてから振り返る構成
- 手続き音：空調（ドローン）、チャイム、蛍光灯のブザー、紙の音、椅子の軋み、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（自分のPC・複合機）、F: ライト（消灯後に自動で点く）
- ヘッドホン推奨

## エンディング

「朝、出社した同僚たちは、きちんと保存された報告書を見つけた。防犯カメラには、午前二時から朝まで、デスクの前に立ち続ける二人の姿が映っていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。散らばる紙は TransformNode でまとめて表示
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
