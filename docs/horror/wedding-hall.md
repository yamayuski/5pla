# ご祝儀袋（wedding-hall）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

ご祝儀袋

## 一行ピッチ

友人の結婚式の二次会のあと、忘れたご祝儀袋を取りに戻った無人の宴会場で、誰もいないはずのスクリーンが点き、司会の声がケーキ入刀を告げる。

## 舞台

結婚式場の宴会場（16m × 20m、天井高4.5m）。白いクロスの丸テーブルが6卓、中央通路の奥にウェディングケーキ、北にステージとスクリーン、入口のロビー。シャンデリアの暖色の灯りだけが残る。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 片付けの途中の宴会場へ入り、自分の席のテーブルで袋を探して拾う（E）。宛名が空白で、裏に赤い字で「おめでとう」が何度も。 |
| 1:00〜3:00 | 異変①ステージのスクリーンが勝手に点き、新婦の名前が黒塗りになっている（1:10）②司会の声「新郎新婦のご入場です」。ステージにスポットが当たるが誰もいない（1:52）③各テーブルに黒い礼服の客が着席し、ステージを向いて拍手している（2:30）。 |
| 3:00〜4:00 | 入口の扉が閉まり、シャンデリアが消える。通路の奥のケーキだけにスポットが当たる（3:25）。「初めての共同作業です。ケーキ入刀を、あなたの手で」（3:35）。 |
| 4:00〜5:00 | ケーキに入刀する（E）と、ケーキの陰から花嫁が目の前に現れる（ジャンプスケア）。入刀しなくても約42秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- スクリーンの文字板の差し替え（祝辞 → 黒塗りの新婦欄）
- 着席する黒い人影を TransformNode ごと visible 切り替え
- ライトグループ（シャンデリア／スポット／ケーキ）を順に切り替え、暗闇の中でケーキだけを照らす
- 手続き音：チャイム、司会の囁き声、拍手代わりのざわめき、ケーキ入刀の衝撃音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（袋・ケーキ）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、式場のスタッフがウェディングケーキの前で、見覚えのない封筒を一通、拾い上げた。宛名には、今日の式の新婦の旧姓。新婦は十年前、同じ会場で、式の当日に亡くなっていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
