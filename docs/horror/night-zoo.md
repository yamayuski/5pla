# 閉園後の見回り（night-zoo）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

閉園後の見回り

## 一行ピッチ

動物園の夜間警備の初日。空っぽに見える檻の奥で赤い目が増えていき、入口が閉まる。最後の檻に座っていた人影から、目を逸らしてはいけなかった。

## 舞台

閉園後の動物園の通路（幅4m × 長さ26m）。左右に3つずつ檻、入口にゲート、最後の右の檻に人影。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 札だけが並ぶ静かな通路。動物の気配がない。 |
| 1:00〜3:00 | 異変①最初の檻に赤い目（1:15）②背後で鉄格子を爪でなぞる音（2:00）③全ての檻に目が並び、最後の檻に人が座っている（2:45）。 |
| 3:00〜4:00 | 入口のゲートが落ちて閉じ込められる（3:25）。灯りと目が消える。 |
| 4:00〜5:00 | 背後から囁き。最後の檻の人影から目を逸らした瞬間、**目の前に現れる**（ジャンプスケア）。 |

時間切れ救済: 330秒で強制的にジャンプスケア。

## 主な演出

- 檻の赤い目の点滅（フック `eyesOn1` / `eyesAll` / `eyesOff`）
- ゲートが落ちる（slam＋lock）、霧、消灯
- 手続き音：鉄格子、足音、囁き、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト

## エンディング

翌朝、新しい檻が一つ増えていた。札には「新入り・目を逸らすと出てきます」。

## 実装メモ

- 共通キット `@5pla/horror-kit` を使用（config / level / index の3ファイル）
- lookAway 型の結末（見つめ続けるほど安全という逆転）
