# お盆の墓参り（night-cemetery）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

お盆の墓参り

## 一行ピッチ

お盆の夜、一人で先祖の墓に線香をあげに来た寺の墓地で、墓石の文字が書き換わり、家の墓の前の土が盛り上がる。

## 舞台

寺の墓地の参道（幅3m × 長さ約32m）。左右に墓石が並び、石灯籠の橙の灯り、突き当たりに自分の家の墓。入口の門は鉄の格子。虫の音と砂利を踏む足音、濃い夜霧。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 参道を歩いて、突き当たりの家の墓に線香をあげる（E）。墓石の没年が、今年になっている。 |
| 1:00〜3:00 | 異変①墓石の文字がすべて赤い字「ここに おいで」に書き換わる（1:10）②手前の石灯籠の火が消え、背後で湿った足音（1:55）③左手の墓の土から白い指が五本突き出す（2:35）④家の墓のほうから読経のような声と鈴の音（3:05）。 |
| 3:00〜4:00 | 背後の門が閉まり、鎖の音。石灯籠が消え、家の墓の前の土が新しく盛られている（3:30）。盛り土が崩れ、濡れた白装束の女が土の中から這い上がる（3:40）。 |
| 4:00〜5:00 | **女を見た瞬間**、女が参道を駆け寄って目の前に現れる（ジャンプスケア）。見なくても約22秒後に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 墓石の文字板をグループごと差し替え（家名 → 赤い字）
- 石灯籠のライトグループを段階的に消し、闇と霧を濃くする
- 床下に置いた女を `move` で盛り土の上へ這い上がらせ、見た瞬間に走らせる
- 手続き音：読経のような囁き、鈴、足音、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（家の墓）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、住職が墓地を見回ると、家の墓の前に、新しい線香が一本、まだ燃えていた。墓石の没年は、昨日までの日付に戻っていたが、刻まれた名前は、昨夜参りに来た人のものだったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
