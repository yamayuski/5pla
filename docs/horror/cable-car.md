# 宙づり（cable-car）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

宙づり

## 一行ピッチ

最終便のロープウェイが谷の真上で止まり、屋根の上から足音が聞こえはじめる。やがて窓の外に、逆さまの顔が張り付く。

## 舞台

夜の山岳ロープウェイのゴンドラ内（3m × 4m、天井高2.4m）。腰から上がガラス張りで、外は霧と麓の町の遠い灯り。乗客は自分ひとり。インターホンが西の壁に付いている。狭い空間に閉じ込められた状態から動かない。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 最終便で山頂へ。窓の外の夜景を眺める。インターホン（E）を押すと「山頂までおよそ七分です」と録音の声。 |
| 1:00〜3:00 | 異変①ゴンドラが急停止し、宙づりのまま揺れる（0:55）②向かいの下りゴンドラとすれ違う。窓に誰かが張り付き、顔だけがこちらを向いている（1:40）③屋根の上を誰かが歩く足音（2:20）④インターホンが勝手に鳴り「そこからはおりられません」（2:55）。 |
| 3:00〜4:00 | 車内の灯りが消えてライトが弱まる（3:25）。東の窓の外から叩く音。暗がりに、逆さまにぶら下がった白い顔の輪郭。 |
| 4:00〜5:00 | **逆さの顔を見た瞬間**（または約42秒後）、窓から目の前に女が現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 狭い密室（ガラス張り）で「見ない」「見る」の葛藤を作る
- 向かいのゴンドラを TransformNode ごと move でスライドさせ、中の人影を一瞬だけ見せる
- 逆さの女は Figure を `rotation.z = π` で反転して窓の外に配置（ジャンプスケア用は別個体）
- 手続き音：軋み、屋根の足音、ノック、インターホンのノイズとささやき、心音

## 操作方法

- WASD / 矢印: 移動（狭い）、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（インターホン）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、運行を再開したロープウェイの山頂駅で、一台のゴンドラの窓に、外側からびっしりと手形が残されているのが見つかった。中に乗っていたはずの人は、どこにもいなかった。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / unless）
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
