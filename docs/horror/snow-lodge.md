# 雪の山小屋（snow-lodge）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

雪の山小屋

## 一行ピッチ

吹雪の夜、避難小屋で火を入れて朝を待つだけのはずが、床に自分のものではない濡れた裸足の足跡が増えていく。

## 舞台

雪山の無人避難小屋（8m × 8m）。南壁中央が出入口、西壁に二段ベッドと薪の山、奥に薪ストーブ、東壁に霜のついた窓、中央に木のテーブル、棚に古い無線機。戸の外は吹き溜まりの雪。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 吹雪の音の中、凍える小屋に入る。薪ストーブに火を入れる（E）と、橙の灯りが壁を照らす。何もしなくても55秒で火が回る。 |
| 1:00〜3:00 | 異変①東の窓を叩く音と、霜のガラスに手の跡（1:15）②戸からストーブまで濡れた裸足の足跡が出現（2:00）③棚の無線機が勝手に鳴り「……三名……全員……小屋の中……」（2:40）。 |
| 3:00〜4:00 | 突風で戸が勝手に閉まり、凍りついて開かない（3:20）。足跡が倍に増える。ストーブの火が消え、ライトも弱まり、背後で誰かの息づかい（3:30）。薪の山から薪を取って火を戻すしかない。 |
| 4:00〜5:00 | 火が戻ると、テーブルの席に霜まみれの登山者が座っている。**彼を見た瞬間**、目の前に現れる（ジャンプスケア）。見なくても火が戻って約30秒で強制発生。 |

時間切れ救済: プレイ開始320秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 小屋の灯りはストーブの火だけ。消えると完全にフラッシュライトのみ
- 足跡・手形は最初は非表示で、異変のタイミングで出現（2段階）
- 戸の slam → lock による閉じ込め、フォグの濃度上昇
- 手続き音：風の唸り（ドローン）、ノック、ささやき混じりのノイズ、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（ストーブ・薪）、F: ライト
- ヘッドホン推奨

## エンディング

「雪解けの春、小屋の中から三人分の登山靴が見つかった。ストーブの前には、四人目の濡れた足跡が、まだ乾かずに残っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / zone / look / after、requires / requiresAny / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。足跡と手形は TransformNode 単位で visible 切り替え
- 共通土台は `kit/` を同梱（自己完結）
