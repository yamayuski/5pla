# 仕込みの時間（early-bakery）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

仕込みの時間

## 一行ピッチ

午前三時、一人きりのパン工房。生地を捏ねる音がもう一つ聞こえる。窯の扉を開けた先に、焼き上がっていたもの。

## 舞台

午前三時のパン工房（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 午前三時のパン工房で生地を作業台に出していく。 |
| 1:00〜3:00 | 異変①作業台の生地が勝手にへこむ（1:10）②照明が瞬き足音が止まる（2:00）③窯の窓に白い帽子の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。窯が焼き上がりを知らせている。扉を開けるしかない。 |
| 4:00〜5:00 | 窯の扉を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 窯の赤い光、タイマー音、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（窯の扉を開ける）、F: ライト

## エンディング

翌朝、店長は言った。「うちの窯、先月から壊れて火が入らないんだよ」 開店の棚には、あなたの形をした大きなパンが並んでいた。
