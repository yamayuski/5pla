# 消えた灯台（lighthouse）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

消えた灯台

## 一行ピッチ

霧の夜、廃止されたはずの岬の灯台を確かめに行くと、灯りが回り始め、古い制服の男が少しずつ近づいてくる。

## 舞台

岬の細い一本道（幅7m × 長さ24m、両側は崖と海）と、突き当たりの灯台の根元の部屋。道の脇に灯りのともる番小屋。濃い霧、波と霧笛。入口の鉄門は後ろで閉まる。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 岬の道を灯台に向かって歩く。道の脇の番小屋に灯りがともっている。 |
| 1:00〜3:00 | 異変①廃止されたはずの灯台の光が回り始める（1:10）②番小屋の窓に人影、背後に足音（1:50）③番小屋の扉が叩きつけられて灯りが消える（2:30）④道の先に古い制服の男が背を向けて立つ（3:05）。 |
| 3:00〜4:00 | 背後の鉄門が閉まり、男の姿が消える（3:25）。灯台の根元の部屋に入るしかない。 |
| 4:00〜5:00 | 部屋に入ると光が止まり、航海日誌に自分の名前と今日の日付。**約3秒後**（入らなくても約60秒後）、男が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 灯台の光は透過ボックスを `update` フックで回転させる
- 番小屋の窓は3枚の看板を `visible` で切り替え（灯り→人影→暗転）
- 濃い霧と波・霧笛の低音、足音、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、港の船乗りたちは、岬の灯台から光が一晩中回っていたと口をそろえた。事務所の記録では、あの灯台はとうに廃止されている。岬の鉄門の前には、懐中電灯だけが落ちていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。光の回転だけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
