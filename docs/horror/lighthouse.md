# 消えた灯台守（lighthouse）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

消えた灯台守

## 一行ピッチ

嵐の夜の無人灯台。外から叩く壁、変わる日誌、閉まる扉。灯室のガラスの向こうには、最初から灯台守が立っていた。

## 舞台

灯台の灯室（6m × 7m）。南壁に扉、東西にソファ、中央にテーブルと無線機とスイッチ、北壁に大型日誌、天井に無影灯。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 遠くの風音が漏れる静かな個室。スイッチで曲を入れる（E）と無影灯が回る。40秒で自動再生。 |
| 1:00〜3:00 | 異変①遠くの風音が止み壁を内側から叩く（1:15）②日誌の歌詞が「たすけて／うしろにいる」に（2:05）③無線機からささやき（2:45）。 |
| 3:00〜4:00 | 扉が勝手に閉まりロック（3:25）。照明が赤に変わりライトが弱まる、背後で息づかい（3:35）。無線機を置き直すしかない。 |
| 4:00〜5:00 | 向かいの灯室の向こうに雨合羽の人影が無線機を握って座っている。**見た瞬間**目の前に現れる。見なくても約35秒で強制発生。 |

時間切れ救済: プレイ開始320秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 無影灯の紫から非常灯の赤への照明切り替え
- 日誌表示の差し替え、扉の slam → lock、フォグ上昇
- 手続き音：ノック、ささやき、ノイズ、息づかい、笑い声、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（スイッチ・無線機）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、巡視船は倒れたままの灯室を見つけた。日誌には十年前に閉院した灯台の患者として、あなたの名前があった。」と表示して終了。
