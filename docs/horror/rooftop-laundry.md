# 干しっぱなし（rooftop-laundry）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

干しっぱなし

## 一行ピッチ

雨が降る前に屋上の洗濯物を取り込みに行くと、風にはためく白いシーツの下に、持ち主のいない白い足が立っていた。

## 舞台

マンションの夜の屋上（14m × 12m）。南西に階段室、奥に給水タンク、3列の物干しに白いシーツが並ぶ。シーツの下端は低く、向こう側に立つ人の足元が見える。街の明かりは遠く、外灯が一本だけ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 階段室を出て、風にばたつくシーツから自分の洗濯物を3枚取り込む（E）。まだ湿っていて冷たい。 |
| 1:00〜3:00 | 異変①一番奥のシーツの下に白い足が見える（1:10）②風が急に強まり、シーツが一斉に膨らむ（2:00）③白い足がシーツの列の向こうを横にすべっていく（2:30）④給水タンクの中を内側から叩く音（3:00）。 |
| 3:00〜4:00 | 階段室の扉が叩きつけられて開かない（3:25）。強風でシーツが荒れ狂い、外灯が落ちてライトが弱まる。白い裾がシーツの向こうからゆっくり近づく。 |
| 4:00〜5:00 | 風がぴたりと止み、すぐそこに白いワンピースの女。**見た瞬間**（または約7秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- シーツをプリミティブの板で作り、上辺ピボットで毎フレーム揺らす。風量は設定データ（windUp / windStorm / windStill）で段階的に変える
- 白い足だけが見える「隠れ」の見せ方、ゆっくりした横移動と接近（move アクション）
- 階段室の扉 slam → lock、外灯の消灯、フォグの上昇
- 手続き音：風、風鈴、ノック、足音、囁き、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（洗濯物）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、管理人が屋上の物干しに、見覚えのない白いワンピースが一枚だけ干されているのを見つけた。まだ、ぐっしょりと濡れていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。風のシーツ揺れだけ `update` / `custom` フックで実装
- 共通土台は `kit/` を同梱（自己完結）
