# ひよこ組（kindergarten-night）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

ひよこ組

## 一行ピッチ

幼稚園の宿直の夜、遊戯室で、閉じているはずのピアノが鳴り、壁の絵が少しずつ変わっていく。

## 舞台

幼稚園の遊戯室「ひよこ組」（12m × 12m、天井高3m）。小さな机と椅子、床のカラフルなマット、壁一面の園児の絵、奥のアップライトピアノ、おもちゃ箱。入口は手前の引き戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 宿直の見回り。床の積み木をおもちゃ箱に片付ける（E）。赤い積み木の裏に「みつけた」と書かれている。 |
| 1:00〜3:00 | 異変①閉じているピアノから「ど・み・そ」とたどたどしい音（1:10）②壁の絵が、長い髪の黒い影の絵（先生の顔）に変わる（1:50）③小さな机に園児の人影が四人、壁を向いてお絵かきしている（2:30）④四人が同時にこちらを向き、くすくす笑う（3:05）。 |
| 3:00〜4:00 | 戸が閉まって開かず、灯りが落ちる。ピアノの音が大きくなる（3:30）。ピアノの前にエプロン姿の先生が背中を向けて座っている（3:40）。 |
| 4:00〜5:00 | **先生を見た瞬間**（または約22秒後）、ピアノが止まり、先生が振り向いて目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 子ども向けのパステルの空間を「暗くする」ギャップ
- 壁の絵（文字板）のグループ差し替え、園児の人影（高さ約0.5）が `face` で一斉にこちらを向く
- ピアノの音をチャイムで表現し、灯りを落としたあとに音量を上げる
- 手続き音：ピアノ（チャイム）、笑い声、きしみ、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（積み木）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、遊戯室の机の上に、新しいクレヨンの絵が五枚、置かれていた。どれも、エプロン姿の『せんせい』の絵。園の記録に、ひよこ組の担任だった先生の名前は、一人も残っていない。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
