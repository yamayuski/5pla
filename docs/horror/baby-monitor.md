# ベビーモニター

## タイトル
ベビーモニター

## 一行ピッチ
初日のベビーシッター。モニターに映る赤ちゃんの横に、もう一人いる。

## 舞台
深夜の一軒家のリビングと、扉の先の子ども部屋。

## 5分の流れ
| 時間 | 内容 |
|---|---|
| 0〜1分 | リビングでモニターを見守る。静かな寝息 |
| 1〜3分 | 知らない歌声、メリーが勝手に回る、子ども部屋の扉が閉まる |
| 3〜4分 | 玄関が施錠され消灯。モニターに2つ目の影 |
| 4〜5分 | ベッドをのぞくと空。人影のジャンプスケア |

## 主な演出
モニター表示の変化、暗転と懐中電灯、扉の勢いよい閉まり、背後の足音。

## 操作方法
WASD移動、マウス視点、クリックで調べる。

## エンディング
夫婦「うちに子どもはいませんよ」。

## 実装メモ
horror-kit利用。config/level/indexのみ追加。
