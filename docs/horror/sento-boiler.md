# 釜の番（sento-boiler）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

釜の番

## 一行ピッチ

閉店後の銭湯のボイラー室。薪をくべるたび、釜の中から誰かが薪を数え返してくる。釜の扉を開けた先に。

## 舞台

閉店後の銭湯のボイラー室（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 釜の火を見ながら薪と圧力計を点検する。 |
| 1:00〜3:00 | 異変①薪の山が崩れる（1:10）②照明が瞬き足音が止まる（2:00）③煙突の陰に半纏の人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。数える声は釜の中から聞こえる。扉を開けるしかない。 |
| 4:00〜5:00 | 釜の扉を開けると人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 火のはぜる音、釜の鳴き声、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（釜の扉を開ける）、F: ライト

## エンディング

翌朝、番台の女将は釜の灰の中から、焦げた半纏の切れ端を見つけた。 圧力計の針は、あなたが入った時刻で止まっていた。
