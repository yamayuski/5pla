# 授与所の夜（shrine-office）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

授与所の夜

## 一行ピッチ

年の瀬の神社で忘れ物を取りに入った授与所。ひとりでに鳴る鈴、隅の小さな人影、新しい絵馬のあと、戸が閉まり、おみくじ筒が鳴り出す。

## 舞台

閉めたはずの神社の授与所（約6m × 8m）。奥に授与カウンターと棚、西壁に絵馬掛け、天井に鈴。入口は南の引き戸。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 冷えた木の匂いの授与所を見て回る。50秒で天井の鈴がひとりでに鳴る。 |
| 1:00〜3:00 | 異変①奥の隅に小さな白い人影、目を逸らすと消える（1:35）②絵馬掛けに「あなたがここにいますように」の新しい絵馬（2:30）③境内の太鼓が一度鳴る（3:10）。 |
| 3:00〜4:00 | 戸が閉まりロック、授与所の明かりが落ち（3:35）、カウンターの灯りだけが残る。おみくじ筒が鳴っている。 |
| 4:00〜5:00 | おみくじを引く（E）と「凶　うしろ」。顔を上げると巫女が立っており、ジャンプスケア。引かなくても約40秒後に発火。330秒で強制発火。 |

## 主な演出

- 鈴・太鼓・筒の音、背後の気配、閉ざされる戸
- lookAway で消える人影、増える絵馬

## 操作方法

- WASD / 矢印: 移動、マウス: 視点
- E / クリック: 調べる（おみくじ筒）、F: ライト

## エンディング

「元日の朝、参拝客が授与所のカウンターで見つけたのは、一枚のおみくじだった。『凶　うしろ』。名前の書かれた絵馬が、そのすぐ隣に増えていた。」

## 実装メモ

- 鈴の揺れは custom フック suzuSwing。絵馬は visible で出す。
