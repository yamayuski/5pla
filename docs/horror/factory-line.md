# 最終工程（factory-line）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

最終工程

## 一行ピッチ

食品工場の夜勤の終わりに、背後の入口が閉まり、非常ベルの赤い灯りの中を女が歩いて追ってくる。奥の非常口までの30メートルを逃げる。

## 舞台

食品工場の製造ライン通路（8m × 30m、天井高4m）。西側にベルトコンベア、東側に大きな機械、奥に緑色の非常口。冷却ファンの唸り。入口は後ろで閉まる。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | タイムカードを押す（E）。記録の時刻は昨日の夜になっている。 |
| 1:00〜3:00 | 異変①止まっていたコンベアが勝手に動く、流れる箱はすべて空（1:10）②構内放送「まだ構内に一名、残っています」（2:00）③入口のほうから濡れた靴のような足音（2:40）④奥の非常口のランプが点滅（3:10）。 |
| 3:00〜4:00 | 背後の入口が閉まり、非常ベルと赤い灯り（3:25）。入口側に女が現れ、奥へ向かって歩いてくる（3:31）。 |
| 4:00〜5:00 | 奥の非常口へ走る。非常口を開けようとした瞬間（または追跡開始から約17秒後）、女が目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- コンベアの箱は `update` フックで流し、ベルが止まる／空の箱が続く不気味さ
- 追跡者は `move` で入口側から奥へ24秒かけて歩く（歩いて追ってくるのに、逃げ切れない）
- 通常灯→赤い非常灯への切り替えと非常ベル
- 手続き音：ゴロゴロ音、チャイム、足音、ブザー、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（タイムカード・非常口）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、ラインの点検に来た職員は、ベルトコンベアの最後に箱が一つ余っていることに気づいた。箱の中には、昨夜の夜勤の社員証が一枚だけ入っていたという。製造ラインは今日も、問題なく稼働している。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。コンベアの流れだけ `update` / `custom` フック
- 共通土台は `kit/` を同梱（自己完結）
