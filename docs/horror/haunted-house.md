# 出演者は3名です（haunted-house）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

出演者は3名です

## 一行ピッチ

遊園地のお化け屋敷で、3人の「出演者」に驚かされたあと、出口の前で背後から4人目の足音が近づいてくる。

## 舞台

遊園地のお化け屋敷の細長い通路（4m × 34m、天井高2.6m）。赤い提灯、血のり、棺桶、お札。入口の扉は進むと閉まり、出口の非常口は鍵がかかっている。入口の張り紙には「本日の出演者は3名です」。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 通路に入ると背後の入口が閉まる。1人目の出演者（白い着物の女）が壁の陰から飛び出す（ゾーン、または0:55）。 |
| 1:00〜3:00 | 異変（驚かせ役）①2人目、棺桶の陰から赤い着物の男が起き上がる（ゾーン、または1:50）②3人目、天井から青い着物の影がぶら下がる（ゾーン、または2:45）。「これで出演者は全員だ」。 |
| 3:00〜4:00 | 出口の前で背後の足音に気づく（ゾーン、または3:35）。出演者は3名のはず。提灯が消える。 |
| 4:00〜5:00 | 4人目の白い着物の女が入口側から歩いてくる。**目を向けた瞬間**（または約13秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 進行はゾーン（位置）で進み、時間経過でも自動で進む（どちらか早いほう）
- 作り物のお化け3人は `visible` の出し入れだけ、4人目だけが `move` で歩いて近づく
- 提灯の消灯、足音、ささやき、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「後日、お化け屋敷のスタッフに尋ねると、『あの日の出演者は、本当に3名だけでした』と青い顔で答えた。防犯カメラには、通路を一人で歩く来場者の背後に、白い着物の4人目がずっと映っていたという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（zone と time の二重化で進行不能を防ぐ）
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
