# 冷蔵庫の中身（kitchen-night）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

冷蔵庫の中身

## 一行ピッチ

深夜の自宅の台所で冷蔵庫を開けると、見覚えのない弁当箱があり、閉じた冷凍庫の中から叩く音がする。

## 舞台

一人暮らしのダイニングキッチン（6m × 8m、天井高2.5m）。テーブル、流し台、壁の時計、奥の冷蔵庫。冷蔵庫の灯りだけで過ごす深夜二時。玄関は手前の壁。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 冷蔵庫の上段を開けて麦茶を取る（E）。中に見覚えのない弁当箱。ふたに自分の字で「今日の分」。 |
| 1:00〜3:00 | 異変①冷蔵庫のモーターが人の唸り声のように鳴る（1:10）②上段の扉がひとりでに閉まる（1:55）③下段の冷凍庫の中からノック（2:35）④「……出して……さむい……」、時計が止まる（3:10）。 |
| 3:00〜4:00 | 玄関のドアが閉まって鍵がかかり、電気が消える（3:25）。冷凍庫を叩く音だけが大きくなる。 |
| 4:00〜5:00 | 冷凍庫を開ける（E）と、折りたたまれていた何かが飛び出す（ジャンプスケア）。開けなくても約55秒後に扉が開く。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 冷蔵庫の扉は `move` で横へスライドして開閉し、中の看板と庫内灯（点光源）を見せる
- 唸るモーター音、ノック、ささやき、扉の閉まる音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（冷蔵庫の上段・冷凍庫）、F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、管理人が部屋を訪ねると、台所の冷蔵庫の扉が開いたままだった。中の食べものはすべて凍りつき、麦茶のボトルの横に『今日の分』と書かれた弁当箱が、ひとつだけ残っていたという。部屋の住人は、見つかっていない。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ。フックなし
- 共通土台は `kit/` を同梱（自己完結）
