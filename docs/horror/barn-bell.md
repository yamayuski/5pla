# 納屋の鈴（barn-bell）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

納屋の鈴

## 一行ピッチ

祖父の古い納屋に入り込んだ飼い猫を探しに行くと、奥から鈴の音がする。それはもう、猫の首輪ではなかった。

## 舞台

田舎の祖父の家の裏にある古い納屋（9m × 20m、天井高4.5m）。入口から奥へ一本の通路が走り、左右に馬房が3つずつ。藁の山、農具、古い荷車。灯りは梁から下がった電球が2つだけで、庭に外灯が1つ。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 懐中電灯を手に納屋へ。奥から断続的に聞こえる首輪の鈴の音をたどり、ミケを探す。 |
| 1:00〜3:00 | 異変①背後の馬房の戸が勝手にばたんと閉まる（1:10）②鈴の音が入口側へ移動し、入口側の電灯が消える（1:50）③右の馬房の藁の中から子どもの笑い声（2:30）。 |
| 3:00〜4:00 | 入口の大戸が閉まり、かんぬきの音。全灯が消えてライトが弱まる（3:20）。奥から馬房の戸が左右対で次々に閉まっていく（3:29〜3:33）。通路の奥から老人が近づいてくる。 |
| 4:00〜5:00 | **老人を見た瞬間**（または約9秒後）、目の前に現れる（ジャンプスケア）。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 馬房の戸 6 枚を実際に回転させ、奥から手前へ「ばたん、ばたん」と次々に閉める（door アクション slam、間隔1.7秒）
- 鈴の音を空間音響で位置を変えて鳴らす（奥 → 左右 → 背後）
- 通路を老人が歩いて近づく（move アクション）
- 手続き音：鈴、戸の衝撃音、子どもの笑い声、重低音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- F: ライト
- ヘッドホン推奨

## エンディング

「翌朝、ミケは母屋の縁側で眠っていた。首輪の鈴は、とうの昔に外れて失くしたはずだった。納屋の奥の馬房からは、錆びた小さな鈴が、いくつも見つかったという。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述
- `level.ts` は MeshBuilder のプリミティブのみ（custom フックなし）
- 共通土台は `kit/` を同梱（自己完結）
