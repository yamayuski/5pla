# 深夜二時のレジ（night-shift）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## 一行ピッチ

ワンオペ夜勤のコンビニで、防犯モニターにだけ映る女が、少しずつ自分の背後へ近づいてくる。

## 舞台

国道沿いのコンビニ「ヨミマート」（店内 12m × 8m）。ガラス張りの正面に自動ドア、左壁沿いにレジカウンター、3 本の陳列棚、奥に冷蔵ケースとバックヤードの扉。外は真っ暗な駐車場。時刻は深夜二時。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯のうなり。店の奥の段ボールを品出しし、レジに戻るだけの「いつもの夜勤」。 |
| 1:00〜3:00 | 小さな異変①レジに戻ると誰もいないのに自動ドアが開き、入店チャイムが鳴る。②防犯モニターを見ると、入口の外に女が立っている（実際に外を見ても誰もいない）。③バックヤードで電話が鳴る。向かう途中で棚の商品が落ちて照明が明滅。扉は開かず、内側からノックが返ってくる。 |
| 3:00〜4:00 | 停電。自動ドアが叩きつけるように閉まり閉じ込められる。冷蔵ケースの明かりとスマホのライトだけ。誰もいない入口でチャイムが鳴る。防犯モニターには店内の通路に立つ女。 |
| 4:00〜5:00 | もう一度モニターを見ると、女は「自分（モニター上の店員）」のすぐ後ろに立っている。背後で息づかい。振り返ると女が飛び込んでくる（ジャンプスケア）。振り返らなくても約9秒後に発生。 |

時間切れ救済: 品出し・電話・モニターそれぞれにヒント/自動進行があり、プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- 防犯カメラ映像: `RenderTargetTexture` + 別カメラ。女とプレイヤーの代役は `layerMask` で「防犯カメラにだけ映る」ようにしている（プレイヤーの目には見えない）。
- 暗闇: 停電で店内照明グループ store が消え、冷蔵ケースの青白い光だけが残る。
- 懐中電灯: 停電後にスマホのライト（減光）。F でオン/オフ。
- 音（WebAudio 手続き生成）: 入店チャイム、蛍光灯のうなり、電話、ノック、ドアのガタつき、商品の落下音、息づかい、心音、スティンガー。
- ドア: 無人で開閉する自動ドア → 停電で閉鎖。開かないバックヤードの扉。
- 背後の気配: モニター越しに「自分の真後ろ」を見せ、振り返り（look トリガー）で発火。

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 品出し・モニターを見る・扉を開ける
- F: ライトのオン/オフ、Esc: 一時停止
- ヘッドホン推奨

## エンディング

暗転後「朝六時、交代のバイトが来たとき、店には誰もいなかった。防犯カメラには、レジの中で、誰もいない背後に何度も頭を下げ続ける店員が映っていたという。」

## 実装メモ

- 起動: `/5pla/?horror=night-shift`
- `config.ts`: 演出トリガーのデータ。分岐の合流は `requiresAny`、時間切れ救済の打ち消しは `unless`。
- `level.ts`: マップ・防犯カメラ・作品固有の custom フック（自動ドア、女の配置、商品落下）。
- `kit/`: 一人称ホラー共通土台（作品フォルダ内に自己完結で同梱）。
- 共有ファイルの変更は `apps/web/src/main.ts` の `?horror=` 分岐と `packages/games/src/horror/registry.ts` のみ（全ホラー候補 PR で同一内容）。
