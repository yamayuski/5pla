# 降りても降りても（fire-stairs）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

降りても降りても

## 一行ピッチ

停電の非常階段。降りても降りても12階のまま、階段の下から「一緒に降りてください」と声がする。

## 舞台

停電したマンションの非常階段（約8m × 14m）。入口に防火扉、奥に黄色い階段口、手前に階数表示台と非常電話。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 蛍光灯の車庫。階数表示を点検する（数字が勝手に上がっている）。 |
| 1:00〜3:00 | 異変①非常電話「もう車の中です」（1:10）②階段を叩く音（2:00）③「一緒に降りてください」の声（2:45）。 |
| 3:00〜4:00 | 防火扉が落ちて消灯（3:25）。階段下に人影、背後に足音。 |
| 4:00〜5:00 | メーターを止めようとすると人影が目の前に現れる（ジャンプスケア）。触らなくても330秒で発生。 |

## 主な演出

- 蛍光灯→消灯、防火扉の slam / lock
- 赤く光る階数表示、階段下の人影
- 手続き音：ブザー、ノック、ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点、E / クリック: 調べる、F: ライト

## エンディング

翌朝、階数表示だけが夜通し増え続けている。

## 実装メモ

config.ts に演出データ、level.ts にジオメトリ。
