# お連れ様（ramen-yatai）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

お連れ様

## 一行ピッチ

残業帰り、川沿いに一台だけ出ていた屋台のラーメン屋。一人で来たのに、隣の空席にも「お連れさんの分」の丼が置かれ、誰もいない席から麺をすする音がする。

## 舞台

夜の川沿いの遊歩道（屋外、20m × 12m）。北に川と柵、東西に街灯が一本ずつ。中央に屋台が一台（暖簾「中華そば」、赤ちょうちん、丸椅子が二つ）。屋台の中の店主は手ぬぐいを巻いて最初からうつむいている。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 川の音と湯気。品書きを見て注文する（E）と「へい、お待ち」と丼が出る。店主は一度も顔を上げない。何もしなくても45秒で丼が置かれる。 |
| 1:00〜3:00 | 異変①隣の空いた席にも丼が置かれる。「お連れさんの分ね」（1:15）②隣の丼から麺をすする音とささやき、風もないのにちょうちんが揺れる（2:00）③遊歩道の街灯が消え、背後を何人もの足音が通り過ぎる（2:45）。 |
| 3:00〜4:00 | 川から濃い霧が上がり、来た道も橋も見えなくなる（3:25）。屋台の電球が切れ、ちょうちんの赤い灯りだけ。勘定の札が置かれる。「二名様で」。 |
| 4:00〜5:00 | 勘定を払う（E）と「お連れさん、ずっと待ってたんですよ。……あんたが来るのを」。店主がゆっくり顔を上げ、赤い目で**目の前に迫る**（ジャンプスケア）。払わなくても約35秒で店主が顔を上げ、それを見た瞬間に発生。 |

時間切れ救済: プレイ開始330秒で強制的にジャンプスケア → エンディング。

## 主な演出

- 最初から目の前にいる「顔の見えない店主」という持続的な不安。最後に顔を上げる（フック `cookLookUp`）
- 誰もいない隣の席の丼とすする音、揺れるちょうちん（フック `lanternSway`）
- 屋外なので扉ではなく、街灯の消灯と濃霧で逃げ道を塞ぐ
- 手続き音：川の音（ドローン）、息づかい、ささやき、通り過ぎる足音、地鳴り、鈴、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（品書き・勘定の札）、F: ライト（電球が切れたあと自動で点く）
- ヘッドホン推奨

## エンディング

「翌朝、川沿いの遊歩道に屋台はなかった。ベンチの上に、冷めた丼が二つだけ並んでいた。片方は、きれいに空になっていた。」と表示して終了。

## 実装メモ

- `config.ts` に演出トリガーを全てデータで記述（time / interact / look / after、requires / unless で保険）
- `level.ts` は MeshBuilder のプリミティブのみ。丼は TransformNode 単位で表示切り替え
- 共通キット `@5pla/horror-kit` を使用（作品フォルダは config / level / index の3ファイル）
