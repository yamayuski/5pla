# てっぺんの手前（gondola-night）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

てっぺんの手前

## 一行ピッチ

閉園間際の観覧車に一人で乗ったはずが、地上40メートルの窓に手形が増え、ゴンドラが止まる。

## 舞台

観覧車のゴンドラ内（3m × 3m）。向かい合う二つのベンチ、東西の窓、天井の電球。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | ゴンドラが昇り始める。軋む音と風。何も起きない静けさで緊張をためる。 |
| 1:00〜3:00 | 異変①窓の外に手形（1:15）②手形が増え笑い声（2:05）③照明が明滅しゴンドラが停止（2:45）。 |
| 3:00〜4:00 | 停電し背後で息づかい（3:20）。閉じ込められ動けない。 |
| 4:00〜5:00 | 灯りが戻ると向かいの席に白い服の女（4:10）。**見た瞬間**に目の前へ飛び出す。5:00で強制発生。 |

## 主な演出

- 電球・ライトの停電、フォグ濃度の上昇、窓の手形
- 手続き音：軋み、ノック、笑い声、息づかい、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）、F: ライト

## エンディング

「係員は降りてきたゴンドラを確認した。乗客は一人のはずだったが、座席には濡れた足跡が二人分、並んでいたという。」

## 実装メモ

- config.ts に演出をデータで記述、level.ts はプリミティブのみ、kit/ 同梱
