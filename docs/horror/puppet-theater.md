# 幕が上がる前（puppet-theater）

> 仮仕様（ホラー候補）。夜間の自動生成によるたたき台です。

## タイトル

幕が上がる前

## 一行ピッチ

閉館した人形劇場。舞台の幕の裏から、人形を動かす糸の音がする。幕を引いた先には。

## 舞台

閉館した人形劇場の客席と舞台（約12m × 16m）。

## 5分の流れ

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:00 | 客席の列を回って点検していく。 |
| 1:00〜3:00 | 異変①糸の軋む音（1:10）②照明が瞬き足音が止まる（2:00）③客席後方に小さな人影（2:40）。 |
| 3:00〜4:00 | 入口扉が閉まって施錠（3:20）、手前の灯りが落ちる。幕の向こうから、開演のブザーが聞こえる。幕を引いて確かめるしかない。 |
| 4:00〜5:00 | 幕を引くと人影がいて、ジャンプスケア。 |

時間切れ救済: プレイ開始330秒で強制ジャンプスケア。

## 主な演出

- スポットライト、糸の軋み、足音、扉の施錠、照明の消灯、霧、懐中電灯
- 手続き音：ささやき、足音、心音

## 操作方法

- WASD / 矢印: 移動、マウス: 視点（クリックでポインターロック）
- E / クリック: 調べる（幕を引く）、F: ライト

## エンディング

翌朝、館長は言った。「あの劇場の演目は、もう十年前に終わっているよ」 舞台の中央に、あなたと同じ服を着た新しい人形が一体、座っていた。
